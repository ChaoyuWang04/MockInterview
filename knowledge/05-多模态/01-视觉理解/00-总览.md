# 视觉理解 · 总览

一句话:这是本子领域 **5 篇的导航页**——只回答"我该读哪篇、按什么顺序读",**不讲任何原理**。这五篇不是五个并列话题,而是**一条从像素到语言模型的流水线**,外加一个岔出去的分支;先看清这条线,五篇的边界就自然清楚了。

## 一、四篇是一条流水线,一篇是岔路

一张图从进系统到被语言模型读懂,要过四道手。**每一篇就是其中一道**,而且**上一道没做好的事,下一道谁也补不回来**——这是本子领域反复出现的一句话:

| 顺序 | 篇 | 这一道在做什么 | 交出去的是什么 |
|---|---|---|---|
| ① | **图像预处理** | 像素在进模型之前被动的手:颜色与噪声 | 一张更"干净"(未必更有用)的图 |
| ② | **任意分辨率与高分辨率** | 4K 截图、长图、扫描件怎么喂进只吃固定方图的视觉塔 | 尺寸合规、且没被压糊的输入 |
| ③ | **视觉编码器** | 像素变成一串带语义的向量 | 视觉特征 |
| ④ | **VLM结构** | 视觉特征怎么汇进语言模型 | 一个能看图说话的模型 |

第五篇 **视觉分割与SAM** 是**岔路**,不在这条线上:它共用编码器这一层的技术,但**输出的不是喂给 LLM 的特征,而是一块像素区域**,任务定义完全不同。想清楚"我要的是让模型看懂图,还是让模型指出图里的一块",就知道该不该读它。

## 二、五篇各回答什么

| 篇 | 它回答什么 | 一句话定位 |
|---|---|---|
| **图像预处理** | 为什么"转灰度"该先问一句为什么;四类噪声模型怎么认;均值/高斯/中值/双边/非局部均值各自的原理与保边代价;视频时域降噪与运动重影 | 关键判据是**图更平滑不等于下游任务更好** |
| **任意分辨率与高分辨率** | 固定分辨率到底卡在哪;位置编码怎么跟着分辨率走;切片路线与原生动态分辨率路线的取舍;成本账 | **不把大图压糊,又不让视觉 token 撑爆上下文** |
| **视觉编码器** | ViT 怎么把图变成 token;归纳偏置与数据量门槛;CLIP 拿"图文配不配对"当监督;SigLIP 换成逐对 sigmoid;不看文字的 MAE 与 DINO;骨干横向选型 | **模型的眼睛**;它没编出来的信息,后面谁也补不回来 |
| **VLM结构** | 视觉特征在哪一层汇入、汇入多少 token、为此新增多少参数;三条接法与按任务选型;编码器+适配器 vs 原生早融合;结构上的冻结与分阶段 | 结构问题只有一个:**训好的 LLM 怎么把图读进去** |
| **视觉分割与SAM** | 语义/实例/全景与可提示分割的任务定义之别;SAM 的三段结构为什么能交互实时;歧义多掩码与质量分;数据引擎三阶段;类别无关的边界与视频/3D 扩展 | **你指哪我切哪**;给区域,不给名字 |

## 三、按目标挑一条读法

| 你的目标 | 建议路径 |
|---|---|
| **第一次系统学视觉理解** | 按流水线顺序:图像预处理 → 任意分辨率与高分辨率 → 视觉编码器 → VLM结构,最后按需读 视觉分割与SAM |
| **准备多模态大模型岗面试**(题最密的一条) | 视觉编码器 → VLM结构 → 任意分辨率与高分辨率;这三篇覆盖本子领域 8 道真题里的 6 道 |
| **做文档/截图理解产品** | 任意分辨率与高分辨率 → 图像预处理 → 多模态RAG(根目录) |
| **做检测分割类 CV 方向** | 视觉分割与SAM → 视觉编码器(骨干选型那一节)→ 图像预处理 |
| **只想搞清楚"图怎么进 LLM"** | VLM结构 一篇即可,机制不懂时再回头翻 视觉编码器 |

## 四、边界速查:这几件事写在哪一篇

五篇互相声明过边界,最容易找错的六处:

| 你要找的 | 在这篇 | 别去这篇找 |
|---|---|---|
| 分辨率、缩放、切图、视觉 token 预算 | **任意分辨率与高分辨率** | 图像预处理 只管颜色与噪声,不碰分辨率 |
| ViT 的 patch embedding、CLIP/SigLIP/MAE/DINO 的训练机制 | **视觉编码器** | VLM结构 与 视觉分割与SAM 都只引一句 |
| 连接器三条接法、视觉 token 账、原生早融合 | **VLM结构** | 视觉编码器 只负责把特征做出来 |
| **结构侧**的冻结与分阶段(为什么必须分阶段、全解冻为什么训崩) | **VLM结构** 第四节 | **训练侧**的冻结判断(怎么用实验决定动哪一层)归根目录 多模态训练 |
| InfoNCE 的公式、温度、难负例工程 | 02 章 **对比学习** | 视觉编码器 只讲 CLIP 拿它当监督信号这件事 |
| 图文数据治理、ITC/ITM/生成/指令四种目标怎么配 | 根目录 **多模态训练** | 本子领域五篇都不讲训练配方 |

> **一个重名陷阱**:02 章 泛化与正则化 里的 SAM 是 Sharpness-Aware Minimization(一种优化方法),和 视觉分割与SAM 里的 Segment Anything Model 毫无关系。

## 五、真题速查

题库 `questions/` 是真题的唯一集合。本子领域挂着 **8 道**,是多模态章里题最密的一块:

| 篇 | 真题数 | topic 第二段 |
|---|---|---|
| **VLM结构** | **4** | CLIP BLIP-2 Flamingo LLaVA与Qwen-VL · MLP与Q-Former连接器 · 表示 对齐与融合 · 后训练差异 |
| **视觉编码器** | 2 | CLIP与图文对齐 · CNN Swin ConvNeXt与EfficientNet |
| **图像预处理** | 1 | 灰度转换与经典降噪 |
| **视觉分割与SAM** | 1 | 架构与提示编码 |
| 任意分辨率与高分辨率 | 0 | 暂无同名 topic 真题,考点表以补充题为主 |

两点值得注意:**`VLM结构` 是全子领域的考试重心**,四道题分别问架构谱系、连接器、融合方式和后训练,建议优先吃透;其中「后训练差异」那道收在题库的 `SFT` 分类下,是跨分类题,别只在 `多模态` 分类里找。

## 六、小节级索引:想找某一件事,直接翻到哪一节

**图像预处理**

1. 先问「为什么要转灰度」
2. 噪声从哪来:四种模型与怎么认出来
3. 五种经典降噪:原理与保边的代价
4. 关键判据:更平滑不等于下游更好

**任意分辨率与高分辨率**

1. 固定分辨率到底卡在哪
2. 位置编码怎么跟着分辨率走
3. 切片路线:把大图拆成视觉塔吃得下的小块
4. 原生动态分辨率路线:不切,直接让序列变长
5. 成本账与按任务选路线

**视觉编码器**

1. ViT:图像怎么变成一串 token
2. 归纳偏置与数据量门槛
3. CLIP:拿"图文配不配对"当监督信号
4. SigLIP:全局 softmax 换成逐对 sigmoid
5. 不看文字的另一条路:MAE 与 DINO
6. 骨干横向选型

**VLM结构**

1. 三条接法:视觉信息在哪一层汇入
2. 横向比较与按任务选型
3. 编码器 + 适配器 vs 原生早融合
4. 结构上的冻结与分阶段

**视觉分割与SAM**

1. 四种"分割"不是一件事
2. 三段结构:不对称设计买来的是交互实时
3. 歧义:一个点到底指什么
4. 数据引擎:10 亿掩码是怎么滚出来的
5. 零样本的真实含义、边界,以及视频与 3D
