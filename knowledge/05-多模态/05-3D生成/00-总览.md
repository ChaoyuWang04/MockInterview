# 3D 生成 · 总览

一句话:这是本子领域 **4 篇的导航页**——只回答"我该读哪篇、按什么顺序读",**不讲任何原理**。这四篇回答的是**两道不同的题加一道收口题**;先分清哪篇在答哪道,边界就自然清楚了。

## 一、两道题,一道收口题

| | 篇 | 它在回答什么 | 输入是什么 |
|---|---|---|---|
| **题一 · 重建** | **NeRF** | 有一组标定过的多视角照片,怎么重建出能任意视角渲染的场景——**隐式**路线 | 多视角照片 + 相机参数 |
| | **3DGS** | 同一道题的**显式**路线,以及显式换来了什么 | 同上 |
| **题二 · 生成** | **多视角扩散** | **没有照片**,只有一句话或一张图,怎么造出 3D | 文本 / 单图 |
| **收口** | **网格生成** | 前三篇的产出,**工业管线其实用不了**,怎么跨过这道坎 | 密度场 / 高斯云 / 多视角图 |

**NeRF 和 3DGS 是同一道题的两个答案**,这一点最容易被忽略:它们的任务完全一样,分歧只在**场景存成什么**——一个存进网络权重(隐式),一个存成几百万个椭球(显式)。3DGS 整篇是针对 NeRF 定义的,所以**两者的横向对比写在 `3DGS` 篇**,`NeRF` 篇只在末尾留一句引用。

**`多视角扩散` 换了一道题**,因为它的输入里根本没有照片。它的立论也因此完全不同:**高质量 3D 资产比互联网图片少三到四个数量级**,所以走不通"堆数据训 3D 模型"这条路,只能借 2D 扩散模型已经学到的先验。

**`网格生成` 是这个子领域的收口**,它立的那条标准其实统摄全章:

> **"渲染出来对"和"拿去能改能用",是两条不同的标准。**

前三篇优化的都是第一条。第二条——干净拓扑、可用 UV、可重新打光的材质——至今仍需要人工介入,这也是"3D 生成还没颠覆美术管线"最实在的原因。

## 二、四篇各回答什么

| 篇 | 它回答什么 | 一句话定位 |
|---|---|---|
| **NeRF** | 3D 表示谱系(体素/点云/网格/隐式场);MLP 吃 5 维吐 4 维;体渲染方程与透射率;位置编码为什么必需;分层采样;训练慢与渲染慢是两件事;Instant-NGP / Mip-NeRF 等加速谱系 | **本子领域的地基篇**:表示谱系和体渲染方程只在这里讲一次 |
| **3DGS** | 高斯基元存了什么(含协方差为何拆成缩放+旋转);可微光栅化五步;快的四条根因;自适应密度控制;浮空物与存储代价;在生成里当输出容器 | 渲染回路里**没有神经网络**,所以那几亿次 MLP 前向是被**删掉**了,不是被优化了 |
| **多视角扩散** | 3D 数据稀缺的量级账;SDS 把冻结的 2D 模型当评委;Janus 问题的根子;相机位姿这个条件难在哪;跨视角注意力;优化式 vs 前馈式 | 所有方法都是**把 2D 先验搬到 3D**的不同解法 |
| **网格生成** | 为什么偏偏是三角网格;网格质量的六个维度;Marching Cubes 的机制与四种病;UV 展开的数学死结;烘死的贴图 vs PBR;自回归网格生成 | 提取出来的拓扑是**扫描出来的,不是设计出来的** |

## 三、按目标挑一条读法

| 你的目标 | 建议路径 |
|---|---|
| **第一次系统学 3D 生成** | NeRF(地基)→ 3DGS(对照着读)→ 多视角扩散 → 网格生成 |
| **做重建 / 新视角合成** | NeRF → 3DGS,两篇对着读就够 |
| **做文生 3D / 图生 3D 产品** | 多视角扩散 → 网格生成 → 3DGS(它常被当输出表示) |
| **关心"生成的资产能不能进管线"** | 网格生成 一篇,读完再按需回头翻前三篇 |
| **准备多模态岗面试** | NeRF → 3DGS(这两篇的对照是最常见的考法)→ 多视角扩散 |

## 四、边界速查:这几件事写在哪一篇

四篇互相声明过边界,最容易找错的七处:

| 你要找的 | 在这篇 | 别去这篇找 |
|---|---|---|
| 3D 表示谱系(体素/点云/网格/隐式场的取舍) | **NeRF** 第一节 | 另外三篇都只有一句引用 |
| 体渲染方程、位置编码、分层采样 | **NeRF** | 3DGS 的 alpha 合成与它同源,但只写"推导见 NeRF 篇" |
| **NeRF ↔ 3DGS 的横向对比** | **3DGS** 第一节 | NeRF 篇只在「局限」留一句 |
| 高斯参数化、可微光栅化、自适应密度控制 | **3DGS** | —— |
| SDS、Janus、跨视角注意力、优化式 vs 前馈式 | **多视角扩散** | —— |
| 提网格、Marching Cubes、UV、材质分解 | **网格生成** | 前三篇都把这件事指给了它 |
| 扩散过程本身、采样器、CFG | 根目录 **Diffusion** | 多视角扩散 只讲用在 3D 上的代价 |

> **一处容易混的对照**:`多视角扩散` 管的是**同一时刻、不同机位**的空间一致性(约束**硬**——同一个点在不同视角的位置由相机参数唯一确定);03-视频生成 的 `长视频一致性` 管的是**同一个东西、不同时刻**的时间一致性(约束**软**——物体本来就会变)。两边只做一句对照,不互相展开。

## 五、真题速查:本子领域暂无真题

2. **问法只代表作者判断**。它们按契约第九节的四条否决线筛过、也都是"一主一追"的复合句形态,但没有真题可以校准它们问得准不准。

> 采到 3D 方向的真题后,按 `docs/02-题库导入流程.md` 入库,再回到对应专篇重做考点表——**真题优先,补充题让位**。

## 六、小节级索引:想找某一件事,直接翻到哪一节

**NeRF**

1. 先摆清 3D 表示谱系:NeRF 到底在反对什么
2. 隐式辐射场与体渲染方程
3. 位置编码:整篇最反直觉的一条
4. 慢在哪、怎么加速、还有什么解决不了

**3DGS**

1. 它要回答的问题:和 NeRF 是同一道题(含横向对照表)
2. 一个高斯基元里存了什么
3. 可微光栅化:快的根子在这里
4. 训练:密度是长出来的,不是给定的

**多视角扩散**

1. 根本约束:3D 数据稀缺
2. 优化式:SDS 把冻结的扩散模型当评委
3. Janus 问题与视角条件化
4. 优化式 vs 前馈式:为什么前馈后来居上

**网格生成**

1. 立论:前三篇的产出,工业管线其实用不了
2. 网格质量到底指什么
3. 路线一:从场里把网格提取出来
4. 路线二:直接把网格生成出来
