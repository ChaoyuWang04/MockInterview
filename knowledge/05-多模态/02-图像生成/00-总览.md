# 图像生成 · 总览

一句话:这是本子领域 **4 篇的导航页**——只回答"我该读哪篇、按什么顺序读",**不讲任何原理**。生成范式本身(VAE、Diffusion、FlowMatching、DiT)住在上一级的多模态章根目录,它们是本子领域四篇共同的前置,这里不重复。

## 一、先读上一级:四篇共用范式

图像生成的原理不在本目录里。根目录那四篇是**整个多模态章共用的地基**——视频生成也从它们出发,所以谁也不归属于某一个子领域:

| 篇 | 它回答什么 | 为什么是前置 |
|---|---|---|
| **VAE** | 瓶颈上为什么要装概率、ELBO 两项在打什么架、重参数化、后验坍塌与"生成糊";**VQ-VAE 一族与码本坍塌的成因、诊断、缓解也在这篇** | latent diffusion 脚下那块地板。不读它就答不了"为什么要在潜空间做扩散" |
| **Diffusion** | 前向加噪与噪声调度、为什么训练目标是"猜噪声"、1000 步怎么压到 10 步、条件与 CFG 引导 | 本子领域三篇的骨干机制都从这里来 |
| **FlowMatching** | 把生成学成一张流速图;三种"直"不是一回事;它和扩散改的不是同一层 | SD3、Flux 这一代文生图用的就是它 |
| **DiT** | 把 U-Net 换成 Transformer:patchify、adaLN-Zero、scaling 曲线 | 当代骨干的默认答案 |

顺序建议:**VAE → Diffusion → DiT → FlowMatching**。前两篇必读;DiT 决定你看不看得懂当代骨干;FlowMatching 可以晚一步补。

## 二、本子领域四篇:各回答什么

| 篇 | 它回答什么 | 一句话定位 |
|---|---|---|
| **SD架构** | 文本编码器 + 去噪骨干 + VAE 编解码三个零件怎么接线;一次出图的算力和显存分别花在哪;SD 1.x → SDXL → SD3 三代改了哪几处 | **产品级流水线的装配图**,不讲扩散原理 |
| **图像Tokenizer** | 离散还是连续这个岔路口;四条量化路线各绕开什么;码本大小/维度/层数怎么配;重建好为什么不等于生成好;语义 ID | **输入层的选型篇**,它钉死下游序列长度与画质天花板 |
| **条件控制** | 条件的形态决定它从哪一层进网络;全局向量类(FiLM/AdaIN/adaLN)、序列类(cross-attention)、空间对齐类(ControlNet)各自的参数与开销账;多条件叠加怎么打架 | **"模型已经会画了,怎么让它照我说的画"** |
| **图像编辑** | 编辑与从零生成的根本差别;inversion 把真图搬回噪声;注意力操控;指令式编辑;掩码式局部重绘;编辑强度怎么评 | 难的不是改的那一处,是**没让改的那 95% 像素能不能原样留住** |

## 三、按目标挑一条读法

| 你的目标 | 建议路径 |
|---|---|
| **第一次系统学图像生成** | VAE → Diffusion → SD架构 → DiT → 条件控制 → 图像Tokenizer → FlowMatching → 图像编辑 |
| **只准备文生图岗面试** | Diffusion → SD架构 → 条件控制 → DiT → FlowMatching |
| **做可控生成或产品落地** | 条件控制 → 图像编辑 → SD架构(重点看开销账本那一节) |
| **做自回归 / 掩码生成方向** | 图像Tokenizer → VAE(第五节 VQ 一族)→ DiT |

## 四、边界速查:这几件事写在哪一篇

本子领域最容易找错的五处,分工都已写死:

| 你要找的 | 在这篇 | 别去这篇找 |
|---|---|---|
| 码本坍塌的成因、诊断与缓解 | **VAE**(根目录第五节) | 图像Tokenizer 只讲谱系与选型,机制一句话引过去 |
| adaLN-Zero 的具体写法与那组对照实验 | **DiT** | 条件控制 只做 FiLM / AdaIN / adaLN 的横向区分 |
| 空间对齐类条件(边缘、深度、姿态) | **条件控制** | DiT 只管全局标量条件那条赛道 |
| CFG 的机制、以及算力为什么翻倍 | **Diffusion** | SD架构 只报账,不讲原理 |
| inversion 与指令式编辑 | **图像编辑** | 条件控制 讲的是给新图加约束,不是改旧图 |

## 六、小节级索引:想找某一件事,直接翻到哪一节

**SD架构**

1. 三大件:各管一段,谁都不能少
2. 开销账本:算力和显存分别花在哪
3. 代际演进:SD 1.x → SDXL → SD3 三代各改了哪几处
4. 文本编码器:决定"听不听话"的那一件
5. 分辨率、负面提示与两种常见工程形态

**图像Tokenizer**

1. 离散还是连续:第一个岔路口
2. 四条量化路线:各自绕开什么
3. 码本怎么配:大小、维度、层数
4. 重建好不等于生成好
5. 语义 ID:同一套量化,换一个下游目标
6. tokenizer 反过来约束下游生成

**条件控制**

1. 条件的形态决定注入位置
2. 全局向量类:FiLM、AdaIN 与 adaLN 到底差在哪
3. 序列类:cross-attention 与图像提示
4. 空间对齐类:ControlNet 与轻量分支
5. 风格与主体:什么时候必须改权重
6. 多条件叠加:权重怎么配、会怎么打架

**图像编辑**

1. 编辑和从零生成的根本差别
2. inversion:把真图搬回噪声这条线
3. 注意力操控:为什么改注意力就能定点改内容
4. 指令式编辑:把编辑变成一次条件生成
5. 掩码式局部重绘与边界融合
6. 编辑强度与保真度:一根旋钮和怎么评测它
