# 视频生成 · 总览

一句话:这是本子领域 **4 篇的导航页**——只回答"我该读哪篇、按什么顺序读",**不讲任何原理**。视频生成不是另起炉灶,而是在图像那套东西上**再压一根时间轴**;所以先读图像侧,再读这里,四篇的分工才立得住。

## 一、前置:根目录四篇,再加图像生成

| 层 | 读什么 | 为什么绕不过去 |
|---|---|---|
| 共用范式(根目录) | **Diffusion** · **VAE** · **DiT** · **FlowMatching** | 加噪去噪、潜空间、Transformer 骨干、流匹配——视频侧一样都没换,只是多了一维 |
| 图像子领域 | **SD架构** · **条件控制** | 视频模型的装配方式和条件注入手段,基本是图像那一套的时间维扩写 |

最短前置路径:**Diffusion → VAE → DiT → SD架构**。这四篇读完再进本目录,否则每一篇都会卡在"这个词是什么"上。

## 二、本子领域四篇:一根时间轴,切成四刀

时间轴带来的问题被切成四块,四篇各管一块,互不重讲:

| 篇 | 它管哪一块 | 它回答什么 |
|---|---|---|
| **视频扩散架构** | **整体架构、路线选型、成本账** | 时间维怎么进网络;扩散 / 自回归 / GAN 三条路线之争;推理成本的账本;显存墙与分块生成的算力账;评测为什么要两个指标一起看 |
| **时空注意力** | **注意力这一层** | 完整三维、分解时空、3D 窗口三种切法的形状与代价;时间轴方向决定能不能流式出帧;从图像模型"充气"时时间层插在哪、怎么初始化 |
| **视频VAE** | **时间维怎么压、压多少、压完怎么解** | 为什么不能逐帧套图像 VAE;三种时序压缩做法的形状账;因果 VAE 首帧为什么单独占一格;压缩率天花板;判别器必须看时间维;解码显存墙与分块接缝 |
| **长视频一致性** | **内容层** | "一致性"其实是身份/场景/光照/镜头四件事;漂移为什么随时长放大;把历史带过去的四条通道;接缝与多镜头;一致性分数必须和运动幅度一起看 |

读法建议按**数据流顺序**:视频VAE(先把 latent 压出来)→ 视频扩散架构(骨干怎么搭、成本怎么算)→ 时空注意力(骨干里最贵那一层怎么切)→ 长视频一致性(生成长了之后会坏在哪)。

## 三、按目标挑一条读法

| 你的目标 | 建议路径 |
|---|---|
| **第一次系统学视频生成** | 视频VAE → 视频扩散架构 → 时空注意力 → 长视频一致性 |
| **只准备视频生成岗面试** | 视频扩散架构(路线之争 + 成本账)→ 时空注意力 → 视频VAE |
| **做推理加速 / 成本优化** | 视频扩散架构第三、四节 → 时空注意力(实现坑与选型)→ 04-Infra 章的 FlashAttention、算子融合 |
| **做长片 / 多镜头产品** | 长视频一致性 → 视频扩散架构(分块、滑窗、队列三种形态) |

## 四、边界速查:最容易写重、也最容易找错的四处

四篇开篇都写死了自己的边界,冲突处按下表认:

| 你要找的 | 在这篇 | 别去这篇找 |
|---|---|---|
| 分块 / 滑窗 / 队列三种形态的**显存与算力账** | **视频扩散架构** | 长视频一致性 只管内容层,不算账 |
| 漂移、身份保持、镜头接缝这些**内容层**的坏法 | **长视频一致性** | 视频扩散架构 只给一句定位 |
| 注意力三种切法的形状、代价与实现坑 | **时空注意力** | 视频扩散架构 只说"时间维从哪一层进",不展开怎么切 |
| ELBO、重参数化、向量量化、STE、码本坍塌 | **VAE**(根目录) | 视频VAE 只用不重讲,它管的是时序压缩那一半 |

| 真题 | topic 第一段 | 备注 |

## 六、小节级索引:想找某一件事,直接翻到哪一节

**视频扩散架构**

1. 时间维怎么进网络
2. 三条路线之争:扩散 / 自回归 / GAN
3. 推理成本的账本
4. 显存墙与分块生成
5. 评测:两个必须一起看的指标

**时空注意力**

1. 先把形状摆清楚
2. 分解时空:两次小注意力
3. 3D 窗口与移位
4. 时间轴的方向:能不能流式出帧
5. 从图像模型充气:时间层插在哪、怎么初始化
6. 实现坑与选型

**视频VAE**

1. 为什么不能逐帧套一个图像 VAE
2. 时间维怎么压:三种做法与形状账
3. 因果视频 VAE:首帧为什么单独占一格
4. 压缩率的天花板:为什么不能往上顶
5. 训练目标与时间一致性:判别器必须看时间维
6. 解码显存墙、分块接缝与离散侧的额外约束

**长视频一致性**

1. "一致性"不是一件事
2. 漂移:误差为什么随时长放大
3. 记忆与条件:把历史带过去的四条通道
4. 接缝与多镜头
5. 评测:一致性分数必须和运动幅度一起看
