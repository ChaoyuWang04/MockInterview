# 多模态 · 总览

一句话:这是**全章 38 篇的分流页**——六个子领域各有自己的导航页,本篇只回答"我该去哪个子领域、哪些内容不在子领域里而在根目录",**不讲任何原理,也不重复各子领域总览已经说过的话**。

## 一、这一章怎么组织的

**根目录放跨子领域的东西,六个子领域按"理解 / 生成 / 交互"分。**

```
05-多模态/
├─ 生成范式(四篇,下面所有生成类子领域都建在它们之上)
│    VAE · Diffusion · FlowMatching · DiT
├─ 跨子领域系统(三篇,横跨多个模态的系统级问题)
│    多模态训练 · 多模态推理系统 · 多模态RAG
└─ 六个子领域(各含 00-总览)
     理解 → 01-视觉理解
     生成 → 02-图像生成 · 03-视频生成 · 04-音频 · 05-3D生成
     交互 → 06-世界模型
```

三点值得先说清:

- **根目录那四篇是地基,不是"杂项"**。图像、视频、3D、音频四个生成子领域都在用同一套扩散/流匹配机器,所以它们只讲一次,子领域一律引过去。**读任何一个生成子领域之前,先把 `Diffusion` 过一遍最省事。**
- **"交互"是第三类,不是生成的子集**。06-世界模型 要的不是"生成一段好看的东西",而是"生成一个**能响应我操作**的东西"——判据、指标、失败模式全换了一套。
- **每个子领域都有自己的 `00-总览`**,里面有该子领域的组织主线、边界速查、小节级索引。**本篇不重复那些内容**,只负责把你送到正确的子领域。

## 二、六个子领域,一句话各是什么

| 子领域 | 一句话 | 组织主线(详见各自总览) |
|---|---|---|
| **01-视觉理解** | 图怎么被模型看懂,并接进语言模型 | **一条流水线**:像素预处理 → 分辨率 → 编码器 → 接进 LLM,外加分割这条岔路 |
| **02-图像生成** | 图怎么被造出来、怎么被控制、怎么被改 | 架构 → 条件控制 → 编辑 → 离散化 |
| **03-视频生成** | 多了时间这一维之后,什么变了 | 架构与时空注意力 → 压缩 → 长时一致性 |
| **04-音频** | 声音怎么表示,以及识别与合成两个反向任务 | **一个地基 + 三个任务**:编解码是地基;识别是多对一、合成是一对多 |
| **05-3D生成** | 从照片重建,或从文本生成,再变成能用的资产 | **两道题 + 一道收口题**:重建(NeRF/3DGS)、生成(多视角扩散)、进管线(网格生成) |
| **06-世界模型** | 学一个能响应动作的环境 | **一个地基 + 一条路线 + 一个横切面** |

## 三、根目录七篇各是什么

| 篇 | 干什么 | 谁在用它 |
|---|---|---|
| **VAE** | 连续与离散(VQ)自编码;**码本坍塌的成因、诊断与缓解只在这里讲一次** | 图像生成、视频生成、音频编解码都引它 |
| **Diffusion** | 加噪去噪、采样器、CFG——生成侧的通用机器 | 图像 / 视频 / 3D / 音频四个生成子领域 |
| **FlowMatching** | 与扩散并列的另一条路径,少步数是它的卖点 | 同上 |
| **DiT** | 把扩散骨干换成 Transformer 之后带来了什么 | 图像生成、视频生成 |
| **多模态训练** | **训练侧**:图文数据治理、四种对齐目标、分阶段与冻结、系统瓶颈、分层评测 | 与 01-视觉理解 的 `VLM结构` 成对读 |
| **多模态推理系统** | 弱 VLM 与强文本模型**级联协同**:结构化证据、动态路由、定向复查 | 与 `多模态RAG` 成对读 |
| **多模态RAG** | 图文材料**怎么进库、怎么被检索出来** | 与 `多模态推理系统` 是一进一出的关系 |

> **最后三篇最容易互相搞混,记住这一刀**:`多模态训练` 讲**怎么把模型训出来**;`多模态RAG` 讲**材料怎么进库被检索**;`多模态推理系统` 讲**一次请求里两个模型怎么协同推理**。

## 四、按目标挑一条读法

| 你的目标 | 建议路径 |
|---|---|
| **第一次系统学多模态** | Diffusion(生成地基)→ 01-视觉理解(理解侧全貌)→ 02-图像生成 → 按兴趣挑其余子领域 |
| **准备多模态大模型岗面试** | **01-视觉理解 → 多模态训练 → 02-图像生成 → 03-视频生成**;这条覆盖全章 18 道真题里的绝大多数(见第五节) |
| **做 VLM / 图文问答产品** | 01-视觉理解 → 多模态训练 → 多模态RAG → 多模态推理系统 |
| **做生成类产品(图/视频/音/3D)** | VAE + Diffusion + FlowMatching + DiT 四篇打底,再进对应子领域 |
| **做具身 / 游戏 / 可交互环境** | 06-世界模型 → 03-视频生成(长时一致性)→ 05-3D生成 |
| **只想补某一块** | 直接进该子领域的 `00-总览`,那里有小节级索引 |

## 五、真题分布:全章 18 道,极不均匀

**这一节是本篇最该带走的信息。** 题库 `questions/` 是真题的唯一集合,全章的分布是这样的:

| 位置 | 真题数 |
|---|---|
| **01-视觉理解** | **8**(其中 `VLM结构` 一篇占 4) |
| 根目录 | 5(`Diffusion` `FlowMatching` `多模态训练` `多模态推理系统` `多模态RAG` 各 1) |
| **02-图像生成** | 3 |
| **03-视频生成** | 2 |
| **04-音频** | **0** |
| **05-3D生成** | **0** |
| **06-世界模型** | **0** |

两条直接结论:

1. **复习优先级按这张表排。** `VLM结构` 一篇就挂着 4 道真题,是全章考试重心;而音频、3D、世界模型三个子领域**加起来一道都没有**。
2. **零真题子领域的考点表全部是「补充题」**——按正文断言反推出来的问法,不是从真实面试采到的。它们按契约第九节的四条否决线筛过,但**没有真题可以校准问得准不准**,证据强度和有真题背书的篇目不是一回事。各子领域总览里都写明了这一点。

> 采到新真题后按 `docs/02-题库导入流程.md` 入库,再回对应专篇重做考点表——**真题优先,补充题让位**。
>
> 另有一条跨分类提醒:`VLM结构/后训练差异` 那道题收在题库的 `SFT` 分类下,只在 `多模态` 分类里翻会漏掉。

## 六、章级边界速查:这件事在根目录还是子领域

各子领域内部的边界见它们自己的总览,这里只列**根目录与子领域之间**最容易找错的七处:

| 你要找的 | 在这里 |
|---|---|
| 扩散过程、采样器、CFG 的机制本身 | 根目录 **Diffusion**(各子领域只讲用在自己这边的代价) |
| 向量量化、straight-through、**码本坍塌** | 根目录 **VAE**(音频 RVQ、图像 tokenizer 都引它) |
| 图文数据治理、对齐目标、分阶段与冻结的**训练侧** | 根目录 **多模态训练** |
| 连接器接法、视觉 token 预算、冻结的**结构侧** | 01-视觉理解 的 **VLM结构** |
| 音频表征谱系(波形 / 频谱 / 离散 token) | 04-音频 的 **音频编解码** |
| 3D 表示谱系(体素 / 点云 / 网格 / 隐式场) | 05-3D生成 的 **NeRF** |
| 世界模型三块结构、隐空间 rollout | 06-世界模型 的 **世界模型范式** |

> **一个跨子领域的重名陷阱**:02 章 `泛化与正则化` 里的 SAM 是 Sharpness-Aware Minimization(优化方法),和 01-视觉理解 `视觉分割与SAM` 里的 Segment Anything Model 毫无关系。
