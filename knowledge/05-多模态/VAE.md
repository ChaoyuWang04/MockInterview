# VAE(变分自编码器)

一句话:VAE 是给自编码器的瓶颈装上概率的那一步改造——编码器不再吐一个点,而是吐一个高斯分布,再用一项 KL 把这些分布往标准正态推,潜空间于是变得连续、可采样;而它在今天的生成栈里最重要的身份,是 Stable Diffusion 这类模型脚下那块把 512×512 像素压成 64×64 潜图的**地板**,扩散和流匹配都在这块地板上跑。

## 一、从自编码器到 VAE:瓶颈上为什么要装概率

普通自编码器(AE)只做一件事:编码器把 $x$ 压成向量 $z$,解码器再还原回 $x$,损失就是重建误差。它压缩很好用,但**不能生成**——原因很具体:训练只保证「训练集里那些点各自能还原」,潜空间里点与点之间的区域从没被约束过。你从里面随手采一个 $z$ 丢给解码器,大概率解出一团糊。

> **类比**:AE 学的是一本查号簿——每个训练样本占一个号码,号码之间的空号是什么它从没管过。VAE 要求把整片号段填满,随便拨一个都能通。

VAE 只改了两处,而这两处是同一件事的两面:**采样让同一张图对应潜空间里一小团区域而不是一个点**,把洞填上;**KL 让这些小团挤在一起铺满标准正态**,把形状定下来。缺任何一边,从先验采样都会落到没训过的地方。

| | 自编码器 AE | 变分自编码器 VAE |
|---|---|---|
| 编码器输出 | 一个确定的向量 $z$ | 一个高斯的 $\mu(x)$ 与 $\log\sigma^2(x)$ |
| 送进解码器的 | 就是那个向量 | 从该分布**采样**出来的 $z$ |
| 损失 | 只有重建误差 | 重建误差 + 把后验推向先验的 KL |
| 能不能生成 | 不能,潜空间有洞 | 能,从 $\mathcal{N}(0, I)$ 采样即可 |

## 二、ELBO:两项各自在干什么

要学的是 $p_\theta(x)=\int p_\theta(x\mid z)\,p(z)\,dz$。这个积分算不了,因为要遍历所有 $z$;真后验 $p_\theta(z\mid x)$ 同样算不了,它的分母就是那个积分。VAE 的办法是拿一个能算的 $q_\phi(z\mid x)$(就是编码器)去近似真后验,再优化一个下界:

$$
\mathcal{L}_{\text{ELBO}} = \mathbb{E}_{q_\phi(z\mid x)}\big[\log p_\theta(x\mid z)\big] - D_{\mathrm{KL}}\big(q_\phi(z\mid x)\,\|\,p(z)\big)
$$

读法:第一项是「按编码器给的分布采 $z$,解码器能把原图还原得多准」,即**重建项**;第二项是「编码器给的这团高斯离标准正态有多远」,即**正则项**。最大化 ELBO = 重建要准 + 潜分布要规整。

### 下界从哪来:差的那一截恰好是后验 KL

$$
\log p_\theta(x) - \mathcal{L}_{\text{ELBO}} = D_{\mathrm{KL}}\big(q_\phi(z\mid x)\,\|\,p_\theta(z\mid x)\big) \ge 0
$$

这行是整套方法的支点:**真实对数似然和 ELBO 之间差的那一截,正好等于「你的近似后验」与「真后验」的 KL**。因为 KL 非负,ELBO 一定是下界;又因为差值恰好是这个 KL,把 ELBO 顶上去等于同时干两件事——抬高似然、把近似后验推近真后验。一箭双雕不是巧合,是这个恒等式给的。

**换成别的度量还保留下界吗?不保留。** 下界性来自「gap 恰好等于一个非负 KL」这条恒等式,不是来自「加了个正则项」。把 KL 换成 JS 或 Wasserstein,右边不再等于任何 gap,「$\log p_\theta(x)$ 不小于目标」这条关系就断了;那类目标要各自重新推导,不能默认继承 ELBO 的解释。

### 高斯先验下的闭式 KL,以及两项怎么打架

先验取 $\mathcal{N}(0,I)$、后验取对角高斯时:

$$
D_{\mathrm{KL}} = \frac{1}{2}\sum_{j=1}^{d}\left(\mu_j^2 + \sigma_j^2 - \log \sigma_j^2 - 1\right)
$$

逐维读:$\mu_j^2$ 罚「均值偏离原点」;$\sigma_j^2-\log\sigma_j^2-1$ 罚「方差偏离 1」,它在 $\sigma_j=1$ 处取到唯一最小值 0。所以 KL 项的诉求很直白——**每一维都长得像标准正态**。工程上网络回归 $\log\sigma^2$ 而不是 $\sigma$:前者取值在整个实轴上,不用额外约束正性,数值也稳。

两项的诉求正好相反:重建项希望每张图的后验又窄又互相离得开(信息多、不混淆),KL 项希望它们都回到方差 1 并挤向原点。重建项单独赢 → 退化成普通 AE,先验采样出垃圾;KL 项单独赢 → 后验坍塌,$z$ 变成纯噪声。**VAE 的调参基本都是在这条对抗线上选位置**,旋钮就是 KL 的权重。

## 三、重参数化:不这么写,梯度就断在采样那一步

重建项要对 $z\sim q_\phi(z\mid x)$ 求期望,实际做法是采一个 $z$ 算一次。麻烦在于:**「采样」这个动作对 $\mu$、$\sigma$ 没有导数**——采样器吐出的是一个随机数,反向传播走到这里就断了,编码器拿不到任何梯度。

重参数化技巧(reparameterization trick)把随机性挪个位置:

$$
z = \mu_\phi(x) + \sigma_\phi(x) \odot \epsilon, \qquad \epsilon \sim \mathcal{N}(0, I)
$$

读法:先摇一个**和网络参数完全无关**的标准正态噪声 $\epsilon$,再用网络输出的 $\mu$、$\sigma$ 把它平移缩放。于是 $z$ 成了 $\mu$、$\sigma$ 的一个**确定的、可导的**函数,随机性被赶到计算图之外的叶子节点上,梯度可以一路穿回编码器。类比一下:原来是「机器随机发一张彩票给你」,梯度不知道该怪谁;现在改成「先公开摇一个号,你的参数决定把这个号加多少、乘多少」,谁贡献了多少一目了然。

不用它行不行?理论上可以改用 score function(REINFORCE)估计器,它只利用「样本的概率」而不利用「样本怎么由参数生成」,**方差高出一大截**,高维潜空间上基本训不动。这正是 Auto-Encoding Variational Bayes 那篇的核心贡献之一:把一个需要方差缩减技巧才跑得动的估计器,换成了直接反传就行的。

```python
mu, logvar = encoder(x)                                   # 回归 log 方差,免去正性约束
z = mu + (0.5 * logvar).exp() * torch.randn_like(mu)      # 重参数化:随机性只在 randn 里
rec = F.mse_loss(decoder(z), x, reduction="sum")          # 对应高斯似然的重建项
kl = 0.5 * (mu.pow(2) + logvar.exp() - logvar - 1).sum()  # 闭式 KL
loss = rec + beta * kl                                    # beta 就是下一节那个旋钮
```

## 四、两个经典失败:后验坍塌与「生成糊」

### 后验坍塌:模型学会了忽略 $z$

现象是 KL 项掉到接近 0,$q_\phi(z\mid x)$ 对任何输入都退化成先验本身——**潜变量不携带任何关于输入的信息**,解码器自己单干。

**为什么会发生?** 因为这确实是 ELBO 的一个合法解,不是 bug。当解码器足够强(典型是自回归解码器:文本 LSTM、PixelCNN),它不看 $z$ 也能把 $x$ 编得八九不离十,重建项损失不了多少;而 KL 项对「忽略 $z$」这件事是明码奖励的,一分不少。两边一权衡,模型就把潜变量扔了。训练早期尤其危险:那时解码器还没学会用 $z$,KL 却已经在压,一旦压死就再起不来。解法都落在「早期别压太狠」或者「削弱解码器」这两侧,前三行加起来正是 Generating Sentences from a Continuous Space 处理文本 VAE 的配方:

| 手段 | 做什么 | 代价 |
|---|---|---|
| KL 退火(warm-up) | KL 权重从 0 线性升到 1,先让重建学会用 $z$ | 多一个调度超参;升太快照样坍 |
| free bits | 每维 KL 低于阈值就不再罚,给每一维保底留一点信息 | 阈值给大了潜空间不再规整 |
| 削弱解码器 | 文本上做 word dropout,逼它去 $z$ 里找线索 | 重建能力下降 |
| 换离散潜变量 | 走 VQ-VAE,KL 项直接变成常数(第五节) | 换来码本坍塌这个新问题 |

KL 权重 $\beta$ 这个旋钮的两个方向:$\beta > 1$ 潜空间更规整、各维更接近独立(β-VAE 的解耦表示靠的就是这个),代价是**重建更糊**,信息被 KL 挤掉了;$\beta < 1$ 重建更清晰,但潜空间越来越像普通 AE,**从先验直接采样的质量会垮**。latent diffusion 用的是一个**很小**的 $\beta$,因为那块地板压根不负责从先验采样(第六节)。

### VAE 生成的图为什么糊

两层原因,都和「换个更大的解码器」无关。其一,**重建项等价于逐像素 MSE**:给定同一个 $z$,现实中有很多张同样合理的 $x$(边缘挪一个像素、纹理换个相位都算),而 MSE 的最优解是**这些可能性的平均**,平均出来就是低通滤波的效果——边缘发虚、高频纹理消失。这是损失的选择决定的,不是容量不够。其二,**KL 逼后验向先验靠,本身就在扔信息**,先被扔掉的正是最难压的高频细节。

真正的修法是**换重建目标**:把「像不像」从逐像素改成特征级(感知损失,用预训练网络的特征比对)加判别器级(patch 对抗损失)。VQGAN 就是这么干的,论文明确说这两项是为了在更高压缩率下保住感知质量。今天所有生产级的 latent 自编码器都带这两项——所以别把「VAE 出图糊」直接套到 SD 的 VAE 上,它早已不是纯 ELBO 训出来的了。

## 五、VQ-VAE 一族:把潜变量换成离散码本

要离散有两个理由。一是**接口**:自回归 Transformer 吃的是离散 token,要让它建模图像,得先有一本「视觉词表」。二是**顺手绕开后验坍塌**:VQ-VAE 的后验是确定性的 one-hot,先验取码本上的均匀分布,于是 KL 恒等于 $\log K$ 这个常数,那个奖励「忽略 $z$」的项直接从优化目标里消失了。论文原话是它 circumvent 了 posterior collapse。

**这也是 VQ-VAE 与普通 VAE 隐变量的本质区别**,一张表说清。注意最后一行:**两者的失败模式不重叠**,离散化不是免费午餐,它把一个问题换成了另一个问题。

| | 普通 VAE | VQ-VAE |
|---|---|---|
| 潜变量 | 连续向量,对角高斯后验 | 码本索引,$K$ 选 1 的离散码 |
| 后验 | 随机,有方差 | 确定性,取最近邻 |
| 先验 | 固定 $\mathcal{N}(0,I)$ | 均匀;事后另训一个自回归先验 |
| KL 项 | 可变,是主要正则 | 常数 $\log K$,不参与优化 |
| 梯度怎么过瓶颈 | 重参数化,严格 | 直通估计(STE),近似 |
| 典型病 | 后验坍塌、出图糊 | 码本坍塌、死码 |

### 量化、三项损失,以及 STE 为什么不是严格求导

编码器输出 $z_e(x)$,在码本 $\{e_j\}_{j=1}^{K}$ 里找最近的一个:

$$
k = \arg\min_j \lVert z_e(x) - e_j \rVert_2^2, \qquad z_q(x) = e_k
$$

就是一次最近邻查表:把连续向量替换成码本里离它最近的那个条目,解码器只看 $z_q$。VQ-VAE 论文在 ImageNet 上的口径是 128×128×3 的图压到 32×32 的码图、$K=512$,按比特算约 **42.6 倍**压缩。

$$
\mathcal{L} = \lVert x-\hat{x}\rVert^2 + \lVert \mathrm{sg}[z_e(x)] - e \rVert_2^2 + \beta\,\lVert z_e(x) - \mathrm{sg}[e] \rVert_2^2
$$

$\mathrm{sg}[\cdot]$ 是 stop-gradient,它决定每一项只更新谁:重建项管画质;中间的**码本项只更新码本**,把被选中的码往编码器输出那边拉;最后的**承诺项只更新编码器**,罚它离选中的码太远,免得编码器四处乱跑、码本追不上。论文取 $\beta=0.25$,并说 0.1–2.0 之间结果没什么变化。这两项的方向或权重写反,训练就会失衡——这是码本坍塌最常见的诱因之一。

$\arg\min$ 挡在中间,梯度靠 STE 硬穿过去:

| 方向 | 走的是什么路 |
|---|---|
| 前向 | $z_e$ → 最近邻查表 → $z_q$ → 解码器,老实量化 |
| 反向 | 解码器输入处的梯度 $\partial\mathcal{L}/\partial z_q$ **原封不动拷到** $z_e$,把量化当成恒等映射 |

**为什么不是严格求导?** 因为 $\arg\min$ 是一个**分片常数**函数:$z_e$ 在同一个码的邻域里怎么动,$z_q$ 都不变,真导数处处为 0;跨过邻域边界时又是跳变,导数不存在。真梯度要么是 0(什么都学不到)、要么没定义,STE 用「恒等」这个假雅可比替换掉它,是一个**有偏**近似,只在量化误差足够小时才接近真实。两个后果:承诺项必须存在,把 $z_e$ 拴在码附近,这个近似才站得住;**码本本身拿不到 STE 传来的梯度**,它在拷贝路径之外,只能靠码本项或 EMA 单独更新。EMA 版本用 $\gamma=0.99$ 的滑动平均做在线 k-means,比梯度更新稳。

### 码本坍塌:一个名字下的三种病

编码器只在少数几个码上打转,大量码长期得不到训练。但 **「用过多少码」这一个数字盖住了三种不同的毛病**,诊断时必须拆开:

| 症状 | 表现 | 主要成因 |
|---|---|---|
| 死码 | 一部分码从头到尾没被选中过 | 初始化就离编码器输出很远,首轮没中 → 拿不到梯度 → 永远不动,**自我强化** |
| 利用率失衡 | 码都在用,但少数码吃掉绝大部分命中 | 编码器输出分布本就长尾;或承诺权重过小,编码器漂移太快 |
| 表示坍塌 | 不同输入被映射到近乎同一个码 | 编码器容量不足、重建目标太弱,潜表示本身没信息 |

还有一条结构性的:**码本越大越容易坍塌**。同样多的训练样本要摊到更多码上,人均命中次数下降,长尾更容易饿死。RQ-VAE 论文正是拿这一点当动机——想把空间分辨率再降一半又不掉重建,VQ 得把码本撑到 $K^4$ 量级,而那个尺寸下坍塌会让训练直接不稳。

### 怎么监控:三层一起看,别只报一个利用率

- **码本侧**:活跃码比例、命中频率直方图、使用分布的熵或 perplexity、每个码**连续未命中的步数**(死码就是这一项一直涨的那些)。
- **重建侧**:重建 MSE/PSNR、感知指标(LPIPS)、rFID。码本统计好看但重建变差,说明是表示坍塌而不是死码。
- **下游侧**:用这个 tokenizer 训出来的生成模型的最终指标。**这一层才是验收口径**,前两层只是定位手段。

两条口径不能混:多层残差结构要**逐层统计**,把各层混在一起算一个利用率会把深层的问题盖掉;视频要**空间纹理与时间变化分开看**(时空压缩的细节见 视频VAE 篇)。

> 🖼️ 占位:训练中码使用频率直方图的演化,健康 / 死码堆积 / 少数码独占三种形态对照,配同期 rFID 曲线

### 怎么缓解,每种手段的副作用是什么

| 手段 | 做什么 | 副作用 |
|---|---|---|
| 数据 / k-means 初始化 | 用真实编码器输出初始化码本,保证一开始就落在数据附近 | 得先跑一段 warm-up 才有样本可用 |
| EMA 更新 | 用滑动平均做在线 k-means,替代码本项的梯度 | 衰减系数不当会跟不上编码器漂移 |
| 死码重启 | 把长期未命中的码重置到某个高频样本附近(Jukebox 的做法) | **重启太频繁会让表示反复震荡**,下游前后不一致 |
| 低维查表 + $\ell_2$ 归一化 | 查表放到低维空间做再投回去;码与编码输出都归一化,最近邻退化成余弦相似度 | 查表维度成了新超参 |
| 熵 / 均衡正则 | 显式鼓励使用分布均匀 | **强行拉平会伤害本就长尾的自然数据分布** |
| 调承诺权重 $\beta$ | 控制编码器允许漂多远 | 太大编码器被锁死,太小码本追不上 |
| 扩容编码器 / 解码器 | 表示坍塌的对症手段:潜表示本身没信息时,怎么调码本都没用 | 训练与推理成本一起涨 |

第四条是 ViT-VQGAN 的核心改动:把码向量从 768 维投到 32 维(或 8 维)再查表,配 $\ell_2$ 归一化,**8192 大小的码本利用率做到约 95%–96%**,远高于同期原版 VQGAN 的大码本。另一条思路是干脆不要显式码本——FSQ 把每一维量化到少数固定标量,论文自报不出现传统意义的码本坍塌,也不需要承诺损失、码重置这一整套机械。这类量化器的全谱系与选型见 图像Tokenizer 篇,本篇只讲 VQ 家族自己的机制。

三个参数怎么定:**码本大小 $K$** 定的是码率上限,别孤立地调大——利用率本来就不高时,加大 $K$ 只是多养一批死码,判据是固定码率下的重建与下游指标;**死码重启频率**要低到不打断收敛、高到不留永久死码,按「连续未命中步数」的分布定阈值,别按固定轮数硬拍;**残差层数 $D$** 看逐层残差能量,某一层之后残差已经很小、重建和下游指标不再改善,那层就只是白白拉长序列。

### 多层残差量化(RQ)会怎样改变这个问题

机制:第一层量化 $z_e$,第二层量化**第一层的残差**,依次叠 $D$ 层,各层**共享同一个码本**。共享的理由论文写得很明白——省掉逐层码本大小的超参搜索,而且让每个码在每一层都能被用上,单个码的利用率更高。$D$ 层深度最多能把空间划成 $K^D$ 个簇,**表达力对标 $K^D$ 大小的 VQ 码本,而码本实际只有 $K$ 那么大**。RQ-VAE 在 256×256 ImageNet 上的公开配置是 $K=16384$、$D=4$,得到 8×8×4 的码图。

对坍塌是双向的。**缓解**的一面:要同样的表达力不必把 $K$ 撑到指数级,而大码本正是坍塌的高发区;共享码本又让每个码有 $D$ 次被选中的机会。**加剧、或者说变复杂**的一面:深层量化的是能量越来越小的残差,各层使用分布天然就不一样,深层容易退化成只在少数码上做微调——所以必须逐层诊断,拿一个总体利用率交差等于没查,RQ-VAE 自己也仍然要用 EMA 加死码随机重启。顺带澄清一个流传的说法:「RQ 配 k-means 保证 100% 码本利用率」没有通用的一手依据,聚类频率、层数、码本大小都得在具体数据和码率预算下实测。

### VQGAN 与 RQ-VAE 的码本设计差在哪

| | VQGAN | RQ-VAE |
|---|---|---|
| 量化结构 | 单层 VQ,一个位置一个码 | $D$ 层残差量化,一个位置一叠码 |
| 码本 | 单码本,ImageNet 上用 1024,类条件合成用到 16384 | 单个**共享**码本跨 $D$ 层复用,$K=16384$ |
| 靠什么缩短序列 | 提高空间下采样率($f=16$),用**感知损失 + patch 判别器**顶住画质 | 码本和分辨率倍率都不动,**加深度**,256×256 直接压到 8×8 |
| 主要压力 | 高压缩率下的重建保真 | 逐层残差的利用率均衡 |

一句话记法:**VQGAN 用更好的损失换压缩率,RQ-VAE 用更多层数换码本大小**。两者不冲突,RQ-VAE 的自编码器同样带对抗与感知损失。

## 六、latent diffusion 脚下的那块地板

这块地板只在两端各出现一次:训练时编码器把图像压成潜图,扩散全程在潜空间跑;推理最后一步由解码器把潜图还原成像素(省了多少算力、$f$ 怎么选,见 Diffusion 篇;训练目标那一层见 FlowMatching 篇,骨干见 DiT 篇)。SD 1.x 这代的配置是下采样 8 倍、4 个潜通道,$512\times512\times3=786{,}432$ 个数压成 $64\times64\times4=16{,}384$ 个数,**少 48 倍**。

LDM 给了两种正则:**KL-reg**(往标准正态施加一点很轻的 KL 惩罚)和 **VQ-reg**(在解码器里放一个向量量化层)。KL 之所以能开得极小,是因为这块地板不负责生成——不需要从先验直接采样,只要潜空间的数值尺度不失控就行,规整性交给后面的扩散模型。一个反直觉但很有用的观察:LDM 论文报告,**VQ 正则的一阶段模型重建略差,但在它的潜空间上训出来的扩散模型采样质量有时反而更好**。所以「重建更好 = 生成更好」并不成立,选型要连着下游一起测。

### 重建上限:天花板卡在这里

解码器还原不出来的东西,扩散模型再强也补不回来——**这是整条链路的硬上限**。LDM 原文自己承认:需要像素级精度的任务上,重建能力会成为瓶颈。实践中最常见的三类受害者是小字、密集重复纹理、远景小人脸,它们的高频信息在编码那一步就已经丢了。所以排查生成质量问题时第一步应该是**把真图过一遍编码再解码看重建**:重建就已经糊的,别再去调采样器和提示词。

### 通道数是新的旋钮

近两代模型的主要改动不在下采样倍率,而在潜通道数。SD3 系统比过 4 / 8 / 16 通道,并进一步验证 16 通道在下游扩散训练上的 scaling 更好,于是这一代整体改用 16 通道:

| 潜通道数 | 重建 FID | PSNR |
|---|---|---|
| 4 | 2.41 | 25.12 |
| 8 | 1.56 | 26.40 |
| 16 | **1.06** | **28.62** |

代价要说清:空间尺寸没变,所以 DiT 的序列长度不变,**涨的是每个位置的通道数、VAE 自身的算力与显存,以及潜空间的信息密度**——每个潜向量更难被拟合,小模型上未必占便宜,SD3 的收益也正是在模型放大时才明显。这同时解释了「换 VAE 就得重训扩散模型」:潜空间的定义变了,旧权重全部作废。验收一块地板要固定分辨率和数据集,同时报 rFID、PSNR、SSIM、LPIPS——只看 PSNR 会偏袒糊的重建,只看 rFID 又对结构错位不敏感。
