# 世界模型 · 总览

一句话:这是本子领域 **3 篇的导航页**——只回答"我该读哪篇、按什么顺序读",**不讲任何原理**。这三篇不是三个并列话题,而是**一个概念地基、一条具体路线,加一个横切两者的关切**。

## 一、地基、路线、横切面

| | 篇 | 它回答什么 |
|---|---|---|
| **地基** | **世界模型范式** | 什么是世界模型、由哪几块组成、为什么要在想象里训练 |
| **路线** | **视频世界模型** | 拿一个视频生成模型当可交互环境用,会撞上哪些新问题 |
| **横切面** | **动作条件与交互** | 动作这个条件有什么特殊——**上面两篇都需要它,但都不讲它** |

### 两篇的分歧就一句话:状态存在哪

这是本子领域最有用的一把钥匙。两篇讲的是同一个目标——**学一个能预测"我这么做之后世界会怎样"的模型**——但**状态的载体完全不同**:

| | 世界模型范式(Dreamer 一系) | 视频世界模型(Genie / GameNGen 一系) |
|---|---|---|
| 状态是什么 | **隐向量**,几百维 | **画面本身**,就是那一帧 |
| 谁来看结果 | 策略网络(为了决策) | 人(为了玩) |
| 一步的产出 | 下一个隐状态 + 奖励 | 下一帧像素 |
| 优化的是 | **样本效率**——少在真实环境里试错 | **实时性与可玩性**——闭环要够快 |
| 主要失败模式 | 复合误差、模型利用 | 不响应动作、走回头路场景变了 |

`世界模型范式` 篇专门论证过**为什么想象要发生在隐空间**(算力、误差、接口三笔账),并把"把画面本身当状态"这条路明确交给了 `视频世界模型`。所以两篇不是新旧关系,**是同一件事的两种取舍**:隐空间省算力但漂了没人发现,像素空间人能直接看但每帧都贵。

### 为什么动作要单独一篇

因为两篇都要用它,但**动作是所有条件里最难伺候的一个**:每步换一个新值、维度低到只有几个数、而且必须被当场遵守。这三条性质决定了它怎么编码、从哪一层进网络、错了会怎么被放大——内容多到塞进任何一篇都会喧宾夺主,所以两篇都写了同一句交割语,把它整条让了出来。

## 二、三篇各回答什么

| 篇 | 它回答什么 | 一句话定位 |
|---|---|---|
| **世界模型范式** | 学出来的环境模拟器;表征+动力学+奖励头三块;RSSM 为什么把隐状态拆成确定性与随机性两半;想象为什么在隐空间;预测准≠有用、复合误差、模型利用 | **只会预测画面的是生成模型,不是世界模型**——差的是那个奖励头 |
| **视频世界模型** | 因果性与实时性两条硬约束;Genie 的潜在动作(无标注学可控性)vs GameNGen 的实时模拟;可回访一致性;帧率预算与 NFE;评测的三种刷分姿势 | 闭环闭得够快才叫环境,**闭不上就还是视频** |
| **动作条件与交互** | 动作空间三形态与分桶;四个注入位置的取舍;延迟的真正代价是错位不是慢;闭环误差放大;反事实可控性评测;与 VLA 策略的衔接 | **开环漂移是看起来不对,闭环漂移是看起来对但对不上** |

## 三、按目标挑一条读法

| 你的目标 | 建议路径 |
|---|---|
| **第一次系统学世界模型** | 世界模型范式 → 视频世界模型 → 动作条件与交互 |
| **做可玩的生成式环境 / AI 游戏** | 视频世界模型 → 动作条件与交互,概念不懂时回头翻 世界模型范式 |
| **做具身智能 / 机器人策略** | 世界模型范式 → 动作条件与交互(第五节直接讲和 VLA 的衔接) |
| **只想搞清楚"世界模型到底是什么"** | 世界模型范式 一篇即可 |
| **准备多模态岗面试** | 三篇都读;`世界模型范式` 的失败模式和 `动作条件与交互` 的开闭环对照是最容易被追问的两处 |

## 四、边界速查:这几件事写在哪一篇

三篇互相声明过边界,最容易找错的六处:

| 你要找的 | 在这篇 | 别去这篇找 |
|---|---|---|
| 表征+动力学+奖励三块、RSSM、隐空间 rollout、想象中训练 | **世界模型范式** | 另外两篇只有一句定位 |
| **复合误差**(开环:只有状态在漂) | **世界模型范式** | 容易和下面一行搞混 |
| **闭环误差放大**(状态和动作一起漂) | **动作条件与交互** | 两者的分界:动作是外生给定,还是由已经偏了的画面反过来选出来 |
| Genie / GameNGen、可回访一致性、帧率预算与 NFE、KV 缓存 | **视频世界模型** | 动作条件与交互 只讲**语义层面**的延迟,算力账在那边 |
| 动作空间表示、注入到哪一层、可控性评测 | **动作条件与交互** | 另外两篇都把这整条让了出来 |
| MDP 要素、DQN / actor-critic / SAC、探索策略 | 03 章 **强化学习基础** | 世界模型范式 只说"它就是 model-based RL 里的那个 model" |

> **两处一句话就能切开的对照**:
> ① **可回访一致性 vs 长视频漂移** —— 前者是玩家可随时转身对质的**离散对错判定**,后者是观众看不到正确答案的**缓慢单向劣化**(见 03-视频生成 的 `长视频一致性` 篇)。
> ② **世界模型 vs 策略** —— 动作在两边的身份**正好反过来**:世界模型拿它当输入(条件),策略拿它当输出(要预测的东西)。

## 六、小节级索引:想找某一件事,直接翻到哪一节

**世界模型范式**

1. 它解决的是什么问题
2. 三块结构:表征、动力学、奖励头
3. 为什么想象要发生在隐空间
4. 评价与失败模式

**视频世界模型**

1. 从"一段视频"到"一个环境":三条硬约束
2. 两条代表路线:Genie 和 GameNGen 解决的不是同一个问题
3. 可回访一致性:视频世界模型独有的那个坑
4. 算力账:为什么扩散在这里天然吃亏
5. 评测:画面好看只是及格线

**动作条件与交互**

1. 动作是个什么样的条件
2. 注入到哪一层
3. 闭环里的延迟与误差
4. 可控性怎么评
5. 和具身策略学习的衔接
