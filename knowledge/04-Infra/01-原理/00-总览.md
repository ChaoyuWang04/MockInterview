# Infra 原理 · 总览

一句话:这是本章 **29 篇的导航页**——只回答"我该读哪篇、按什么顺序读",**不讲任何原理**。想知道"手段之间怎么组合、按什么顺序上线",那是 推理加速 篇(串讲篇)的活;两篇分工不同,别搞混。

🔴 只表示当前复习重点,不表达来源或题目真实性。各专篇文末的「面试考点串联」负责把题库问法与正文位置对齐。

## 一、按依赖顺序读:六组 29 篇

### 硬件地基(2 篇)——所有结论的物理来源

| 篇 | 它回答什么 |
|---|---|
| 🔴 **GPU架构与执行模型** | 一张卡里面:SIMT、warp、内存层级、Tensor Core、occupancy。**本章地基,先读它** |
| 🔴 GPU互联与组网 | 出了这张卡:NVLink / NVSwitch / PCIe / RDMA 的带宽层级、零拷贝、多机 topo |

### 分析方法(3 篇)——先学会量,再谈优化

| 篇 | 它回答什么 |
|---|---|
| 🔴 Roofline与Bound分析 | 这个算子是被算力卡住还是被带宽卡住?算术强度与拐点怎么算 |
| 🔴 性能分析与Profiling | Nsight Systems / Nsight Compute / torch.profiler 各管什么,trace 怎么看 |
| 🔴 显存管理与OOM | 显存这本账怎么列,缓存分配器与碎片,OOM 从哪查起 |

### kernel 优化(4 篇)——单个算子怎么写快

| 篇 | 它回答什么 |
|---|---|
| 🔴 访存与算子优化 | 切块、合并访存、bank conflict、warp reduce、循环展开的技巧清单与代价 |
| 🔴 GEMM优化 | 分块怎么放大算术强度,调参空间有哪些 |
| 🔴 算子融合 | 为什么融合只对访存受限的算子有用,什么能融什么不能 |
| 🔴 CUDA流与异步执行 | stream 怎么并行、同步点的危害、pinned memory、传输与计算重叠 |

### 推理机制(11 篇)——一个请求从进来到吐完,途中的每一个机制

阅读顺序建议按下表从上往下,它大致就是数据流的顺序:

| 篇 | 它回答什么 |
|---|---|
| 🔴 KVCache | 为什么要缓存、形状与显存账、为什么它是 decode 的带宽瓶颈 |
| Prefill与Decode的矩阵形状 | 两阶段的激活形状差在哪,为什么一个计算受限一个访存受限(定量版) |
| 🔴 FlashAttention | 不让注意力矩阵落显存:分块 + online softmax |
| 🔴 PagedAttention | 把 KV 切成小块散着放,消灭碎片、支持共享 |
| RadixAttention | 用基数树跨请求自动复用前缀,省的是 prefill |
| 🔴 连续批处理 | 调度粒度细到每个 decode step;chunked prefill;数值不确定性 |
| 🔴 PD分离 | 两阶段拆到不同机器,KV 怎么传 |
| 🔴 投机解码 | 小模型猜、大模型验;接受率与加速比;KV 回退与 d2h 同步 |
| 🔴 CudaGraph | 消除 kernel 下发开销;动态性的边界;图专属显存池 |
| TorchCompile | 从字节码抓图、自动融合;graph break 与动态形状 |
| 🔴 推理服务指标 | TTFT / TPOT / ITL / 吞吐怎么定义,耗时各花在哪 |
| 解码策略 | 温度、top-k / top-p / min-p、惩罚项;一步解码的流水线 |

### 量化(3 篇)——按"先通用、再算法、再 KV"读

| 篇 | 它回答什么 |
|---|---|
| 🔴 **量化** | 通用原理:公式、粒度与 scale shape、动态/静态、PTQ/QAT、数据类型谱系 |
| 🔴 权重与激活量化 | 激活离群值,以及 LLM.int8() / SmoothQuant / GPTQ / AWQ / 旋转类 |
| 🔴 KVCache量化 | K 与 V 为什么分开量化、算子怎么改、CUDA Graph 与 TP 下怎么取参数 |

### 分布式(4 篇)——多卡之后的世界

| 篇 | 它回答什么 |
|---|---|
| 🔴 **并行策略** | DP/TP/PP/EP/SP/CP 各切什么、通信算子与通信量、哪些能跨机、并行度怎么分配 |
| 🔴 集合通信 | AllReduce 等算子的语义、Ring vs Tree、算法带宽 vs 总线带宽、overlap |
| 🔴 MoE并行与DeepEP | dispatch/combine 四种方案、EP 怎么切、负载不均衡 |
| ZeRO | DP 维的显存瘦身:三个 Stage 切什么、通信为什么涨到 1.5 倍 |
