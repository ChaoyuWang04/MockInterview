# Infra 框架与引擎 · 总览

一句话:这是本章 **12 篇的导航页**——只回答"我该读哪篇",**不讲任何原理**。本章的分工是**只讲工程与用法**:机制原理一律在 `01-原理` 章(那 30 篇已全部成文),算法在 `03-强化学习` 章,源码细节在开源解读模块。

> **本章所有文章都有时效**。它们对照的是 `projects/` 下的源码快照(约 2026-04)与当时的官方文档,各篇文末与正文都标了口径。框架演进极快,**任何"我记得它是这样"的说法,上线前都该拿自己那个版本核一遍**。

## 一、按用途分四组

### 推理引擎(3 篇)

| 篇 | 它回答什么 |
|---|---|
| 🔴 **vLLM** | 一个请求从进来到吐完 token 经历了什么;架构分层、调度器、前缀缓存、CUDA Graph 怎么配 |
| SGLang | 前端语言 + 后端运行时的双重身份;RadixAttention 在引擎里怎么落地、结构化输出怎么做 |
| 推理引擎对比 | **选型篇**:主流引擎哪些已经趋同、真正的分野在哪几条线上、给定负载该选谁 |

### 训练框架(3 篇)

| 篇 | 它回答什么 |
|---|---|
| Megatron | Megatron-LM 与 Megatron-Core 的分别;并行度怎么配与那些约束;checkpoint 换并行度的坑 |
| DeepSpeed | 非侵入式接入;一份 JSON 配置管什么;配置与代码谁优先 |
| FSDP | PyTorch 原生分片;FSDP1/FSDP2 的分片表示差异;wrap 粒度怎么定 |

### RL 训练框架(5 篇)

先读 **RL框架对比** 建立全局,再按需读单篇:

| 篇 | 它回答什么 |
|---|---|
| RL框架对比 | **选型篇**:所有 RL 框架都要解决的同一组难题、各家的不同选择、场景决策表 |
| verl | 编排型框架:训练与推理引擎一个都不造,造的是把两者接到同一条数据流上的胶水 |
| slime | 反抽象路线:只绑 Megatron + SGLang,参数直接透传给上游 |
| ROLL | 角色化资源编排:每类活做成一个能单独分卡的角色,用一份资源清单摆到集群 |
| OpenRLHF | 把 RLHF 三阶段打包成开箱即用、可复现的实现;Ray 做角色放置 |

### 通信库(1 篇)

| 篇 | 它回答什么 |
|---|---|
| NCCL | 拓扑探测与算法自选、关键环境变量、nccl-tests 怎么读、多机排障清单 |

## 二、三条读法

| 你的目标 | 建议路径 |
|---|---|
| **准备推理岗面试** | vLLM → SGLang → 推理引擎对比(机制原理先读完 `01-原理` 章的推理机制那一组) |
| **准备训练/分布式岗** | Megatron → FSDP → DeepSpeed → NCCL(原理先读 并行策略 与 ZeRO) |
| **准备 RL / 后训练岗** | RL框架对比 → verl → slime / ROLL / OpenRLHF 按需(算法先读 `03-强化学习` 章) |

## 三、本章与别处的边界

这一章最容易和别处写重,分工写死如下:

| 你想找的 | 去哪 | 本章的做法 |
|---|---|---|
| 分页、连续批处理、CUDA Graph、KV 量化、投机解码的**机制** | `01-原理` 各专篇 | 一句话引用,不展开 |
| DP/TP/PP/EP/SP/CP、ZeRO、集合通信算子的**原理** | `01-原理/并行策略`、`ZeRO`、`集合通信` | 一句话引用,不展开 |
| 优化手段的**上手顺序与互相影响** | `01-原理/推理加速`(串讲篇) | 不重复编排层内容 |
| PPO / GRPO / DPO 等**算法** | `03-强化学习` 章 | 一句话引用 |
| 某个项目的**源码实现细节** | 开源解读模块(`opensource/`) | 写「具体实现见开源解读模块」 |

反过来,**个体篇不做横向对比,对比篇不讲某一家的内部架构**——这两条是本章内部最容易越界的地方。
