# Infra 框架与引擎 · 总览
一句话:这是本章 **16 篇主题文章的导航页**——只回答"我该读哪篇、读它之前该先懂哪篇原理",**不讲任何原理**。本章讲工程边界、设计范式与选型;机制原理在 `01-原理`,算法在 `03-强化学习`,源码级调度和函数参数在开源解读。

> **动态阅读口径**:知识库保留框架与引擎最初想解决的问题和稳定范式,同时按最新官方稳定版/主干文档更新高层能力边界。有“动态状态卡”的文章以卡片日期为准;暂无卡片的存量文章视为待迁移旧稿,引用前要复核,下次涉及版本事实时补卡。

## 二、RL 框架七家各绑了谁

七篇 RL 框架单篇都建立在训练与生成引擎之上:它们的主价值是闭环编排、资源放置、数据管理与权重更新。**读某一家之前,先把它的训练与 rollout 路线读了**,否则“权重同步”和“显存腾挪”没有着力点。

| 框架 | 训练后端(读哪篇) | 生成后端(读哪篇) | 资源编排 |
|---|---|---|---|
| verl | FSDP / FSDP2 / Megatron,另挂多种(FSDP 篇 · Megatron 篇) | vLLM / SGLang / HF 原生 generate(vLLM 篇 · SGLang 篇) | Ray |
| slime | **只有** Megatron(Megatron 篇) | **只有** SGLang,server 模式(SGLang 篇) | Ray |
| ROLL | Megatron-Core 或 FSDP2(Megatron 篇 · FSDP 篇) | vLLM / SGLang(vLLM 篇 · SGLang 篇) | Ray |
| OpenRLHF | **只有** DeepSpeed ZeRO(DeepSpeed 篇) | vLLM(vLLM 篇) | Ray |
| AReaL | 独立训练服务(具体后端随版本核对) | SGLang 默认,vLLM 可选 | 解耦微服务 |
| Miles | Megatron 主路,FSDP2 辅路(训练引擎对比 篇) | SGLang | 训推分池 |
| NeMo-RL | DTensor/FSDP2 或 Megatron-Core(训练引擎对比 篇) | vLLM / SGLang / Megatron 推理等官方路线 | Ray |

多家框架用 Ray 做角色放置,但 Ray 在这里**不是**分布式训练后端——切模型的活仍由 FSDP2、Megatron-Core 或 DeepSpeed 完成。AReaL 的微服务解耦和 Miles 的分池路线也不应被简化成“都是 Ray”。

## 三、三条读法

| 你的目标 | 建议路径 |
|---|---|
| **准备推理岗面试** | vLLM → SGLang → 推理引擎对比(机制原理先读完 `01-原理` 章的推理机制那一组) |
| **准备训练/分布式岗** | Megatron → FSDP → DeepSpeed → **训练引擎对比** → NCCL(原理先读 并行策略 与 ZeRO) |
| **准备 RL / 后训练岗** | RL框架对比 → 按范式选 verl / slime / ROLL / OpenRLHF / AReaL / Miles / NeMo-RL(算法先读 `03-强化学习`) |

## 五、本章与别处的边界

这一章最容易和别处写重,分工写死如下:

| 你想找的 | 去哪 | 本章的做法 |
|---|---|---|
| 分页、连续批处理、CUDA Graph、KV 量化、投机解码的**机制** | `01-原理` 各专篇 | 一句话引用,不展开 |
| DP/TP/PP/EP/SP/CP、ZeRO、集合通信算子的**原理** | `01-原理/并行策略`、`ZeRO`、`集合通信` | 一句话引用,不展开 |
| 优化手段的**上手顺序与互相影响** | `01-原理/推理加速`(串讲篇) | 不重复编排层内容 |
| PPO / GRPO / DPO 等**算法** | `03-强化学习` 章 | 一句话引用 |
| 某个项目的**源码实现细节** | 开源解读模块(`opensource/`) | 写「具体实现见开源解读模块」 |

反过来,**个体篇不做横向对比,对比篇不讲某一家的内部架构**——这两条是本章内部最容易越界的地方。

## 六、最容易过时的五处

## 七、真题速查

题库是全部真题的唯一集合。当前 `topic` 首段直接挂在本章篇目上的真题有五道:

| 题(按题库 topic) | 落在哪 |
|---|---|
| vLLM 的核心加速机制,怎么联合 PagedAttention、连续批处理、CUDA 执行优化与配置调优提高吞吐、控制 TTFT/TPOT | **vLLM 篇**第五、六节;单项机制归 `01-原理` 各专篇 |
| DeepSpeed 提供哪些关键能力,怎么选 ZeRO、卸载和并行组合,训练变慢或通信超时怎么排查 | **DeepSpeed 篇**第三、六节 |
| FSDP 与 DeepSpeed 在架构、显存、通信、卸载、并行组合上怎么比,什么时候优先 FSDP,wrap/prefetch/offload 怎么调 | **训练引擎对比**第六至八节 + FSDP / DeepSpeed 各自单篇 |
| FSDP 的参数、梯度、优化器状态怎么分片,一次前向、反向、optimizer step 里 AllGather / ReduceScatter / reshard / 预取各发生在哪 | **FSDP 篇**第三、四节(分片原理归 ZeRO 篇) |
| verl 同步 PPO/GRPO 里 prompt batch、`rollout.n`、mini-batch、每卡 micro-batch 与 PPO epoch 怎么换算 | **verl 篇**第六节 |

其余框架类考点由作者补充,在考点表中统一称为**补充题**。
