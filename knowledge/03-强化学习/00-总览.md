# 强化学习 · 总览

一句话:这是本章 **9 篇的导航页**——只回答"我该读哪篇、按什么顺序读、这道题该去哪篇找",**不讲任何原理**。每个机制的公式、推导、诊断和代价都在各专篇里,本页一律只给一句定位加一个指向。

本页是 hub,不参与题目 `topic` 匹配,也不挂复习优先级角标——重点标记和考点表都在各篇自己文末。

## 一、按依赖顺序读:六组 9 篇

分组依据是**前置关系**:上一组没读懂,下一组的取舍就无从判断。

### 地基(1 篇)——LLM 之外的那半个世界

| 篇 | 它回答什么 |
|---|---|
| **强化学习基础** | MDP 五要素与马尔可夫性、$V$ 与 $Q$、贝尔曼方程;value-based / policy-based / actor-critic 三条路线的分野;DQN 的 replay 与 target network、DDPG 与 TD3、SAC 的最大熵目标;model-based 的取舍与稀疏奖励下的探索设计 |

面试里"你了解经典 RL 吗"问的就是这一篇。它**不回答**"LLM 对齐该选哪个算法"——那是下一篇的题。

### 入口(1 篇)——后训练全景与奖励侧

| 篇 | 它回答什么 |
|---|---|
| **RLHF与RM** | 后训练三阶段各用什么数据;Reward Model 怎么训、**RM 与 Critic 差在哪**;奖励设计与 reward hacking;过程奖励(PRM)与 LM Judge;pass@k 与"RL 到底有没有扩展能力";对齐税;PPO / DPO / GRPO 的**选型对照** |

**全章的入口页,建议第二个读。** 它把"信号从哪来"讲清楚,后面几篇讲的都是"拿到信号之后怎么用"。

### 在线 RL 主线(3 篇)——同一条线上的三代

| 篇 | 它回答什么 |
|---|---|
| **PPO** | 策略梯度与重要性采样;**裁剪目标与完整损失**;GAE 的 $\gamma$ 与 $\lambda$;token 级 MDP 映射;策略熵与熵塌缩;一批 rollout 复用几次、陈旧到什么程度就废了 |
| **GRPO** | 用同题一组回答的相对得分当优势,免掉 Critic;组大小 $G$ 与零方差组;为什么减均值只缩梯度、除标准差才引入难度偏置 |
| **GRPO变体** | DAPO / Dr. GRPO / GSPO / GiGPO 各盯上 GRPO 的哪个故障、怎么修、代价是什么;以及四者能不能叠加 |

顺序不能乱:GRPO 的裁剪和概率比原样来自 PPO,变体篇的每一条又都建立在 GRPO 的组内机制上。

### 公共零件(1 篇)——三条路线都要用

| 篇 | 它回答什么 |
|---|---|
| **KL散度** | KL 的不对称性与和交叉熵的关系;正向/反向 KL 各重罚什么;**k1 / k2 / k3 估计器**,以及"数值无偏不等于梯度无偏";Reference Model 约束放奖励里还是损失里;On-Policy Distillation 及其 logits 依赖 |

PPO、GRPO、DPO 里都有一根拴向 reference 的绳子,但**形态各不相同**,三篇各自只说自己那一段,完整的一根在这里。

### 离线路线(1 篇)——不采样的那条岔路

| 篇 | 它回答什么 |
|---|---|
| **DPO** | 从带 KL 约束的奖励最大化推到闭式解,再反解出隐式奖励(**配分函数为什么会消掉**);梯度里的隐含加权;$\beta$ 的含义;两侧 logp 同时下降正不正常;偏好数据怎么造、要不要先 SFT;与 ORPO / IPO / KTO 的机制差异 |

它和在线主线是**并列分支,不是后继**——同一批偏好数据往哪边走是路线选择,不是先后关系。

### 延伸场景(2 篇)——同一套机制换了战场

| 篇 | 它回答什么 |
|---|---|
| **AgenticRL** | 多轮轨迹、工具与环境交互、部分可观测;轨迹级优势为什么不够用;多智能体信用分配;训练数据构造与冷启动数据质量;什么时候该写死 Workflow、什么时候才值得训;rollout 要跑真实沙箱带来的系统问题 |
| **多模态RL** | 把去噪轨迹当序列决策;在线策略优化 / 可微奖励反传 / 离线偏好优化三条路线的分工;美学分、CLIP 对齐与可验证约束怎么合成一个奖励;图像与视频特有的 reward hacking 形态 |

### 演进主线:谁接替谁,谁只是另一条路

只讲关系,机制一律看上面那几篇。

| 关系 | 一句话 |
|---|---|
| 经典 RL → RLHF | 语言模型的动作空间是十万量级的离散集合、轨迹几千步,value-based 那一路接不上,**策略梯度是被迫也是自然的选择** |
| PPO → GRPO | 不是 PPO 错了,是**Critic 太贵**——用一组样本现场采出基线,顶掉一个同量级模型 |
| GRPO → 各变体 | 免 Critic 换来的代价(组统计的偏置、序列级信用分配、token 级比率的噪声)在大规模训练里逐条暴露,变体是**逐个故障打的补丁**,不是新范式 |
| PPO/GRPO ↔ DPO | **并列,不是替代**。在线路线有探索、受奖励投机之苦;离线路线稳且便宜、受数据覆盖之限 |
| 偏好奖励 → 可验证奖励 | 换的是**信号来源**(评委 → 判卷机),不是优化算法。"用 GRPO"和"用可验证奖励"是两件正交的事,可以任意组合 |
| 单轮 → Agent / 多模态 | 算法基本照搬,变的是**轨迹形态与奖励来源**:一个多了环境和多轮,一个把去噪步数当成时间轴 |

## 二、五条读法:按你的目标挑一条

| 你的目标 | 建议路径 |
|---|---|
| **从零补 RL** | 强化学习基础 → RLHF与RM → PPO → KL散度 → GRPO → DPO → 其余按需 |
| **只准备对齐 / 后训练面试** | RLHF与RM → PPO → DPO → GRPO → KL散度(经典 RL 只需扫一遍 强化学习基础 的前两节) |
| **面推理模型 / RLVR 方向** | RLHF与RM(pass@k 与奖励设计两节)→ PPO → GRPO → GRPO变体 |
| **面 Agent 方向** | AgenticRL → GRPO变体(GiGPO 那一节)→ RLHF与RM(奖励设计与作弊)→ 06-应用 的 Agent 各篇 |
| **面多模态生成** | 多模态RL → DPO → GRPO → 05-多模态 的 Diffusion 篇、FlowMatching 篇 |

只有**两三天**准备时间,就读 RLHF与RM 和 PPO 两篇:本章过半的真题落在这两篇里。

## 四、本章之外

### 相邻章节的衔接

本章只讲**怎么训**——目标函数、优势怎么算、信号从哪来。同一件事的另外几个面在别的章:

| 你要找的 | 去哪 |
|---|---|
| RL 框架的整体架构、训练端与采样端怎么同步权重 | 04-Infra 的 RL框架对比 篇,以及 verl 篇、slime 篇、ROLL 篇、OpenRLHF 篇 |
| rollout 端的吞吐:连续批处理、KV cache、引擎选型 | 04-Infra 的 连续批处理 篇、KVCache 篇、推理引擎对比 篇 |
| 采样温度、top-p 对多样性与 pass@k 的影响 | 04-Infra 的 解码策略 篇 |
| 四个模型同台的显存账、并行与分片 | 04-Infra 的 显存管理与OOM 篇、并行策略 篇、ZeRO 篇 |
| SFT 的模板与数据配比、LoRA、蒸馏的分类学 | 02-预训练与微调 的 SFT 篇、LoRA 篇、蒸馏 篇 |
| Agent **系统怎么搭**(规划、工具、记忆、多智能体架构) | 06-应用 的 规划模式 篇、工具调用 篇、记忆与上下文 篇、多智能体 篇 |
