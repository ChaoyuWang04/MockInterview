# 模型结构 · 总览

一句话:这是本章 **17 篇的导航页**——只回答"我该读哪篇、按什么顺序读",**不讲任何原理**。想知道"这些机制之间谁接替了谁、谁只是并排的另一条路、谁根本不算新机制",那是 新架构追踪 篇(本章串讲篇)的活;两篇分工不同,别搞混。

本页是 hub,不参与题目 `topic` 匹配,也不挂复习优先级角标——重点标记和考点表都在各篇自己文末。

## 一、按依赖顺序读:八组 17 篇

分组依据是**前置关系**:上一组没读懂,下一组的取舍就无从判断。第一组是所有人的起点,最后一组是所有人的终点;中间六组彼此独立,可以按需要跳着读。

### 地基(1 篇)——后面 16 篇都默认你读过它

| 篇 | 它回答什么 |
|---|---|
| **注意力基础** | 一次加权读取怎么算、为什么要除以 √d_k、Q/K 为什么各投影一次、多头拆的是什么、掩码有哪几种、复杂度账分几项。**本章地基,先读它** |

### KV 怎么省(4 篇)——不换算法,只压那本缓存

| 篇 | 它回答什么 |
|---|---|
| KV共享注意力 | 让多个 query 头共用一套 K/V:MHA → MQA → GQA 这条线上,砍的是头数 |
| MLA | 把 K/V 压成低维潜在向量再存,砍的是每个 token 存多宽;附 decoupled RoPE 与 CCA |
| SWA | 每个 token 只准看最近一窗,砍的是缓存里存几个 token |
| 注意力配件 | 不改变注意力复杂度的五件周边:QK-Norm、输出门控、attention sink、跨层 KV 共享、逐层注意力预算 |

### 换一种算法(3 篇)——改"看谁"或者改"怎么算"

| 篇 | 它回答什么 |
|---|---|
| 稀疏注意力 | 改看谁:从固定图案决定,到打分器按内容当场挑;经典谱系与 NSA / DSA / CSA / HCA |
| 线性注意力 | 改怎么算:不留历史 K/V,只滚动一个固定大小的状态;兼作长序列六条路线的横向对照入口 |
| Hybrid注意力 | 改配比:便宜的层和贵的全局层按什么比例混、全局层留几个放在哪、有没有人干脆不混 |

### 位置信息(1 篇)——顺序是从哪一步进来的

| 篇 | 它回答什么 |
|---|---|
| RoPE | 位置信息在哪一步注入、进来之后长度能撑多远;含正弦编码、扩窗手段、partial RoPE 与 NoPE |

### 层内组件(3 篇)——注意力之外,每一层还有什么

| 篇 | 它回答什么 |
|---|---|
| Norm位置 | 两个互相独立的旋钮:统计量沿哪些轴算(BN / LN / RMSNorm),Norm 装在残差的哪一侧(pre / post / sandwich) |
| FFN与激活 | 通道维的加工车间:宽度怎么定、参数占比多少,以及激活函数为什么一路演化到门控结构 |
| 残差流 | 残差连接治的是什么病,以及这条十年没人动的主干道 2026 年被怎么改写 |

### 容量扩展(2 篇)——把"装多少参数"和"每 token 算多少"分开拧

| 篇 | 它回答什么 |
|---|---|
| MoE基础 | Dense 对照、稀疏激活、专家粒度与共享专家,以及"省 FLOPs 不等于省显存"的边界 |
| MoE路由 | 训练时的路由算法:怎么打分、怎么选人、负载不均怎么压平 |

### 训练与输入(2 篇)——一头一尾两件事

| 篇 | 它回答什么 |
|---|---|
| MTP | 训练目标多猜几个 token 之后,训练侧和推理侧各变了什么 |
| Tokenizer | 文本和整数序列之间那本不可微的字典:BPE 怎么合并、词表大小怎么权衡、换掉它要付什么代价 |

### 串讲(1 篇)——全章读完之后再看

| 篇 | 它回答什么 |
|---|---|
| 新架构追踪 | **不讲原理**:替代、并列、正交三条判据,演进主线怎么长出来的;末尾接当季追踪表 |

## 二、四条读法:按你的目标挑一条

| 你的目标 | 建议路径 |
|---|---|
| **从零补基础** | 注意力基础 → RoPE → Norm位置 → FFN与激活 → 残差流 → Tokenizer → MoE基础 → 其余按第一节顺序 |
| **只准备注意力相关面试** | 注意力基础 → KV共享注意力 → MLA → SWA → 稀疏注意力 → 线性注意力 → Hybrid注意力 → 注意力配件 |
| **读懂一份模型技术报告的架构选择** | 新架构追踪 → Hybrid注意力 → 然后对着报告点名的机制回查专篇(MLA / 稀疏注意力 / 线性注意力 / MoE路由 / MTP / 残差流) |
| **面 MoE 或训练侧** | MoE基础 → MoE路由 → MTP → Norm位置 → 残差流 |

## 三、真题速查:哪一类问法去哪篇

题库 `questions/` 是真题的唯一集合。下表按**常见问法方向**归口到篇;逐题对照在各篇文末的「面试考点串联」里,本页不重复。

| 常见问法方向 | 去哪篇 |
|---|---|
| self-attention 怎么算、为什么除以 √d_k、Q/K 为什么不共用一套投影 | 注意力基础 |
| 为什么要分多头、头数怎么选、多头到底学到了什么、能不能剪 | 注意力基础 |
| causal / padding / 双向掩码分别怎么写,复杂度账怎么列 | 注意力基础 |
| 手撕 self-attention、手撕 multi-head attention | 注意力基础 |
| 位置编码有哪几类、RoPE 原理与长度外推、手撕 RoPE | RoPE |
| BN 和 LN 差在哪、pre / post norm 对训练稳定性的影响、RMSNorm 为什么省掉均值中心化 | Norm位置 |
| MHA / MQA / GQA / MLA 的关系与取舍(MLA 本身的机制在 MLA 篇) | KV共享注意力 |
| FFN 为什么先扩维再降回来、GELU 和 SwiGLU 怎么选 | FFN与激活 |
| Seq2Seq 到 FlashAttention 这条线怎么演进、注意力 / FFN / Norm / SSM 各自站在哪 | 新架构追踪 |
| 注意力复杂度怎么优化、长序列 attention 方案怎么比较 | 稀疏注意力 · 线性注意力 |
| MoE 的结构、容量与部署权衡 | MoE基础 |
| MoE 训练时的负载均衡 | MoE路由 |
| 残差为什么能让深层网络训得动 | 残差流 |

MLA、SWA、Hybrid注意力、注意力配件、MTP、Tokenizer 目前没有直接挂靠的真题,但它们是上面这些问法**往下追一到两层**的落点——问完 GQA 追一句"还有别的省法吗",答案就在这几篇里。

各篇当前挂着哪些题,在页面上按 `topic` 看,或者跑一次 `npm run topics` 现场查,不要依赖任何写死在文章里的数字。

## 四、本章之外

### 相邻章节的衔接

本章只讲**模型结构本身**——算的是什么、为什么这么算。同一件事的工程实现在别的章:

| 你要找的 | 去哪 |
|---|---|
| 注意力的 kernel 实现与 IO 优化(分块、online softmax) | 04-Infra 的 FlashAttention 篇 |
| KV cache 的机制、形状、显存账与分页管理 | 04-Infra 的 KVCache 篇、PagedAttention 篇 |
| 序列并行 / 上下文并行,以及 MagiAttention | 04-Infra 的 并行策略 篇、MagiAttention 篇 |
| MoE 的 All-to-All、专家并行切分与热专家 | 04-Infra 的 MoE并行与DeepEP 篇 |
| 优化器、混合精度、长上下文训练配方 | 02-预训练与微调 章 |
| 某个模型的源码实现细节 | 开源解读模块(`opensource/`) |
