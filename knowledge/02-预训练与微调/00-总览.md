# 预训练与微调 · 总览

一句话:这是本章 **21 篇的导航页**——只回答「我该读哪篇、按什么顺序读、这道题该去哪篇找」,**不讲任何原理**。每个机制的公式、数字、边界和代价都在各专篇里,本页一律只给一句定位加一个指向。

本页是 hub,不参与题目 `topic` 匹配,也不挂复习优先级角标——重点标记和考点表都在各篇自己文末。

本章有三处**最容易读串的分工**,先在这里点名,后面各组里还会再点一次:损失那三篇谁管哪一族、提示微调 和 LoRA 谁管选型、拒绝采样 这个名字底下其实是三件不同的事。

## 一、按依赖顺序读:七组 21 篇

分组依据是**前置关系**:上一组没读懂,下一组的取舍就无从判断。前三组是一条时间线(开训之前 → 训练循环里 → 基座练完再接一段);第四组开始换了主语,从「怎么把模型训出来」变成「怎么把它改造成你要的东西」;最后三组是横向的方法论,插在任何位置读都行。

### 开训之前(3 篇)——还没写训练代码就得拍板的事

这三篇的共同点是:**决定一旦做错,要烧掉几十万卡时才知道**。它们排在最前面不是因为简单,而是因为后面每一组都默认这几个决定已经定了。

| 篇 | 它回答什么 |
|---|---|
| **预训练流程** | 整条流水线长什么样:三代范式怎么换的、从零开训要规划哪几件事、贵的决定怎么便宜地验证、loss 尖峰与 NaN 从哪一层查起。**全章地图,先读它** |
| ScalingLaws | 开训前的报价单:再投多少算力能把 loss 压到多少、这笔钱该买多大的模型喂多少 token;以及它为什么只是预算工具,不是能力定律 |
| 数据工程 | 从原始素材到可训练样本的整条流水线:预训练语料怎么爬、怎么洗、怎么配,指令与偏好数据怎么设计、怎么标、怎么验收;两条线共用同一套手艺 |

### 训练循环内部(2 篇)——一步训练只有两件可调的事

从哪儿出发,以及每一步往哪个方向走多远。**参数初始化 排在 优化器 前面是有理由的**:起点没定好,后面学习率怎么调都救不回来。这也是全章唯一和「loss 炸了怎么办」直接相关的两篇。

| 篇 | 它回答什么 |
|---|---|
| 参数初始化 | 起点要同时办成两件事——打破同层神经元的对称性、让信号逐层传下去既不放大也不衰减;以及有了残差和 Norm 之后,现代模型为什么没那么怕初始化了 |
| 优化器 | 把四个旋钮分开看:SGD → Adam → AdamW 的自适应到底适应了什么、状态显存账怎么算、warmup 与衰减形状怎么配、batch size 的三方拉扯、梯度裁剪治什么不治什么 |

### 基座练完再接一段(1 篇)——它不算微调

| 篇 | 它回答什么 |
|---|---|
| 长上下文训练 | 窗口不是从头训出来的,是**扩**出来的:位置编码、注意力、KV、分布式这四层手段按什么顺序上、每一步付什么代价 |

单开一组,是因为它两头都不沾:出厂的还是个基座(所以不算微调),但吃的又是上面两组那套东西(长文档配比、位置编码改法、并行改法)。它本身是串讲篇,单层机制一律指到 01 章与 04 章的专篇,所以读完前两组再读它最顺。

### 把基座掰成你要的形状(5 篇)——同一件事的几条路

到这里主语变了:模型已经存在,问题变成**改哪些参数、改多少、拿什么数据改**。前三篇按「改动落在哪」排——改全部权重 → 旁挂一份低秩增量 → 一个权重都不改;后两篇换个角度,蒸馏 换的是模型本身,拒绝采样 管的是喂进去的数据从哪来。

| 篇 | 它回答什么 |
|---|---|
| **SFT** | 用「指令—回答」示范教一个已经会说话的模型按要求作答:模板与损失掩码、多轮对话怎么组织、灾难性遗忘怎么控、超参怎么调、效果掉了从哪查起 |
| LoRA | 在旁边挂一张低秩勘误表,省下的是梯度与优化器状态那本账:秩与目标层怎么选、QLoRA 的 NF4 与计算精度、权重融合的边界;**PEFT 的横向选型与多任务存储账也归这篇** |
| 提示微调 | Prompt / Prefix / P-Tuning 三种软提示,一个基座权重都不改:分野在这段连续向量**从哪一层进去**、可训练参数量各是多少、RoPE 下前缀给不给位置、KV 缓存怎么处理 |
| 蒸馏 | 让学生模仿教师的行为,而不是只背标准答案:响应、特征、关系三类各学什么,温度与 KL 方向怎么配,拿不到 logits 时还剩什么招;顺带澄清「教师生成数据」和「数据集浓缩」是两件事 |
| 拒绝采样 | 把三件同名的事分开:经典拒绝采样(严格无偏,接受率由包络常数定死)、按分数筛答案的 best-of-N(只是借了名字,不无偏)、重要性采样(一个样本都不丢,代价是权重方差会爆) |

**这一组里有两条分工写死,答题时别串**:提示微调 只讲三种软提示自己的机制,PEFT 横向怎么选、多任务下要存几份权重,一律归 LoRA;拒绝采样 只负责把上面三件同名的事分清楚,投机解码那套算法归 04-Infra 章。

### 学习目标(4 篇)——梯度到底往哪儿走

前面几组讲的都是「怎么训」,这一组讲**训的目标是什么**。结构决定模型能表达什么,优化器决定它每步怎么走,而往哪里走完全由损失说了算。**三篇之间的分工是写死的**:

| 篇 | 它回答什么 |
|---|---|
| **损失函数** | 总览篇:这个任务默认该选哪个目标、什么时候该偏离默认、损失和评测指标是什么关系、多个损失怎么加权;各族只给一句定位,单族机制一律在下面两篇 |
| 分类损失 | 交叉熵这一族:概率解释与梯度形式怎么来的、二分类为什么不用 MSE、标签平滑从**损失视角**改了什么、Focal、类别不平衡与概率校准 |
| 回归损失 | MSE / MAE / Huber 这一族:罚的形状怎么决定模型拟合哪个统计量、背后的噪声假设各是什么、按预测目标怎么选,以及从 MSE 出发的逐层反传 |
| 对比学习 | 第三条路,监督信号从「是什么」换成「是不是一对」:InfoNCE 为什么是一道 N 选 1 的分类题、温度调的是什么、难负例与假负例这套负样本工程 |

标签平滑另有一条分工:**正则视角归 泛化与正则化,损失视角归 分类损失**,两边都不重写。

### 泛化与迁移(3 篇)——训练集上 loss 降下去,不等于新数据上管用

三篇的共同问题是**一套参数要覆盖多广**:泛化与正则化 管同一个分布里没见过的新样本,域泛化 管换了分布而且一个目标域样本都拿不到的情况,多任务学习 管同时压好几个目标还不许互相拖累。越往后要求越强,能用的手段越窄,所以按这个顺序读。

| 篇 | 它回答什么 |
|---|---|
| **泛化与正则化** | 训练误差和新数据误差之间那道缝是怎么来的,以及每条正则手段各放弃了什么换了什么:L1 与 L2、weight decay、Dropout、早停,还有哪几条搬到大模型微调上会失效 |
| 域泛化 | 训练时一个目标域样本都拿不到,却要在目标域上不崩:DG / DA / TTA 三种设定的分野、DANN 与 IRM 各押了什么前提、为什么调好的 ERM 就是很强的基线 |
| 多任务学习 | 多个任务共用一套参数,一定会在共享参数上打架:先分清打的是量级失衡还是梯度方向冲突,再决定调损失权重、动梯度,还是干脆用多任务专家结构在结构上分家 |

### 经典机器学习底子(3 篇)——不在 LLM 链路上,但面试照考

这三篇是彼此的前后手:特征工程 造输入,集成学习 是表格数据上的默认模型,推荐模型 是这两件事在工业场景里的合体。**面算法岗、推荐岗、数据岗时,它们的权重不比前面几组低**。

| 篇 | 它回答什么 |
|---|---|
| 特征工程 | 把一条原始记录翻译成模型能吃的向量:五种类别编码怎么选、目标编码的标签泄漏、缺失值填成众数为什么是错的、数值缩放、CTR 特征设计,以及训练与线上不一致这个经典事故 |
| 集成学习 | 把一堆不够好的模型拼成一个好模型:Bagging 压方差、Boosting 压偏差、Stacking 再学一个组合器,以及 XGBoost / LightGBM / CatBoost 这条梯度提升树线各改了什么、怎么选。通用的特征处理不在这篇,在 特征工程 |
| 推荐模型 | 在几亿维、极度稀疏的离散特征上,把「哪些特征凑一起才有信号」学出来:LR → FM → DeepFM → DCN 这条交叉线,行为序列模型、双塔召回与生成式推荐 |

## 二、四条读法:按你的目标挑一条

| 你的目标 | 建议路径 |
|---|---|
| **从零补基础** | 预训练流程 → 参数初始化 → 优化器 → 损失函数 → 分类损失 → 回归损失 → 泛化与正则化 → 数据工程 → SFT → 其余按第一节顺序 |
| **只准备大模型训练与微调岗** | 预训练流程 → ScalingLaws → 数据工程 → 优化器 → 长上下文训练 → SFT → LoRA → 提示微调 → 蒸馏 |
| **面推荐 / 广告 / 传统算法岗** | 特征工程 → 集成学习 → 推荐模型 → 分类损失 → 多任务学习 → 对比学习 → 泛化与正则化 |
| **手里已有基座,要把它做进业务** | SFT → LoRA → 数据工程 → 泛化与正则化 → 域泛化 → 蒸馏 |

## 四、本章之外

本章只讲**怎么把模型训出来、怎么把它改到能用**。同一件事的另外几个面在别的章:

| 你要找的 | 去哪 |
|---|---|
| RLHF / PPO / DPO / GRPO,奖励模型怎么训、偏好数据怎么用 | 03-强化学习 的 RLHF与RM 篇、PPO 篇、DPO 篇、GRPO 篇 |
| MoE 的结构、容量取舍、路由算法与负载均衡 | 01-模型结构 的 MoE基础 篇、MoE路由 篇 |
| 位置编码本身的机制、Norm 的类型与位置、词表怎么定 | 01-模型结构 的 RoPE 篇、Norm位置 篇、Tokenizer 篇 |
| 分布式训练、显存账、ZeRO 与并行切分 | 04-Infra 的 并行策略 篇、ZeRO 篇、显存管理与OOM 篇 |
| Megatron / DeepSpeed / FSDP 这些训练框架怎么用 | 04-Infra 的 Megatron 篇、DeepSpeed 篇、FSDP 篇 |
| 投机解码的算法(名字里也有「拒绝」,但和本章那篇是两件事) | 04-Infra 的 投机解码 篇 |
| 训练完怎么量化,采样温度与 top-p 怎么影响输出 | 04-Infra 的 量化 篇、解码策略 篇 |
| 检索场景怎么建库、向量维度怎么定、检索评测与线上口径 | 06-应用 的 Embedding 篇、检索优化 篇、RAG评测 篇 |
