# 报告解读

这里保存网页展示的 Technical Report 长文解读,按公司分目录;页面则按技术方向分组:

```text
reports/<公司>/<报告>.md   # 一篇长文,目录名即主要归属方,也是卡片上的公司条幅
reports/index.md           # 方向索引:`## 方向` 分组,每行「报告 | 公司 | 一句话」,行序即页面顺序;已发布按首发日从新到旧
```

状态不写在索引里,由文件推导:正文存在为已发布,`_<报告>.md` 为施工中,否则未解读;`npm run reports:status` 现场打印。一份报告对应一篇完整长文,不要拆成算法、训练或 infra 多篇。[DeepSeek-V4](DeepSeek/DeepSeek-V4.md) 已验收为第一篇写作标杆;后续文章学习它的语言、解释方式和启发性,不机械复制章节模板。完整流程与子 agent 协作契约见 [`docs/10-基模报告流程.md`](../docs/10-基模报告流程.md)。
