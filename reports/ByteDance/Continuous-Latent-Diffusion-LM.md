## 读之前：四个名字就够了

这篇论文要同时踩三条老路：自回归语言模型、离散扩散语言模型、连续扩散语言模型。读正文前，只需要这四个词。

**自回归语言模型（autoregressive LM，AR）**：把一段话拆成一串词元（token），按从左到右的链式法则一个一个写。训练目标清楚，推理却必须串行；全局主题、填空、局部改写都得挤过同一条「只看前缀」的管子。

**变分自编码器（Variational Auto-Encoder，VAE）**：编码器把观测压成连续潜变量，解码器再从潜变量还原。训练时用变分下界（ELBO）同时管重建和正则。人话版：先学会一种压缩后的连续写法，再决定怎么把字填回去。

**流匹配（Flow Matching）与扩散 Transformer（Diffusion Transformer，DiT）**：流匹配不直接学密度，而是学一条从噪声走到数据的速度场；DiT 是用 Transformer 当这个速度场网络。推理时沿速度场走若干步，把噪声运到目标分布。

**离散扩散 / 掩码扩散（以 LLaDA 为代表）**：不按从左到右写，而是在离散词表上反复加噪、去噪，把被掩掉的 token 找回来。它去掉了手写的左右顺序，但中间状态仍是离散观测，扩散路径仍是「把字本身恢复出来」。

贯穿全文的那条线不是「再发明一种扩散 LM」，而是：

> **高质量文本生成不必绑死从左到右，但现有替代方案仍在词或近词的表示上做观测恢复。Cola DLM 把扩散从「恢复字」改成「运输连续语义先验」，再让解码器负责把字写出来。**

它也不是另外两条常被拿来对照的路。Coconut 仍是自回归 LM，只是推理时把 hidden 当 thought；Ouro 是预训练里循环加深计算。二者本批尚未发布，这里只点名、不写数字。Cola DLM 是 **生成模型**：扩散做的是 **潜先验运输（latent prior transport）**，不是 token 去噪，更不是潜空间里的思维链。

## 一句话先说清

报告把这套东西叫 **Cola DLM（Continuous Latent Diffusion Language Model，连续潜空间扩散语言模型）**（PDF p. 1）。它先用 Text VAE 学会文本与连续潜变量之间的稳定映射，再用块因果 DiT 在连续潜空间里学全局语义先验，最后用条件解码器把潜变量还原成字。

从统一的马尔可夫路径角度看，扩散路径只负责把简单高斯运到潜先验，不负责把被弄脏的 token 找回来。因此：

- 全局语义在连续潜空间里组织；
- 局部用词由解码器实现；
- 块与块之间仍有因果，块内部可以并行。

实验覆盖 4 个研究问题、8 个基准、与 AR 和 LLaDA **严格对齐的约 2B 对照**，以及大约 2000 EFLOPs 的缩放曲线（PDF p. 1、9–10、20–21）。报告自己的判断是：层次化的连续潜先验，可以成为严格 token 级语言建模之外的一条原则性替代，而且对这类模型，**生成质量和缩放趋势可能比似然更能反映能力**（PDF p. 1、28）。

## 旧方法各自缺一块

报告没有写成长篇批判，但引言和 §2 把三块拼出来了（PDF p. 1–3）。下面按「报告写了什么」和「我们怎么解释」分开。

### AR：目标清楚，顺序却被写死

报告的观察是：AR 用链式法则直接参数化 token 条件概率，训练目标清楚，但生成被钉在从左到右，推理天生串行，也不适合填空、局部编辑、全局重组（PDF p. 2–3）。

本文补一句解释，不是报告原文：AR 把「全局语义」和「下一个字」塞进同一条条件链。主题还没成形，模型已经在选介词。这不是实现问题，是状态空间选在了表面字符串上。

### 离散扩散：左右顺序解开了，仍在恢复观测

离散扩散分两类（PDF p. 3）：

- 离散转移核：在 token 空间里前向扰动、反向恢复，采样通常很慢，也用不上连续空间的平滑语义几何；
- 掩码或吸收态：逐步把 token 映到 mask，再恢复原文。中间态丢信息，限制全局规划和细粒度控制。

LLaDA 属于第二条。它削弱了手写的左右偏差，但改的仍是观测恢复过程，没有显式的层次化隐变量（PDF p. 7）。

### 连续扩散：空间连续了，目标往往还是「把字找回来」

连续扩散又分三类（PDF p. 3）：

| 类型 | 做法 | 报告指出的卡点 |
|---|---|---|
| 词表对齐的高维连续 | 在 one-hot、logit 或概率单纯形上扩散 / 流 | 维度跟词表走，难扩展 |
| token embedding 连续 | 先映到连续嵌入，再扩散 | 本质仍是恢复被弄脏的目标表示，缺层次化隐变量和统一边际似然 |
| 潜空间连续 | 用 AE / VAE 压缩后再扩散 | 常把潜空间当固定表示，再接自回归解码器，而不是层次化隐变量框架 |

Plaid 是第二条的代表：连续，但状态仍与 token 对齐，核心目标是连续观测恢复（PDF p. 8）。报告把它看成 Cola DLM 在「近乎不压缩、近乎贴着观测」时的极限（附录 C.4，PDF p. 50）。

本文的判断：三条路缺的是同一块——**一个真正被边缘化掉的中间变量，专门承载全局语义，而把用词交给条件解码。** 扩散可以服务这块，但扩散本身不是这块。

## 设计一：先把生成模型写成层次化隐变量

### 旧问题

如果扩散仍作用在词或近词的表示上，连续空间只是换了一种噪声，没有换建模对象。报告要的是：生成分布本身按「先验 × 条件解码」分解（PDF p. 4）。

### 新设计

记离散文本为 $x$，连续潜变量为 $z_0$。生成模型只有两件东西：条件解码器 $p_\theta(x \mid z_0)$ 和潜先验 $p_\psi(z_0)$：

$$
p(x,z_0)=p_\theta(x \mid z_0)\,p_\psi(z_0),\qquad p(x)=\int p_\theta(x \mid z_0)\,p_\psi(z_0)\,dz_0
$$

编码器 $q_\phi(z_0 \mid x)$ **不是生成模型的一部分**，只在训练时做变分推断（PDF p. 4，式 3.1）。

先验用连续流定义。底分布是标准高斯 $p_1(z_1)=\mathcal{N}(0,I)$，网络给出速度场 $v_\psi(z_t,t)$，沿 ODE 从 $t=1$ 积到 $t=0$，得到 $z_0=\Phi^\psi_{0\leftarrow 1}(z_1)$。于是 $p_\psi$ 是 $p_1$ 在反向流下的推前（PDF p. 4，式 3.2）。

序列实现里，潜变量再切成块 $z_0=(z_0^{(1)},\ldots,z_0^{(B)})$，先验按块因果分解：

$$
p_\psi(z_0)=p_\psi(z_0^{(1)})\prod_{b=2}^{B}p_\psi(z_0^{(b)}\mid z_0^{(<b)})
$$

块内可以双向看，块间只能看历史。这既保留跨块因果，又让一块之内并行（PDF p. 4，式 3.3）。

### 工作机制

ELBO 把训练目标拆成三件事（PDF p. 4，式 3.4–3.5）：

$$
\mathbb{E}_{p_{\mathrm{data}}}[\mathcal{L}_{\mathrm{ELBO}}]=\mathbb{E}_q[\log p_\theta(x \mid z_0)]-I_q(X;Z_0)-\mathrm{KL}(\bar q_\phi(z_0)\Vert p_\psi(z_0))
$$

人话就是：

1. **条件重建**：给了 $z_0$，解码器能不能写出 $x$；
2. **信息压缩**：潜变量里到底留了多少关于文本的信息；
3. **先验匹配**：学到的 $p_\psi$ 能不能贴上编码器诱导的聚合后验 $\bar q_\phi$。

编码器、解码器一旦固定，学先验就等价于让 $p_\psi$ 去贴 $\bar q_\phi$。实践中不直接优化密度，而用 Flow Matching 学速度场（PDF p. 4，式 3.6–3.7）。报告写得很硬：**Flow Matching 是先验的求解器，不是模型定义本身**（PDF p. 4）。联合训练时 $\bar q_\phi$ 和 $p_\psi$ 会共进化：编码器重塑潜数据分布，先验反过来正则并组织潜空间。

### 收益、代价与可迁移启发

收益是分工清楚：全局语义走连续几何，局部用词走解码器。代价也清楚：多了一个变分推断缝，似然不再等于训练目标（后文 §5.1）。可迁移的不是「上一个 DiT」，而是：**先问生成分布要不要一个被边缘化的中间状态；再决定扩散运的是这个状态，还是观测本身。**

## 设计二：两段训练，一段推理

### Stage 1：先把文本–潜变量接口钉稳

第一阶段不学最终先验，只学稳定的潜–文对应（PDF p. 6，式 3.15–3.16）：

$$
\mathcal{L}_{\mathrm{VAE}}=-\mathbb{E}_{q_\phi}\log p_\theta(x \mid z_0)+\beta\,\mathrm{KL}(q_\phi(z_0 \mid x)\Vert p_{\mathrm{base}}(z_0))+\lambda_{\mathrm{mask}}\mathcal{L}_{\mathrm{mask}}
$$

三项各管一件事：重建、用底先验把后验拉住、BERT 式掩码损失防止解码器只背表面、编码器语义塌缩。主实验里 VAE **不压缩序列长度**；编码器和解码器都严格因果（PDF p. 6）。

### Stage 2：在稳住的潜空间上学生成先验

第二阶段才让块因果 DiT 上场。对第 $b$ 块，可见集合是「历史干净潜块 + 当前噪声块」，历史走 stop-gradient（PDF p. 6，式 3.17）。联合目标三块（PDF p. 6，式 3.18）：

1. 继续保 autoencoding：重建、正则、掩码；
2. 条件 Flow Matching，学块级条件先验；
3. 相对参考编码器的 KL，压住联合训练时的潜漂。

人话：VAE 还可以动，但不能乱跑；DiT 要学的是「在已有语义条件下，下一块连续语义该长什么样」。

### 推理：前缀编码 → 按块运输 → 条件解码

推理三步（PDF p. 7，式 3.19–3.21）：

1. 用编码器把前缀变成干净潜条件 $z^{\mathrm{pre}}\sim q_\phi(z^{\mathrm{pre}}\mid x^{\mathrm{pre}})$；
2. 每一块从高斯种子 $\epsilon^{(b)}\sim\mathcal{N}(0,I)$ 出发，在历史条件下运到干净潜块；
3. 解码器以前缀和已生成潜块为条件写出回复。

Figure 1 的推理侧还画了 KV cache（PDF p. 6）。这与因果解码器一致：写字阶段仍可流式，并行发生在「一块里的潜向量一起去噪」，不是把整段话一次性无序吐出。

附录 B 把无条件采样写得更干净：先从 $p_1$ 取样，再沿速度场积到 $z_0$，最后条件解码。编码器这条路在真正生成时不出现（PDF p. 45）。这是它和「数据条件前向加噪再反向恢复」的扩散 LM 的分界。

## 设计三：用随机路径看清「扩散在运什么」

### 旧问题

AR、LLaDA、Plaid、Cola 表面上都能逐步采样。报告认为，外层都写成「一条随机路径再发射文本」并不决定模型性质；真正的差别是：**路径活在什么状态空间、这条路径在生成里扮演什么角色**（PDF p. 7）。

观测路径：在文本或近乎无损的文本对齐表示上走，目标是恢复观测。先验路径：只用来生成潜先验，再交给解码器。

### 对照表

Table 1 是全文最该记住的一张表（PDF p. 8）：

| 方法 | 状态空间 | 路径角色 | 连续性出现在哪 | 显式隐变量 |
|---|---|---|---|---|
| AR | 前缀 token | 直接生成路径 | 无 | 无 |
| LLaDA | 离散掩码序列 | 离散观测恢复 | 离散 token 空间 | 无 |
| Plaid | 连续、token 对齐的表示 | 连续观测恢复 | 连续 token 空间 | 无 |
| Cola DLM | 压缩后的潜序列 | **先验运输路径** | 潜空间 | 有 |

Cola 的路径只做这件事（PDF p. 8，式 3.26）：

$$
z_1\sim p_1,\qquad z_0=\Phi^\psi_{0\leftarrow 1}(z_1),\qquad x\sim p_\theta(x \mid z_0)
$$

报告自己写：用连续路径，不是因为连续天生更强，而是因为它能抓住潜分布的几何；用隐变量，是为了把语义结构从 token 实现里拆出来（PDF p. 8）。

附录 C.5 把这句话再说死一次：Cola 不是狭义的「潜空间反向扩散 LM」。狭义那种先定义数据条件的前向加噪 $q(z_{0:T}\mid x)$，再学反向过程去恢复潜状态；Cola 的连续路径在生成时不依赖任何具体观测 $x$，编码器的 $q$ 属于推断，不属于模型构造（PDF p. 51）。

### 什么时候这条路才占便宜

报告给了一个总体判据：模型类的不可约逼近误差，加上变分推断缝，构成总统计负担。Cola 要赢 AR，当且仅当它的总负担更小（PDF p. 8–9，命题 3.1）。

这不是自动成立。适用边界收成三条曲线同时变好（PDF p. 9，式 3.35）：

1. 表示的率失真 $D(R)$ 在较低速率就已经小——数据里存在低维、仍有用的全局语义；
2. 先验逼近误差能随容量下降；
3. 推断缝可控。

附录 D 把反面也写出来了：没有低速率充分统计、局部表面形式本身就是语义、或 token 空间模型已经够用时，瓶颈只会抬高重建下界、再加一条推断缝（PDF p. 53–54）。**扩散和连续都不能单独保证优势。**

| 序列 / batch | 长度 512；全局 batch 1,408；每步 720,896 token |
| 优化 | AdamW；峰值学习率 $1.5\times 10^{-4}$；$\beta=(0.9,0.95)$；weight decay 0.01；梯度裁剪 1.0 |
| 日程 | 5k 步从 $1\times 10^{-6}$ 线性升到峰值，再余弦降到 $1\times 10^{-5}$；评测不用 EMA |
| 种子 | random seed 66，data seed 6198 |
| 评测 | 统一 few-shot **生成**协议；最大新 token 32；截断在第一个换行 |

容量对照不是「大家都叫 2B」就完了（PDF p. 76，Table 9）：

| | AR | LLaDA | Cola DLM |
|---|---:|---:|---:|
| 总参数 | $\sim$2.2B | $\sim$2.2B | $\sim$2.3B |
| 核心非嵌入骨干 | $\sim$1.8B（27 层） | $\sim$1.8B（27 层） | DiT $\sim$1.8B（24 层） |
| 其余 | 嵌入 410,738,688 | 嵌入 410,738,688 | VAE $\sim$500M；嵌入 308,054,016 |
| 注意力 | 因果 | 双向 | VAE 因果 + DiT 块因果 |
| 隐藏 / FFN / 头 | 2048 / 8192 / 16×128 | 同左 | DiT 同左 |
| 潜维 | — | — | 16（RQ4 默认） |

VAE：4 层编码 + 4 层解码，隐藏 1536，FFN 6144（PDF p. 76）。数值精度也对齐：checkpoint 与运行时权重 fp32，主计算 bf16 autocast，LayerNorm / softmax 留在 fp32（PDF p. 77，Table 10）。

一个合理质疑是：Cola 多了一段 VAE 预训练，AR 是从头训的，这算不算偷跑？报告的回答分三层（PDF p. 75–76）：

1. 预训练的 VAE 编码器不是生成先验；推理时新内容仍由 DiT 按块生成再解码。多出来的阶段是在学文本–潜变量接口，不是多训了一个文本生成器。
2. 核心生成骨干都钉在约 1.8B；多出来的 500M 是连续潜变量公式自带的表示构造成本，类似于 AR 也必须在训练早期把嵌入几何稳住。
3. 经验上，Fix VAE 小算力时还能打，但更早饱和；Joint DiT x1 才是缩放最强的。如果优势只来自「有一个预训练编码器」，冻结空间应该一直领先。

评测为什么不走 PPL：§5.1 会证明，Cola 的似然型 PPL 和生成质量可以对不上。于是所有模型都改成统一 few-shot 生成：多选题也要写出选项正文而不是 A/B/C，LAMBADA 是 0-shot 续写，SQuAD 是 1-shot 短答案，其余多为 2-shot（PDF p. 10、70–71，Table 7）。报告自己承认，这种口径会压低多选题的绝对分，相对缩放趋势才是它要的证据（PDF p. 20–21）。

本文的判断：这套对齐是这篇论文能成立的前提。少了「同一语料、同一分词、同一优化、同一生成式评分」，后面「Cola 更能 scale」就说不清是范式还是配方。

### RQ1：潜空间里有没有全局语义结构

问题不是「某个 loc 最好」，而是：若潜表示只是一堆互相独立的局部维，最优 timeshift 不该随潜维稳定漂移（PDF p. 10，Implication 1；证明在附录 E）。

Figure 2 给出反向证据（PDF p. 11）。左图经验峰与预测虚线接近：Task Avg 的最佳 loc 从 $d=16$ 的约 1.00，到 $d=64$ 的约 1.70，再到 $d=128$ 的约 2.30。右图按任务拆开，数字如下（读自 Figure 2）：

| | $d=16$ | $d=64$ | $d=128$ |
|---|---|---|---|
| LAMBADA | loc 1.1 / 33.2 | loc 2.0 / 33.2 | loc 2.0 / 31.1 |
| MMLU | loc 1.1 / 5.4 | loc 1.7 / 8.7 | loc 2.3 / 10.6 |
| SIQA | loc 1.0 / 15.6 | loc 2.0 / 17.6 | loc 2.3 / 23.3 |
| Task Avg | loc 1.0 / 17.33 | loc 1.7 / 19.47 | loc 2.3 / 24.97 |

多数语义指标都随维度偏向更大的 loc。附录 E 的可证结论只到「存在跨维共享或联合结构」；再把它解释成高层语义，要靠这些指标一起漂，而不是单任务噪声（PDF p. 54–55）。这是式 3.35 的第一条——低维全局语义——的经验支撑。

### RQ2：什么样的潜空间才对生成有用

报告从四件事看潜空间：动还是冻、几维、语义是否平滑、后验有多确定。

**冻住不如在稳的初始化上一起长。** Figure 3 比五种策略：Fix VAE、Joint DiT x1、Joint DiT x0.01、All Scratch x1、Interval（每 5k 步里 2k 联合、3k 冻 VAE）（PDF p. 11–12）。小算力时 Fix VAE 有时略好；算力加大后 Joint DiT x1 在 Task Avg / LAMBADA / MMLU / SIQA 上都最稳，Fix VAE 先饱和。All Scratch 全程最弱。Figure 4 的可视化：从零训、$d=16$ 更塌、轨迹像简单外漂；$d=128$ 能减轻塌缩，仍不如「预训练初始化 + 联合」有结构（PDF p. 13）。弱更新和间歇冻结都好过从零，但都明显弱于 Joint DiT x1。

**加维能抬语义容量，但不能代替形成过程。** 在 All Scratch、loc=1、117 EFLOPs 下（PDF p. 13，Table 2）：

| 设定 | LAMBADA | MMLU | SIQA | Avg. |
|---|---:|---:|---:|---:|
| $d=16$ | 14.3 | 6.9 | 4.9 | 8.7 |
| $d=64$ | 20.9 | 5.4 | 7.6 | 11.3 |
| $d=128$ | 18.5 | 8.1 | 8.9 | 11.8 |

平均分随维上升，LAMBADA 在 64 维见顶。更大的潜维同时改变最佳噪声校准（回到 Figure 2），所以加维不只是「空间变大」，还是动力学在变。

**BERT 式掩码损失是语义护栏。** Figure 5 全在 Joint DiT 下：VAE 学习率与 DiT 相同时，加 BERT loss 几乎全程更好；学习率只有 0.01 倍时增益很小；只加大更新、不加 BERT，后期甚至更差（PDF p. 14–15）。能训不等于训对：潜空间越主动进化，越需要被拉向局部语义可恢复。

**VAE logSNR 管的是概率空间有多光滑。** 附录 H.7 把它定义成后验均值功率对后验方差功率的对数比；越大，后验越干净、越确定（PDF p. 77）。主文 Table 3（PDF p. 15）：

| 设定 | 77.86 EFLOPs Avg. | 116.78 EFLOPs Avg. |
|---|---:|---:|
| 固定 logSNR = 1.0 | 14.70 | 18.83 |
| 固定 logSNR = 1.5 | 18.27 | 21.80 |
| 固定 logSNR = 2.0 | 16.77 | 20.63 |
| 可学习（约 4.5） | **18.90** | **22.1** |

可学习最好；固定 1.5 是最强的固定替代，且 SIQA 上固定 1.5 更好。报告自己说优势稳定但不大，只报了两个算力点，缩放行为仍开放（PDF p. 15–16）。后文会看到：把 logSNR 压低能改善似然型 PPL，却不一定改善生成。

### RQ3：扩散过程怎么校

训练侧两件超参：块大小和噪声日程。推理侧两件：去噪步数和 CFG。

**块大小 16 最好，不是越细越好，也不是越大越全局。** Figure 6 在 Joint DiT、loc=1 下比较 1 / 16 / 64 / 128，看 30k（116.78 EFLOPs）和 40k（155.71 EFLOPs）两个点。16 在两个点的 Task Avg 都最高；64 和 128 全面掉，尤其 SIQA 和 MMLU；块大小 1 仍强过过大块，但弱于 16（PDF p. 16–17）。报告没有排除「不同块大小喜欢不同噪声校准」——这里日程被钉在 loc=1。

**loc=1 的 logit-normal 日程最稳。** Figure 8 在 30k / 40k 都是 loc=1.0 的 Task Avg 最高、三任务最均衡。Figure 7 显示：Joint DiT 只有配上 loc=1 才能追上或超过对应的 Fix VAE；loc=0 或均匀日程全程更弱（PDF p. 17–18）。附录 G 的信息论观点：改 loc 不是改训练花招，而是平移去噪轨迹的 logSNR，从而改变「语义信息在哪些时间步还看得见」（PDF p. 18）。Implication 2：最好的日程是和当前潜空间、要恢复的语义尺度对齐的那条，而不是普适的时间参数化。

**推理：步数很快饱和，CFG 中等最好。** Figure 9a：1–2 步到 4–8 步所有任务都跳；大约 16–32 步后 Task Avg 几乎走平。报告说 8–10 步已经收回大部分最终性能。块大小 16 时，16 个 token 只需 8–10 次串行去噪，对应相对 AR 解码 **理想化的 1.6–2.0 倍串行深度下降**（PDF p. 19）。这是「块内并行」，不是端到端延迟承诺。Figure 9 左图有一条约 32.20 的虚线，右图约 31.33，应是饱和区参考，正文没有把它们写成结论数字。

Figure 9b：CFG 从 0 升到约 3–6，Task Avg 迅速上升，中等区间最好；超过约 10 开始掉，20 和 60 严重失真（PDF p. 19–20）。RQ4 推理取 16 步、CFG=7，落在「够用、未过激」的区域。

### RQ4：连续潜先验能不能 scale

RQ4 用前面淘出的保守配方：潜维 16、块大小 16、VAE/DiT 学习率比 1 的联合训练、BERT loss、logit-normal loc=1；推理 16 步、CFG=7。AR / LLaDA 非嵌入骨干都钉在 1.8B，LLaDA 推理去噪长度等于生成长度（PDF p. 20）。

Figure 10 是头条图，横轴到约 2000 EFLOPs，八个基准加 Task Average（PDF p. 20–21）。正文 **没有** 给出终点精度表。报告用文字钉住的观察是：

1. Task Average 上 Cola 全程上升，最终最好；AR 小算力仍有竞争力，LLaDA 早期也有增益，但 Cola 在高算力区升得更持久。
2. 优势在偏推理、偏全局语义的任务上更清楚：MMLU、RACE、Story Cloze、OBQA。
3. 生成向任务上，LAMBADA 随算力追上并贴近 AR；SQuAD 后期超过 AR，逼近 LLaDA 的强区。
4. 这是保守估计：消融已显示 $d=16\to 128$ 还能抬语义容量，logSNR 也还有空间。

本文从图里能读到、但报告没写成数字的补充：HellaSwag 和 SIQA 上 AR 的曲线经常在 Cola 之上或缠在一起；SQuAD 上 LLaDA 长期更高。所以「最终 Task Average 最好」成立，并不等于「每个任务都赢」。绝对分被生成式多选题口径压低，报告自己把当前成绩称为对真实容量的保守度量（PDF p. 20 图注）。

## 讨论：四件核心框架之外的事

### 似然好看，生成不一定好看

这是评测口径的根。生成只要求先验质量到达「解码器认为合法」的语义区域；似然型估计还要求在金标准后验邻域里把局部密度校准准（PDF p. 21–23，Implication 3–4）。

Figure 11：解码探针成功率和后验命中可以一直很高，先验命中却大起大落——问题经常不在解码器，而在先验没对准金标准潜邻域（PDF p. 22）。Table 4 用同一个续写样本里的 at / her / settled 把错位写到 token 级（PDF p. 23）。最刺的一行：token `at` 的似然型 PPL 从直接训练的 $1.15\times 10^6$ 降到固定 logSNR=1.0 的 641.57、再到 1.5 的 245.36，生成却从 `on` 变成 `in` 再变成逗号。`her` 在直接训练时生成对了，PPL 却可以差到 $6.93\times 10^8$。

报告的解释：VAE logSNR 改的是潜 **概率空间** 的光滑，生成质量更跟潜空间的 **语义光滑** 有关。压低 logSNR 让局部密度更平，点态密度误差变小，PPL 变好，同时可能把局部语义抹掉，模型改走 in / the / went 这种泛化但次优的续写（PDF p. 23）。这就是 RQ4 不用 PPL 当主指标的原因，也是 Afterword 第二条主题的实验原型。

### 第一个生成块：干净条件重绘远好于部分重绘

第一块里，已知前缀潜和未知待生成潜挤在同一块里。Figure 12 画了四种策略（PDF p. 24）：干净条件重绘（已知区全程保持干净）、部分重绘（只在轨迹的一段注入与时间步匹配的噪声引导）、左/右 padding（只改位置布局，不显式重绘）。随机长度设定下，这些模式训练和推理一致。

Table 5（PDF p. 24）：

| | 部分重绘最好 Avg. | 干净条件 | 左 pad | 右 pad |
|---|---:|---:|---:|---:|
| Avg. | 9.3（$t=3,m=1.0$） | **24.6** | 16.0 | 16.7 |
| LAMBADA | 8.5 | **37.1** | 24.6 | 24.7 |

减小 $m$（缩短被引导的轨迹比例）通常更差；把重绘次数从 $t=1$ 加到 $t=3$ 没有稳定收益。Padding 好过大部分部分重绘，仍明显低于干净条件。附录 I.1 从 Flow Matching 看：部分重绘把「在固定条件下运输未知区」变成「一边维持嘈杂的已知区、一边运输未知区」，条件方差变大，误差沿 ODE 累积（PDF p. 81–84）。第一块特别敏感，因为已知区在潜空间里是语义锚，不是词级提示。

### 潜空间压缩：坏在边界，不在压缩本身

§5.3 用 $d=128$ 训了两个 VAE：p1 一 token 一潜，p2 每两个 token 压成一个；其余跟 RQ4 相同（PDF p. 25）。Table 6：

| | Overall Avg. | 偶数长度（Mod0） | 奇数长度（Mod1） |
|---|---:|---:|---:|
| p1 | 15.87 | 17.31 | 14.41 |
| p2 | 9.13 | **18.12** | 0.26 |

整体看 p2 差，几乎全是奇数前缀造成的：Mod1 上 LAMBADA 0.79、MMLU / SIQA 为 0。偶数长度上 p2 平均略好于 p1。Implication 5：弱点来自不可整除的边界，不是压缩本身（PDF p. 25）。原因很 Cola：前缀潜是后续块因果先验的 **干净条件**，边界一旦语义偏移，误差会穿过去噪进解码。效率账也直白：块大小 16 时，p1 一块覆盖 16 个 token，p2 覆盖 32 个。边界若能修好，压缩同时服务抽象和速度。

### VAE 重建相当稳，统一图文只是可行性样张

Figure 13：扩散总步 $T=1000$ 时，$t=0$ 重建准确率 0.9998；$t=250$（约 25% 噪声）仍约 0.92；约 $t=385$ 仍留大约 50%（PDF p. 26）。潜–文映射不是一碰就碎的码。

§5.5 把同一套分解接到图文：模态各有 VAE，联合潜状态 $\tilde z_0=(z_0^{\mathrm{text}},z_0^{\mathrm{img}})$，共享块因果 MMDiT 运联合先验，各模态解码器负责实现（PDF p. 26–27）。实现细节：文本切块，图像潜当一整大块；Image VAE 用内部多分辨率数据（256 / 384 / 640 / 1024），空间下采样 16、64 个潜通道。文生图先在 256 分辨率训 80k 步、全局 batch 约 3k，再在 640 分辨率续 10k 步、batch 约 1k；图条件文本生成约 50k 步（PDF p. 27–28）。附录 I.2 还写：统一原型大约只用 1B 文本 token；caption 方向在有限图文对（约 5M）上已有初步能力；该节展示的图是外部图像模型按真值 caption 生成的，不是真实照片（PDF p. 84–85）。

报告把这些明确标成 **早期、定性、可行性**，不是成熟多模态系统（PDF p. 28）。本文也只把它读成「同一套先验运输可以跨过离散文本」，不把样张当 SOTA 证据。

## 限制、结论，以及 Afterword 里真正要带走的三句话

§6 把本文定位成起点，不是终点（PDF p. 28）：

- 规模仍受控，需要更大模型、更长训练、更充足算力看上限；
- VAE 训练策略、压缩方案、潜维、语义平滑，以及 VAE logSNR、块大小、噪声日程的联合校准，都还影响潜空间组织和生成质量；更强的潜表示通常要求更好对齐的噪声校准；
- 框架价值不在去噪本身，而在「全局语义先验 + 局部文本实现」。可替换的潜模块点名了 AE 和 RAE，先验学习可换成 drifting-model 一类的连续分布匹配。

§7 收束：理论分析和实验都指向层次化信息分解对文本生成有用；在严格对齐下，Cola 有强的生成质量和可鼓励的缩放；对这类模型，生成向评测和缩放趋势可能比似然更有信息量；连续潜公式也给离散文本和连续模态的统一建模提供了一条具体路径（PDF p. 28）。

§8 很长，不必当散文抄。它把学习写成模型–环境闭环，然后说本工作其实同时改了三件事（PDF p. 29–33）：

1. **表示**：状态不必等于表面 token 前缀。若文本真有「低维全局语义 + 高维局部实现」，先在潜状态里组织语义、再条件解码，可能更接近生成机制。压缩不等于有害删信息，关键是抽出可泛化的结构。
2. **目标**：AR 的最大似然和 PPL 天然对齐；Cola 优化的是重建 + 先验拟合 + 表示正则，ELBO 与真边际似然之间还有推断缝。错位不是没学会，而是在学别的东西。能力更应看生成质量和缩放，而不是某一点上的局部拟合。
3. **环境**：统一模型的意义不是一个骨干里塞进多种数据，而是让模型进入观测、转移、反馈不可按模态拆开的环境。文本一直是统一模型里最别扭的一块，因为它天生离散。Cola 提供的是离散文本进入连续交互状态的接口，而不只是另一种文本生成器。

作者在项目页另有一封更口语的信，强调「真正想问的是：有没有比离散 token 更接近语义本质的信息载体」。那是外部补充，不是 PDF 正文。

## 可迁移启发

1. **先选路径角色，再选扩散。** 观测恢复和先验运输都可以逐步采样，统计含义完全不同。自己的项目如果还在词或 embedding 上加噪，连续空间不会自动变成层次化语义。
2. **Flow Matching 是求解器。** 模型定义是 $p(x)=\int p_\theta(x \mid z_0)p_\psi(z_0)\,dz_0$。实现可以换 drifting、换别的分布匹配，只要先验家族够表达、推断缝可控。
3. **表示要共进化，但必须从稳的接口出发。** 冻死的 VAE 会封顶；从零联合会塌。这比「要不要 VAE」这条口号有用。
4. **评测跟目标走。** 层次化连续模型上，PPL 变好可能只是把概率空间抹平。生成任务就用生成协议；不要用 AR 的似然习惯审一款不在 token 上做最大似然的模型。
5. **条件要当锚，不要当再去噪的对象。** 第一块的干净条件重绘，是条件生成里很便宜、却决定性的实现选择。
6. **压缩的第一失败模式往往是边界，不是速率。** 奇数长度把 p2 打到近零，偶数长度反而略好。任何非 1 的 patch / 下采样，都要先问不可整除的前缀怎么进干净条件。
7. **约 2B 对照的写法可以复用。** 同一语料、分词、batch、优化、种子、精度，再把「多出来的模块」解释成方法内在成本，而不是偷偷多吃的预训练。没有这张表，跨范式缩放曲线很难信。

依赖特定规模的部分也说清：2000 EFLOPs、八基准生成式绝对分、统一图文原型，都还在受控设定里；解码器仍是因果的，串行变少来自块内并行，不是已经取代 AR 服务栈。

## 关键词回看

- **Cola DLM**：层次化连续潜空间扩散语言模型。生成模型，不是潜空间 CoT。
- **潜先验运输**：扩散 / 流把高斯运到 $p_\psi(z_0)$，不恢复被弄脏的 token。
- **Text VAE**：学 $q_\phi(z_0 \mid x)$ 与 $p_\theta(x \mid z_0)$；主实验不压缩长度，编解码因果。
- **块因果 DiT**：块间因果、块内双向；Flow Matching 学条件速度场。
- **聚合后验 $\bar q_\phi$**：编码器把数据抬到潜空间后的目标分布；先验要贴的是它。
- **VAE logSNR**：后验均值功率相对方差功率；管概率光滑，不等于语义光滑。
- **干净条件重绘**：第一块里把已知前缀潜当全程固定条件。
- **三条控制曲线**：率失真、先验逼近、推断缝。三者同时变好，瓶颈才是优势而不是税。

## 最后的判断

这篇论文最值得记住的，不是某一个 loc、也不是 Figure 10 还在涨的 Task Average，而是它把一种容易被口号化的路线写清楚了：

> **连续扩散语言模型可以不是「在词的连续化外壳上做去噪」，而是一个带 CNF 先验的层次化隐变量生成模型：扩散只负责把语义先验运到位，字由解码器实现。**

约 2B 对齐和生成式评测，让「能 scale」这句话有了可核对的口径；似然与生成的错位，则提醒不要用 AR 的 PPL 习惯去审它。它仍然是受控规模上的起点：数据没点名、终点表没给、解码器仍因果、统一图文只是定性原型。把摘要读成「连续潜空间已经取代自回归」，报告自己的限制和三条控制曲线都不支持。

若只带走一条能用在自己项目里的原则：当你觉得离散 token 在挡路，先问缺的是更平滑的观测恢复，还是一个真正被边缘化、专门承载全局语义的中间状态。缺的若是后者，扩散才值得从词上搬开。
