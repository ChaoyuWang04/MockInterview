# 知识库结构与文章地图

页面 `/kb`。**按训练流程编排**:模型结构 → 预训练与微调 → 强化学习 → Infra → 多模态 → 应用。

本文件只维护稳定的目录结构、文章唯一名称和内容边界。当前施工顺序只看 [01-TASK.md](01-TASK.md);文章怎么写只看 [05-知识库写作契约.md](05-知识库写作契约.md)。

## 结构约定(2026-08 重构)

- **顺序**:文件夹用 `NN-` 数字前缀控制顺序,页面显示时剥掉前缀;目录内 `00-总览.md` 自然排第一
- **层级**:支持任意层嵌套(如 `05-多模态/03-视频生成/视频VAE.md`)
- **与题库的联动**:题目 frontmatter `topic` 第一段 → **按文章名全库匹配**(不再要求同名分类文件夹),因为分章已不与题库分类一一对应
- **文章名全局唯一**(各章的 `00-总览` 除外,它们是 hub 页不参与匹配),有测试守护
- **只有写完的文章才建文件**:知识库里每一篇都是成文稿,没有「占位」「旧稿」之分。还没动笔的文章登记在下面的计划表里,不提前建空文件

新增文章:按文章名反查题库 topic → 回读真题、追问和已有答案,核实事实并列出本篇必答考点 → 写正文与考点表 → 逐题验收覆盖情况 → `npm test` 与 `npm run kb:lint`。
**写作契约(语言/公式/图表/mermaid 规模/代码/真实性/怎么出考点题)见 [05-知识库写作契约.md](05-知识库写作契约.md)**,标杆样板是 `04-Infra/01-原理/GPU架构与执行模型.md`;架构类参考 [references/frontier-llm-architecture-handbook-2026.md](references/frontier-llm-architecture-handbook-2026.md)。

| 04-音频 | `音频编解码` | **音频表征谱系**(波形 / STFT / 梅尔谱 / 离散 token);多层 RVQ token 摊平进一维序列的四种排布 | 声码器(mel → 波形)归 `TTS`,神经编解码器(波形 → token → 波形)归 `音频编解码`——两者都产波形但输入不同;`语音识别` 独占三范式与 Whisper;`音乐生成` 独占两条路线、长时结构、乐理约束、版权 |
| 05-3D生成 | `NeRF` | **3D 表示谱系与体渲染方程**;隐式辐射场、位置编码与谱偏差、分层采样、加速谱系 | **`NeRF ↔ 3DGS` 的横向对比判给 `3DGS`**(3DGS 整篇针对 NeRF 定义);`多视角扩散` 独占数据稀缺这条立论、SDS、Janus 问题;网格与材质归 `网格生成` |
| 06-世界模型 | `世界模型范式` | **概念框架**:表征加动力学加奖励三块、隐空间 rollout、想象中训练、与 model-based RL 的关系 | **动作空间表示与条件注入整条判给 `动作条件与交互`**,另两篇只说一句「动作作为条件进入」;`视频世界模型` 独占「把视频生成模型当可交互环境」:因果性与实时性两条硬约束、可回访一致性 |

**两组容易混的「一致性」**:`多视角扩散` 管**同一时刻不同机位**的空间一致性(约束硬,相机参数唯一确定),`长视频一致性` 管**同一东西不同时刻**的时间一致性(约束软);而 `视频世界模型` 管的是可交互环境里的**可回访一致性**(玩家可随时转身对质,是离散的对错判定),`长视频一致性` 管的是单向长视频的**缓慢漂移**。两组都只做一句对照,不互相展开。

扩散与流匹配机制归 `Diffusion`、`FlowMatching`,条件注入机制归 `条件控制`,经典 RL 归 `强化学习基础`,各篇只讲自己这边的代价。

> **04-音频、05-3D生成、06-世界模型三个子领域题库零真题**,考点表全部是补充题。之后采到真题,入库后须回对应专篇重做考点表——真题优先,补充题让位。
