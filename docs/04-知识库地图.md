## 结构约定(2026-08 重构)

- **顺序**:文件夹用 `NN-` 数字前缀控制顺序,页面显示时剥掉前缀;目录内 `00-总览.md` 自然排第一
- **层级**:支持任意层嵌套(如 `05-多模态/03-视频生成/视频VAE.md`)
- **与题库的联动**:题目 frontmatter `topic` 第一段 → **按文章名全库匹配**(不再要求同名分类文件夹),因为分章已不与题库分类一一对应
- **文章名全局唯一**(各章的 `00-总览` 除外,它们是 hub 页不参与匹配),有测试守护
- **占位稿**:正文含 `> 🚧 占位:` 标记,页面显示为虚线灰框;写完删掉该行即可
- **重点考点**:正文含 `> 🔴 重点考点:` 标记,页面显示红色「重」角标 —— 表示该篇有真实面经考点支撑、文末有「面试考点串联」;纯介绍性文章不加

新增/重写文章:按文章名查 [写作参考索引](references/写作参考索引.md) 及其链接的面经映射,并反查题库 → 回读原题、追问和老师答案,核实来源与事实、列出本篇必答考点 → 写正文与考点表 → 逐题验收并回填映射的小节和状态 → 删掉占位/旧稿标记 → `npm test` 与 `npm run kb:lint`。
**写作契约(语言/公式/图表/mermaid 规模/代码/真实性/怎么出考点题)见 [05-知识库写作契约.md](05-知识库写作契约.md)**,标杆样板是 `04-Infra/01-原理/GPU架构与执行模型.md`;架构类参考 [references/frontier-llm-architecture-handbook-2026.md](references/frontier-llm-architecture-handbook-2026.md)。
