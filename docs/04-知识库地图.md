## 结构约定(2026-08 重构)

- **顺序**:文件夹用 `NN-` 数字前缀控制顺序,页面显示时剥掉前缀;目录内 `00-总览.md` 自然排第一
- **层级**:支持任意层嵌套(如 `05-多模态/03-视频生成/视频VAE.md`)
- **与题库的联动**:题目 frontmatter `topic` 第一段 → **按文章名全库匹配**(不再要求同名分类文件夹),因为分章已不与题库分类一一对应
- **文章名全局唯一**(各章的 `00-总览` 除外,它们是 hub 页不参与匹配),有测试守护
- **占位稿**:正文含 `> 🚧 占位:` 标记,页面显示为虚线灰框;写完删掉该行即可
- **重点考点**:正文含 `> 🔴 重点考点:` 标记,页面显示红色「重」角标;它只表示当前复习优先级,不表示题目来源

新增/重写文章:按文章名反查题库 topic → 回读真题、追问和已有答案,核实事实并列出本篇必答考点 → 写正文与考点表 → 逐题验收覆盖情况 → 删掉占位/旧稿标记 → `npm test` 与 `npm run kb:lint`。
**写作契约(语言/公式/图表/mermaid 规模/代码/真实性/怎么出考点题)见 [05-知识库写作契约.md](05-知识库写作契约.md)**,标杆样板是 `04-Infra/01-原理/GPU架构与执行模型.md`;架构类参考 [references/frontier-llm-architecture-handbook-2026.md](references/frontier-llm-architecture-handbook-2026.md)。

### 01-模型结构

总览 · 注意力基础 · KV共享注意力(MHA/MQA/GQA)· MLA · 稀疏注意力 · 线性注意力 · SWA · Hybrid注意力 · 注意力配件 · RoPE · MoE基础 · MoE路由 · Norm位置 · FFN与激活 · 残差流 · MTP · MagiAttention · Tokenizer · 新架构追踪

> 新出现的注意力变体各开一篇;还不够成篇的先记进「新架构追踪」。

**`注意力基础` 与 `注意力配件` 的分工写死**:`注意力基础` 负责标准注意力本身——QKV 投影与公式、$\sqrt{d_k}$、点积与加法打分、多头拆分与头数、掩码(causal/padding/双向)、复杂度账本、注意力头分析与剪枝;`注意力配件` 只负责不改变注意力复杂度的周边件——QK-Norm、门控、attention sink、跨层 KV 共享、逐层注意力预算。手撕注意力类真题的 topic 一律挂 `注意力基础`。

另有基础文章计划:`Transformer整体架构` 负责串起完整数据流和组件边界,`RNN与门控循环网络` 负责 RNN/GRU/LSTM 的递归与门控机制,`卷积与池化` 负责 CNN 基础算子、参数共享和下采样。
