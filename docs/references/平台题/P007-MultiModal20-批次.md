## 事实校正口径

- Qwen-VL 的视觉接入不是 BLIP-2 的 Q-Former；正式答案按其视觉接收器与位置表示的一手描述书写。
- LLaVA 的 MLP 逐视觉 token 投影；不能把它说成依赖全局平均池化。连接器预训练与视觉指令微调阶段的冻结范围不同。
- BLIP-2 的两阶段训练分别连接冻结图像编码器和冻结 LLM，不等于“对比匹配之后统一做指令微调”。
- CLIP 使用网络图文对作弱监督，不等于没有监督，也不保证天然容忍噪声；零样本只表示不使用目标数据集的任务标签训练。
- 固定参数量、学习率、batch、时延、吞吐提升和视觉 token 数均依模型与硬件配置变化，不能写成通用结论。
- SAM 的多掩码输出用于处理提示歧义，不是三个固定语义层级；原始 SAM 是提示式图像分割基础模型，不是视觉语言模型。
- 灰度系数取决于颜色标准和处理空间；多模态模型通常保留彩色输入，灰度化不是默认步骤。
- Swin 的窗口注意力在固定窗口下对图像大小近似线性，但完整网络成本不能只写成一个复杂度；骨干优劣必须按目标任务、输入尺寸和硬件实测。
