## 关键纠错

| 页面说法 | 入库处理 |
|---|---|
| GRPO 被展开为 Generalized Reward 等多个名称 | 统一更正为 **Group Relative Policy Optimization**。 |
| PPO clip 会把全部概率比或 KL 硬限制在区间内 | 改为：裁剪让代理目标在越界后不再继续奖励有利方向，不能保证参数、概率比或 KL 永不越界。 |
| 原始 GRPO 不含参考策略 KL | 按 DeepSeekMath 原始目标更正：原始 GRPO 含 KL 项；后续配方可调整或去掉。 |
| PPO 式 RLHF 被称为离线强化学习 | 更正为训练环中由当前策略持续生成 rollout 的典型 on-policy 路线。 |
| `OPO = Offline Preference Optimization` 被当成公式唯一的算法 | 一手资料无法确认。P003-Q037 改为离线偏好优化类别辨析并删除无来源公式；P003-Q114 的正文实际是 DPO，按 DPO 归并。 |
| verl 的 batch 公式同时乘 `world_size` 与 `dp_degree` | 按 2026-04-29 本地快照重算：区分 prompt batch、每题生成数、PPO mini-batch、每卡 micro-batch，不重复计算数据并行。 |
| Reward Model 与 critic 被当成同一种打分器 | 更正为：RM 评价完整回答/轨迹的偏好，critic 估计条件状态的未来回报并提供基线。 |
| CoT 被说成强化学习的必要条件 | 更正为：RL 需要 action 与 reward，不要求显式输出 CoT。 |
