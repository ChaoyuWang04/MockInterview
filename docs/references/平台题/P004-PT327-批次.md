## 关键纠错

| 页面说法 | 入库处理 |
|---|---|
| 把 Pre-LN 与 Post-LN 公式或名称写反 | 统一按 `Post-LN: LN(x+F(x))`、`Pre-LN: x+F(LN(x))` 订正。 |
| 多头数量为 `h`，总计算量因此自动除以 `h` | 在总隐藏维固定时，各头成本相加；分头改变表示组织，不会让总计算量自动除以头数。 |
| `Q=K` 后 attention 矩阵仍对称 | `QQ^T` 对称，但逐行 softmax 的分母不同，结果通常不对称。 |
| FlashAttention 是线性注意力、Mamba/RWKV 都属于线性注意力 | FlashAttention 是精确稠密 attention 的 IO 优化；Mamba 是选择性状态空间模型，RWKV 才有线性 attention 的递归表达。 |
| RoPE 天然支持任意长度外推，MLA 不需要 RoPE | RoPE 可计算表外位置但不保证质量；DeepSeek-V2 的 MLA 明确保留解耦 RoPE 分量。 |
| RULER 是扩散采样器 | RULER 是长上下文评测基准；DPM-Solver++ 等才是扩散 ODE/SDE 数值求解方法。 |
| ESMM 用 CTR 塔和 CTCVR 塔，最后做除法得到 CVR | 原始 ESMM 是 CTR/CVR 两塔，二者相乘形成 CTCVR 并接受联合监督。 |
| CLIP 原论文 batch 为 64K+；FSQ 保证 100% 码本利用 | CLIP 原论文为 32,768；FSQ 无显式可学习码本，不代表所有隐式组合必然被使用。 |
| 闭源模型的层数、专家数、Top-k 和注意力配置可以按传闻填写 | 官方未公开的结构不写成事实；所有精确数字必须绑定可访问的一手资料与版本。 |
