## 事实校正口径

- ZeRO 显存节省必须写明精度、优化器与数据并行度，不能套固定倍数。
- KV Cache 要区分单步计算、整段生成计算和缓存读取；不能笼统写成“有缓存就是 $O(1)$”。
- MLA 的正确展开是 **Multi-head Latent Attention**；原题中的 `Multi-Loop Attention` 作为原话保留，只在答案中订正。
- V100 没有 BF16 Tensor Core 支持；硬件精度能力必须按代际核实。
- FlashAttention 是精确注意力的 IO 优化；固定分块不会把算法变成近似，但浮点计算顺序可能带来舍入级差异。
- vLLM 吞吐目标必须绑定模型、硬件、精度、输入输出长度、并发与 SLO，不使用无条件的固定 token/s 结论。
