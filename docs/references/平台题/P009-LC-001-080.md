## P009-Q001

原图：`inbox/7-LC-241/LC-001.png`。真实面经原件：[B006-G01-Q001](../面经原题.md#b006-g01-q001)。

### 页面元数据

- 难度：简单
- 公司：小米、字节、快手、腾讯、联通

### 题目逐字原文

请使用Python和PyTorch（或伪代码）手动实现一个完整的多头注意力（Multi-Head Attention）模块，要求包含输入的线性投影（QKV生成）、分头处理、缩放点积注意力计算、多头结果拼接、输出投影，并支持可选的注意力mask机制；请清晰表达每个步骤的设计逻辑与张量形状变化。

### KEY POINTS

QKV 投影及维度；reshape/transpose 分头；缩放点积、softmax；`key_padding_mask`、`causal_mask`；拼头与输出投影。

### REFERENCE ANSWER（结构化摘要）

PyTorch 模块依次做 Q/K/V 投影，变形到 `(B,h,L,d_k)`，算 `QK^T/sqrt(d_k)`，施加两种 mask，softmax 后乘 V，再拼头并过输出层；说明各张量形状。

### 追问题目

长序列的瓶颈与优化；为何除以 `sqrt(d_k)`；Dropout 应放在哪里。

### 分类与去重

非 LC；与 LC-026、LC-079 近义，直接复用/合并 `questions/手撕代码/002-手写-multi-head-attention.md`。

### 核对注记

主体正确；若某一 query 的 key 全被 mask，`softmax(-inf)` 可产生 NaN，答案未说明保护策略。
