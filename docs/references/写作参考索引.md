# 写作参考索引

写知识库文章前,按**文章全名**检索两处:下方的平台题映射,以及 [面经考点映射](面经考点映射.md)。这里统一入口,不复制面经映射的历史记录。来源材料、题库答案与知识库覆盖是三件事:有来源不等于答案正确,有题库文件也不等于文章已覆盖。

## 来源与维护

- **真实面经**:原件与逐题映射沿用 [面经原题](面经原题.md) 和 [面经考点映射](面经考点映射.md),按 10 的流程处理,不在本表重复登记。
- **平台整理题**:保留老师题干、答案、要点与追问,来源统一放在 `平台题/`。平台的公司标签按页面记录,不能据此把题干或老师答案当成已核实的面试原话;不自动加 `面经` 或 🔴。
- 平台题编号使用 `P001-Q01` 等固定编号,批次编号不重用;题序仅记采集时的位置。复用已有题时照样保留来源行与老师答案链接;同一原题可按跨篇考点拆多行。
- 动笔前必须读该篇关联来源的**完整题干与追问**,并阅读老师答案,核验其中相关事实。不能只看摘录或把“来源文件存在”当作已经使用。
- 状态沿用「待核对 / 待写 / 待补 / 已覆盖」:只有正文与考点表能回答对应来源问题、且填写了实际正文小节,才能标已覆盖。文章不存在或占位则登记待写,不为入库强行写整篇;其余未覆盖项须列入 `01-TASK.md`。
- 题库答案是否经用户验收,由 `待校对` 标签单独表示。文章重写、小节迁移后重新核对映射,任务完成后保留来源与映射。

批次核验记录:[P001 · SFT 前三题](平台题/P001-核验与入库.md),包含去重判定、老师答案中的疑点及纠正依据。
