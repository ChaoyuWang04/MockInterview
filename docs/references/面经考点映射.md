本表长期记录**原题 → 题库 → 主负责文章 → 正文覆盖**。任务完成后只删 `01-TASK.md` 的待办,保留本表和 [原文存档](面经原题.md)。入库步骤见 [面经双写流程](../10-面经双写流程.md),写前检索与写后验收见 [写作契约第九节](../05-知识库写作契约.md)。

## 怎么查与维护

- **写前按文章全名查本表的所有状态**,再反查题库的 `topic` 与「面经」标签,并搜索原件中的相关术语;本表没有某篇不代表一定没有真题。
- 原题位置使用固定编号并链接原件锚点。考点摘录只取原话,省略处用「…」;AI 补的追问、答案和场景设定不是原件。摘录是导航,验收时必须读完整原题。
- 一行对应一个主负责文章内的考点及其追问;跨篇复合题分行。不同原题的同一考点可以复用题库题目与正文小节,但保留各条原题的位置。
- 新题的 `topic` 第一段必须与主负责文章全名一致;链接的题库文件须真实存在。历史合题或归属疑点可先登记「待核对」并说明,后续拆题/改归属时同步本表。
- 尚无题库文件填「待入库」,文章未定填「待定」并留任务;已确定但尚无文件的文章填计划全名、状态「待写」。不能编造链接。缺原件的历史「面经」题单列来源待核对记录,不得编原题编号。
- 「正文小节」填**实际正文标题**,不能只指向文末考点表。尚未确认填「—」并可附缺口说明;改标题、迁移内容、改题目文件名时同步本表。已覆盖的行在文章重写后也要重新核对。
- 所有非「已覆盖」行须有待办,可按文章或批次合并成一条任务并引用原题编号。原件保留全部来源,任务可删除,映射可更新但不能因没答上就删掉。

| 覆盖状态 | 含义与下一步 |
|---|---|
| 待核对 | 原件、题库归属或正文覆盖尚有项目未核对;不能据此宣布文章完成 |
| 待写 | 原件和归属已确认,文章尚未成文;任务队列安排撰写 |
| 待补 | 原件和归属已确认,已有正文或考点表未答全;任务写明缺口 |
| 已覆盖 | 已逐题对照原件,正文能回答该行考点及追问,考点表已承接,并填入实际正文小节 |

状态只表示该行考点的覆盖,与文章的「旧版/占位/成文」、题库答案的「待校对」分开。页面跳转、🔴 标记和检查命令通过都不等于已覆盖。
