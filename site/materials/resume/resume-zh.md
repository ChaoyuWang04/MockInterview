### 金融财富管理 RAG 问答系统构建与 GRPO 对齐优化 — 华泰证券(南京) 算法实习

*2025.4 – 2025.8*

**项目背景：** 负责构建面向财富管理业务的检索增强生成（RAG）问答系统，整合2000+多模态文档（PDF、PPT、扫描图片等），为销售与投顾团队提供即时客户需求匹配与方案建议服务。

**技术栈：** Python、Transformers/PEFT、BGE、DeepSeek-R1-7B、GRPO、Milvus、Elasticsearch、Cross-Encoder、Docker

**核心工作与方案：**

- **RAG 系统构建：** 结合章节标题、表格边界、条款编号进行智能切分，保留层级标签便于精准检索；在内部金融问答数据上对 BGE 进行对比学习微调，增强对专业术语的语义理解；采用混合检索（BM25 + 向量）+ 微调 Cross-Encoder 二次重排策略，确保关键条款与语义近似内容均能被召回；通过 Context Injection 与 Query Rewrite 解决多轮追问中的指代词消解问题；在 Prompt 中要求 LLM 对每段内容标注来源出处，提升答案可解释性与合规可追溯性。
- **GRPO对齐优化：** 从真实咨询日志与红队测试语料筛选 3,000+ 条高质量 Prompt 作为训练种子；设计三维 Reward Function——事实准确性基于 RAG 召回文档通过 LLM-as-Judge 进行 grounded faithfulness 打分，上下文一致性检测多轮对话中的指代遗忘，表达拟人化评估回答风格与顶级投顾的偏差；基于 DeepSeek-R1-7B 进行 GRPO 策略优化，同一 Prompt 采样多个输出经 Reward 评分后组内归一化驱动策略梯度更新。

**成果：**

- 混合检索 + 微调 + 重排策略下，Recall@5 从 52% 提升至 88%，MRR 从 0.38 提高至 0.72
- 幻觉率从 8.0% 降至 1.2%；多轮上下文衔接错误率从 3.0% 降至 0.5%；未见场景泛化任务完成率达 81%
