# 简历 · Agent 档

偏**模型训练与 Agent 系统**:数据/奖励/评测自建、GRPO 训练、生产化 Harness。

## 工作经历

### 业务 Agentic RL 基座模型训练

`2025.09 – 2026.03`

**背景** 面向广告投放优化场景,训练可自主调用 30+ 业务工具、多轮完成投放诊断、调价与审批闭环的 Agent 基座模型,数据、训练、评测全流程自建。

- **环境与数据** 构建确定性 Function Call 沙箱与 2500+ 条脱敏数据任务;事实由沙箱回放生成、语言由教师模型改写,建库门禁把关质量;训练样例与线上真实请求逐项对齐。
- **奖励与评测** 5 维加权子分 + 35 类分数硬封顶,判分依据沙箱终态事实;冻结评测集配对读数、多遍聚合控制方差、词表内外双轨测泛化;多次先于人工发现 reward hacking。
- **GRPO 训练** 基于 VeRL 自研多轮工具调用采样循环;任务池动态调度防训练分布漂移;行为守卫自动停训练。
- **会话能力** OPD 在线蒸馏矫正表达、CoT 拒绝采样冷启难例思考、多轮真实消息对数据。

**成果**

- 端到端任务通过率 **0.36(Base) → 0.71(SFT) → 0.90(GRPO)**
- 多轮指代续查 36% → 92%
- 自然语言质量人工盲评得分率 30% → 73%
- 证据缺失率、越权操作率均下降至 5%
- 298/343 个测试任务集超过开源模型 zero-shot 基线

### Agent 生产化 Harness Engineering

`2025.09 – 2026.03`

**背景** 将模型上线为稳定服务,幂等、崩溃可恢复、全程证据可溯源,同时作为模型行为的真实反馈源回流训练。

- **可靠执行** 任务异步执行逐步落库,状态机统一管理状态迁移;请求、任务、工具三层幂等防重复副作用;崩溃后从 checkpoint 断点恢复,结果未知的调用先挂起、由对账任务查证后回填。
- **可观测与人工审批** SSE 事件流实时推送执行过程,断线重连自动补齐;日志、指标、trace 三件套贯穿全链,告警绑定处置手册;高风险操作生成预览转人工审批,全量审计留痕。
- **发布与回流** 灰度发布、可演练回滚、新旧数据版本兼容;训练与线上共用同一套提示渲染与解析;多模型并排真人 A/B 实测;线上轨迹归因回流评测集,环境错误不进训练负样本。

**成果**

- 核心 SLO:任务 P95 完成 < 60s、任务失败率 < 1%、队列延迟 P95 < 10s、高危操作审批与审计覆盖 100%

## 项目经历

### Agentic 负载推理引擎优化 · 模型 + Harness + Infra Codesign

`2026.05 – 至今`

**背景** 消费级多卡上异步 Agentic RL,解决 verl 框架的权重同步与批组织机制的静默失效,确保训练正确性与吞吐。

- **正确性** 定位并修复三个指标正常但模型未学习的框架级静默缺陷,覆盖 FSDP 梯度同步、LoRA 权重下发、打包前向归约,修复后数值逐位验证。PR 已提交 verl 框架与 NCCL GitHub。
- **吞吐与执行层** Nsys / torch profiler 定位并逐点消除 CPU-GPU 强制同步,CUDA Graph 与 torch.compile 按负载实测定界启用;前缀共享前向端到端提速 **2.31 倍**;权重同步载荷缩减 **33 倍**;整机 GPU 占空比 **31% → 73%**。
- **低精度与算子** 利用 Blackwell 原生 FP8 做训推统一量化与 KV cache 压缩;inline PTX 与 TileLang 实现块缩放 GEMM,实测逼近硬件峰值;掩码稀疏投影与算子融合降显存。
- **异步与训推一致性** TIS 重要性采样修正训推不一致;同步频率与陈旧度双旋钮对照实验定位异步吞吐损失来源,确定生产配置。
