# 简历 · Infra 档

偏**框架、引擎与硬件**:verl/FSDP 训练框架排障、vLLM 推理服务优化、NCCL 通信与 FP8 算子。

## 工作经历

### Agentic RL 训练框架优化(verl / FSDP)

`2025.09 – 2026.03`

**背景** 消费级多卡上异步 Agentic RL,解决 verl 框架的权重同步与批组织机制的静默失效,确保训练正确性与吞吐。

- **正确性** 定位并修复三个指标正常但模型未学习的框架级静默缺陷,覆盖 FSDP 梯度归约、LoRA 权重下发、打包前向推 Rollout 端;修复后数值逐位验证,最小复现与修复提交 verl 与 PyTorch 上游。
- **吞吐** Agentic 训练 87% token 为组内重复题面,PrefixGrouper 前缀共享前向端到端提速 **2.31 倍**;掩码稀疏投影降显存 **39%**,长序列由 OOM 转为可训;Nsys / torch profiler 消除同步,生产步速提升 **28%**,整机 GPU 占空比 **31% → 73%**。
- **权重同步与 IO** 训推分离下 LoRA 增量热更新,同步载荷缩减 **33 倍**、仅占训练步时 0.8%,更新后做数值级验证;checkpoint 增量存档,落盘提速 **9.5 倍**、体积缩小 **12 倍**。
- **异步与训推一致性** TIS 重要性采样修正训推不一致,序列级与 token 级口径以数值实验定界;同步频率与陈旧度双旋钮对照实验定位异步吞吐损失来源,确定生产配置。

**成果**

- 后训练(数据、SFT、RL、评测)迭代周期压至天级
- 异常由常驻判据自动停机
- 全部性能优化确保训练质量零回退

### Agentic 负载推理服务优化(vLLM)

`2025.09 – 2026.03`

**背景** Agent 负载题面高重复、prefill 占比高,围绕 vLLM 优化,同时支撑 RL rollout 与业务端点双负载。

- **多卡拓扑与路由** 无卡间互联下选择 4 个独立引擎而非张量并行,自研前缀亲和路由让同一会话固定命中同一引擎的 KV cache;重负载扩展 **3.86 倍**、突发 TTFT P90 降 **40%**、缓存命中率 **98%**。
- **调度与稳定性** 为每个请求建立全链路耗时分账,定位数据库连接池等待、单进程 GIL、事件轮询三类瓶颈并逐一消除,goodput@SLO 提升 **3 倍**;杀掉 1/4 worker 实测零丢单;PD 分离以三项测量判定不适用于高缓存命中负载。
- **投机解码与量化** ngram 投机解码单流 TPOT 提速 **2.3 倍**、48 并发吞吐 **+41%**,逐字对比验证无损;FP8 KV cache 并发吞吐 **+50%**、TTFT P99 **23.6s → 10.0s**,质量以冻结评测配对回归背书。
- **执行层** CUDA Graph 消除 decode 微间隙,生成提速 **33%**;chunked prefill 粒度扫参,冷启动 TTFT 降 **12%**。

**成果**

- 单机四卡支撑 192 并发全 SLO 达标,吞吐 **735 → 2211 runs/min**
- 业务请求 P95 时延 **6.2s → 3.0s**

## 项目经历

### GPU 通信、算子与低精度训推 · 模型 + Harness + Infra Codesign

`2026.05 – 至今`

**背景** 以硬件物理上限为基准,在消费级 Blackwell(sm120)上做通信排障、低精度算子实现与训推统一量化。

- **通信** 定位 NCCL Simple kernel 的 16 字节对齐悬崖导致 AllGather 集合通信带宽骤降 **12 倍**的根因,应急协议切换恢复 **3.3 倍**,分片对齐根治方案提交上游。
- **算子** 识别 torch.compile 后端 triton 在 SM120 静默退化,使用 inline PTX 点亮 sm120 全部块缩放 MMA 指令,作为 FP8/FP4 指令峰值基准;TileLang / CUDA 实现该架构首个可用 MXFP8 块缩放 GEMM,达硬件峰值 **61%**;反向算子提速 **2.1 倍**并接入训练管线。
- **训推统一 FP8** 参照 B200 两侧同核 recipe、在消费级上复现路线,单开关同切 vLLM 与 trainer,两侧量化偏置对消 **9 倍**,RL 训练质量与 bf16 持平且零速度损失;模型主干逐层误差放大实验划出可用边界。
- **量化机理** 定位 FP8 舍入等效于采样温度微升的系统性偏置,随序列长度累积至重要性采样越界;以温度反向补偿实测缓解 **6 倍**,与两侧对消路线互相验证。
