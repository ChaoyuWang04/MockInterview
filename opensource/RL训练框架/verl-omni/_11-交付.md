# 第 11 章交付底稿

## 主旨、边界与基准

主旨:任务 Reward 之外,冻结 Teacher 在学生实际访问的状态上提供局部预测监督;监督是什么、如何路由与部署、代价落在哪里是本章主线。

正文以扩散 OPD 为主,全模态 OPD 仅说明与固定依赖 verl 的复用关系;DMD 只给真实实现边界,不写成已接通配方。Teacher 不与 Reward/Reference 混为一谈,不受旧“第三引擎”命名约束。

本项目快照 `/tmp/verl-omni-base`,b708218d5b62134ea75945a348d87f54c0c2fea2,v0.2.0;依赖 `/tmp/verl-omni-verl-base`,fefb080262e1c015a0ea05f958822a6a512dc795。证据中本仓 Python 相对 verl_omni,docs/examples 相对仓库根;上游证据明确标“依赖”。

## DMD 与其他否定性核查

在基准commit执行只读 `git -C projects/RL训练框架/verl-omni grep -n -E 'generated_x0|teacher_x0|fake_update_ratio|dmd_stage' b708218d5b -- verl_omni`。全部命中只在 `diffusion_algos.py` 的参数/消费/输入校验,`workers/config/diffusion/dmd.py` 和YAML默认中。`generated_x0`、`teacher_x0`没有引擎生产点,`fake_update_ratio`没有运行时消费者,`dmd_stage`没有训练器赋值者。固定快照全树rg同结果。因而不声称DMD训练路径已打通,也不把default fake_update_ratio=2称作实际运行频率。

DMD数值语义:normalizer为每样本全部非batch维的abs(x_g-x0_real)均值,epsilon下限;差值(fake-real)/normalizer后nan_to_num;surrogate target detach,mask仅控制最终reduction,全mask报错;fake-score target=noise.detach-x_g.detach。utils中的Euler、CFG与timestep shift是纯工具,不拥有模型或runtime。依据 `trainer/diffusion/distillation/utils.py:40-163`。

FM MSE损失要求teacher_noise_pred (`diffusion_algos.py:1168-1203`),现OPD Teacher仅产均值且校验明确拒绝附加FM MSE,不能把registry里存在视为runtime支持。
