## 二、一句话核心

Transformer Engine 解决的是:**Transformer 一层要在 NVIDIA GPU 上又快又不散**——把 Linear / Norm / Attention / MoE 收成可替换积木,用类似 AMP 的 autocast 打开 FP8 / MXFP8 / NVFP4,scale 和 amax 由库自己管。

它不是并行策略库。张量并行、流水并行、FSDP 怎么切卡,是 Megatron / FSDP 自己的解读;这里只写层内量化、融合,以及 Linear 接到 TP 时怎么把通信盖进 GEMM。

代码花在哪(基准 `git ls-tree -r -l`,含 CUDA,不含 `tests/`):

| 部分 | 体量 | 说明 |
|---|---|---|
| `transformer_engine/common/` | 4512 KB / 245 文件 | 框架无关的 C++/CUDA 核 |
| `transformer_engine/pytorch/` | 4301 KB / 174 文件 | PyTorch 模块、量化状态、绑定 |
| `transformer_engine/jax/` | 1721 KB / 77 文件 | JAX / Flax 绑定,接到同一份 C++ |
| `transformer_engine/debug/` | 152 KB / 21 文件 | 精度调试工具 |
| 合计 | 约 10.4 MB / 518 文件 | 解释本体 |

`docs/` 5.9 MB 是用户手册,主张采集的主来源,不计入解释本体体积。
