## 图与数字来源

唯一图 `06a-residency-tradeoff.svg`,1120×636。图示原分片规模 N=8,中间档 k=4,选值是合法因数教学例,不是推荐最优。均匀分片、相同 dtype、忽略 padding 时,前向后注册视图的本地元素量为 P/8、P/4、P、CPU 上 P/8。条长完整宽320,对应40/80/320/40,同一尺度。依据入口语义与 `_fsdp_param.py:985-1005`。图故意不称显存曲线:原始分片底座在中间档及完整保留时仍存在,且未包含梯度、optimizer、激活、通信缓冲。颜色绿=GPU 参数视图、黄=CPU 参数视图。图内 8/4 rank 是该例的 all-gather 参与规模。

典型配置三套均为按上述 API 语义推导的试验起点。2 节点×4 卡=8,连续 rank 布局决定整数4构造的小组能否留在节点内,未将其写成自动拓扑识别。没有卡型性能承诺。主机资源不足时不能据 offload 推出作业一定可运行。
