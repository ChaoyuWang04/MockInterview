# 代码索引

全项目一页,按章分节。路径都相对 `torch/distributed/`(基准快照 `/tmp/fsdp-base`)。**只写文件与符号名,不写行号**——行号随上游漂,符号名不会;要行号去各章的交付说明。

覆盖面与断言清单不在这里:底稿是 `_登记表.md`,每章的逐条断言在 `_0N-交付.md`。

## 01|一次迭代的形状

| 文件 | 符号 |
|---|---|
| `fsdp/__init__.py` | 两套 API 的统一导出,`__all__` 按 FSDP1 与 FSDP2 分组 |
| `fsdp/_fully_shard/_fully_shard.py` | `fully_shard`、`FSDPModule`、`register_fsdp_forward_method`、`UnshardHandle` |
| `fsdp/_fully_shard/_fsdp_state.py` | `FSDPState`(根状态默认保留参数)、`FSDPStateContext`、`_register_group_forward_hooks`、`RegisterPreBackwardFunction` |
| `fsdp/_fully_shard/_fsdp_api.py` | `MixedPrecisionPolicy`、`OffloadPolicy`、`CPUOffloadPolicy`、`DataParallelMeshDims` |
| `fsdp/_fully_shard/_fsdp_init.py` | `_init_default_mesh`、`_get_device_from_mesh`、`_init_param_group`(空参数与多网格分组) |
| `tensor/_api.py` | `DTensor.to_local`(分片参数对外是全局逻辑视图) |
| `checkpoint/state_dict.py` | `get_state_dict`、`set_state_dict`(两套实现共用的断点入口) |
