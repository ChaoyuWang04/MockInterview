## 真实调用与配置来源

- 表内保存/恢复序列根据上述 get/set/save/load 的真实签名编排,并非照搬可能存在旧版本示例的 docstring。没有训练/GPU 实测。
- 保存的 `model`、`optimizer` 是作者选择的顶层键;加载序列使用相同顶层键。`path`/`export_path` 是调用方提供的路径,不是框架默认。
- 常规恢复显式先用新布局获取目标状态;`set_state_dict` 使用 `state["model"]` 与 `state["optimizer"]`,保留非张量替换后的结果。模型/优化器已正确构造且张量已分配,不把此序列冒充初始化教程。
- 完整模型导出只调用 get_model_state_dict,所有 rank 参与;最终 torch.save 只在 rank0。未宣称这一文件可完整恢复训练。
- 自定义 scheduler/RNG/data progress 由上层应用携带;get_state_dict 的返回范围只有模型和优化器,依据 `state_dict.py:1271-1279,1356-1359`。不编造 FSDP 自动保存这些状态。
- 不做 API 漫游:ignore_frozen_params、flatten_optimizer_state_dict 等完整字段覆盖放在统一 StateDictOptions 符号索引,正文只列本主线的4项。
