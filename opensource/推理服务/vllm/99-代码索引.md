# vLLM 附录|代码索引:每一节对应源码的哪里

> 这一页不是写给读者的,是写给**要去源码里查出处的人**。前面各章的正文一律不写文件路径和行号,全部集中到这里。

## 怎么用这一页

按「章 → 小节」找到你在读的那一段,拿到**文件加符号名**,到 `projects/推理服务/vllm/` 下 grep 那个符号即可定位。

**为什么不写行号** :vLLM 主干一天合几十个提交,行号随时在漂——写进正文半个月就过期,而符号名几乎不变。需要精确到行的场合只有一种,就是更新源码基准时逐条复核,那份数据在项目底稿 `_登记表.md` 的核对清单里,每条断言都记着基准行号与逐字引用。

**分工**:这一页负责「去哪找」,底稿负责「当时是什么样」。

| `vllm/model_executor/models/registry.py` | 架构名 → 模型类的注册表,含跨进程惰性探测;新模型族的条目已指向 `vllm.models.*` |
| `vllm/model_executor/layers/` | 并行层、量化层、RoPE、norm、activation、fused_moe |
| `vllm/model_executor/layers/quantization/` | 量化方案库 |
| `vllm/model_executor/layers/fused_moe/` | MoE 融合层与 kernel 选择 |
| `vllm/model_executor/model_loader/` | 6 个 loader 类:`DefaultModelLoader` / `ShardedStateLoader` / `RunaiModelStreamerLoader` / `TensorizerLoader` / `ModelExpressModelLoader` / `DummyModelLoader`(共同基类在 `base_loader.py`),另有 `weight_tying.py`(绑定权重重连)、`weight_utils.py`、`checkpoint_weight_patch.py`、`ep_weight_filter.py`、`mtp_validation.py` 与 `reload/`(RL refit 用的分层热重载) |
| `vllm/model_executor/kernels/` | 量化与线性层的 kernel 选择与实现 |
| `vllm/model_executor/determinism/` | 批不变性(确定性推理)实现 |
| `vllm/distributed/parallel_state.py` | 进程组、TP/PP/DP/EP rank 管理 |
| `vllm/distributed/kv_transfer/` | PD 分离 KV 传输 connector 家族 |
| `vllm/entrypoints/` | OpenAI 兼容 API server(`openai/`)、CLI(`cli/`)、server 启动与路由(`serve/`、`launchers/`;`FrontendArgs` 住在 `launchers/cli_args.py`,不在 `arg_utils.py`)、`llm.py`(离线 `LLM` 类)、`speech_to_text/`(ASR 独立端点)、`generate/` / `pooling/` / `mcp/` / `scale_out/`,以及 `anthropic/` / `cohere/` 等其他协议兼容层 |
| `vllm/config/` | 配置中枢,按域拆成 `model.py` / `cache.py` / `scheduler.py` / `parallel.py` / `load.py` / `lora.py` / `multimodal.py` / `structured_outputs.py` / `compilation.py` / `speculative.py` / `kv_transfer.py` / `vllm.py` 等 |
| `vllm/multimodal/` | 多模态基础抽象(processing / registry / cache / hasher) |
| `vllm/lora/` | LoRA 的全部实现(不是遗留代码) |
| `vllm/sampling_params.py` | `SamplingParams` 参数类与请求级校验 |
| `vllm/envs.py` | 环境变量与开关(近三百个 `VLLM_*`) |
| `vllm/compilation/` | torch.compile 集成与融合 pass(含 SP pass) |
| `vllm/platforms/` | 硬件平台适配,会覆盖 block_size 等配置 |
| `csrc/` | C++/CUDA 源码(`attention/`、`core/`、`cpu/`、`cutlass_extensions/`、`libtorch_stable/`、`moe/`、`quantization/`、`quickreduce/`、`rocm/`;顶层 `cache.h`、`custom_all_reduce.cuh`、`ops.h`) |
