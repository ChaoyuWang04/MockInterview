## 图的每条关系

图 `08a-turn-and-interruption.svg` 是一种合法插话时序,不是所有轮次都固定出现的耗时形状;没有数值刻度。

| 图示关系 | 依据 |
|---|---|
| 第一轮VAD结束后进入回答 | `serve/realtime/session.py:418-429、446-465、563-587` |
| 回答时仍可收到第二轮输入,开始讲话触发取消 | `serve/realtime/session.py:155-178、394-417`;回答由独立队列任务创建 `:463-465、563-574` |
| 取消先标记再中止;迟到块不再发 | `serve/realtime/session.py:521-556、736-741` |
| 旧回答取消后继续旧轮转写,补用户历史 | `serve/realtime/session.py:588-603` |
| 第二轮收轮后排队,须等前轮完成与讲话结束 | `serve/realtime/session.py:418-429、460-465、563-577` |
| 旧轮历史就绪后下一轮构造请求包含它 | `serve/realtime/session.py:599-619、986-1007` |
| 客户端需自行停止已收到的音频 | 服务侧取消仅task/abort/事件, `serve/realtime/session.py:521-561`;音频已作为delta发送 `:756-768`,不是可撤回传输 |
