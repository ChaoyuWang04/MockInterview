## 题目

常见 NLP 基础任务有哪些?请说明分词、文本分类、NER、句法分析、机器翻译和问答的输入输出与常用指标,并讨论大模型时代是否还需要专用任务模型。

## 要点

- 先按序列、标签、跨度、树结构和生成结果区分任务
- BPE、WordPiece 是切分算法,SentencePiece 是可训练工具框架
- F1、BLEU 等指标仍有用,但必须结合任务与人工评估
- 是否保留专用模型取决于结构约束、延迟、数据与可解释需求

## 答案

**这些任务的本质区别在于输出结构不同,因此不能只用一个生成指标统一评价。**

| 任务 | 典型输出 | 常用评价 |
|---|---|---|
| 分词/Tokenization | 子词或 token 序列 | 未知词、序列长度、下游效果 |
| 文本分类/情感分析 | 一个或多个标签 | Accuracy、Macro/Micro-F1 |
| NER | 实体跨度及类型 | 实体级 Precision、Recall、F1 |
| 句法分析 | 依存边或成分树 | UAS/LAS、成分 F1 |
| 机器翻译 | 目标语言文本 | BLEU、COMET 与人工评估 |
| 问答 | 答案跨度或生成文本 | EM、F1、事实性与引用正确率 |

BPE 和 WordPiece 都从较小单元构造子词词表,但合并准则不同;SentencePiece 是直接在原始文本上训练和应用分词模型的框架,可承载 BPE 或 Unigram 等算法。词表更大不等于低资源语言一定更好,还要看语料覆盖、采样、切分长度和训练目标。

大模型可把多项任务统一成指令到文本,减少流水线接口;专用模型仍适合需要稳定结构、低延迟、高吞吐、端侧部署或严格错误边界的场景。NER、句法等中间结果若要进入搜索、审计或规则系统,保留结构化模块通常更易验证。资源有限时可选小模型微调、参数高效微调、蒸馏和量化,并用同一业务集比较精度、延迟和成本。

低资源翻译不能只靠扩大词表,更关键的是增加可信平行/单语数据、合理采样、跨语言迁移和质量评测。传统 F1、BLEU 仍能衡量指定维度,但开放生成还需语义、事实性、安全性和人工偏好等补充指标。

## 知识点

任务定义决定输出约束和评价指标;端到端大模型与专用模型是可组合的工程方案。
