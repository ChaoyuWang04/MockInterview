## 题目

离散视觉 Tokenizer 中的 VQ、RQ、FSQ 和 LFQ 有什么差异?它们与推荐系统中的语义 ID 又是什么关系?应如何选择和评估?

## 要点

- 比较显式码本、残差多级量化与有限标量量化
- 无显式码本不等于所有隐式码字必然使用
- 视觉 token 与推荐语义 ID 的下游目标不同
- 用码率、利用率、重建和下游生成共同评价

## 答案

**这些方法都把连续表示离散化,但离散空间的构造和训练目标不同,不能只按码本利用率排胜负。**

| 方法 | 离散方式 | 主要特点 |
|---|---|---|
| VQ | 在显式可学习码本中选最近向量 | 直观,但需处理离散梯度和死码 |
| RQ/RVQ | 多层依次量化前一层残差 | 用多个短码表示一个向量,可逐层增加精度 |
| FSQ | 各潜变量维度量化到少量固定标量级别 | 没有传统可学习码本,训练更简洁 |
| LFQ | 用分量或比特构成隐式组合码 | 避免对巨大显式码本做最近邻查找 |

FSQ 论文报告它不易出现传统 codebook collapse,但这不表示任何数据上所有笛卡尔积组合都会被访问。MAGVIT-v2 的 lookup-free quantization 也不是“用 Gumbel-Softmax 搜索 $O(K)$ 码本”;具体 LFQ 变体仍应按论文定义说明。

视觉 Tokenizer 主要压缩像素或潜变量,要保住纹理、结构和运动,供图像/视频重建与生成。推荐系统的语义 ID 则要让相似物品获得可生成、可检索的离散标识,重点是推荐排序、目录覆盖和 ID 冲突。两者都可使用残差量化,但优化目标不同。

选型时在固定码率和计算预算下同时测 active-code ratio、熵/perplexity、重建误差、感知指标以及下游生成或推荐指标。RVQ 层数和每层码本大小越大通常表达容量越高,也会增加序列长度、搜索空间和训练难度;应通过逐层残差能量、码利用率与下游收益决定,不存在通用最佳配置。

## 知识点

“码本是否显式存在”“一个向量用几个码表示”“离散表示服务什么任务”是三条独立比较维度。
