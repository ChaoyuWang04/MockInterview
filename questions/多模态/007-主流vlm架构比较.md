## 题目

请比较 CLIP、Flamingo、BLIP-2、LLaVA 和 Qwen-VL 的核心结构、训练目标、信息交互方式与适用场景。它们分别解决了什么问题，选型时应看哪些边界？

## 要点

- 先区分只输出表征或匹配分数的双编码器，与能生成回答的视觉语言模型
- 比较视觉特征怎样进入语言模型：查询压缩、层间 Cross-Attention 或输入投影
- 分开说明各模型公开的一手结构，不能把 Qwen-VL 的接入模块写成 Q-Former
- 训练目标随模型而异，不存在所有 VLM 通用的固定三阶段流程
- 选型要联合看任务输出、视觉细节、上下文长度、数据、时延和部署条件

## 答案

**这些模型不能只按发布时间排成一条“升级路线”，因为它们的任务接口不同。** CLIP 解决跨模态表征和匹配；其余模型把视觉证据接入语言生成过程，面向描述、问答、对话或定位。

| 模型 | 视觉与语言怎样连接 | 主要训练信号 | 擅长的接口与边界 |
|---|---|---|---|
| CLIP | 图像塔、文本塔独立编码，在向量空间比较相似度 | 双向图文对比目标 | 检索和开放词汇分类高效；不能直接生成回答，细粒度交互有限 |
| Flamingo | Resampler 压缩视觉特征，在冻结语言模型层间插入门控 Cross-Attention | 交错图文上的下一个 token 预测 | 适合图文交错和上下文少样本；需要改语言层并承担额外融合计算 |
| BLIP-2 | Q-Former 用固定数量查询读取冻结图像编码器，再连接冻结 LLM | 先做视觉语言表征学习，再做连接 LLM 的生成学习 | 以较少可训练模块复用两端模型；查询压缩可能丢视觉细节 |
| LLaVA | 视觉 token 经线性层或 MLP 投影后，作为输入 token 交给 LLM | 特征对齐预训练和视觉指令微调 | 结构简单、易扩展；成本随视觉 token 数增长，能力依赖数据和视觉塔 |
| Qwen-VL | 独立视觉编码器、视觉接收器与 Qwen 语言模型组成，训练包含多阶段数据与定位信号 | 图文预训练、跨模态预训练和指令阶段等 | 支持理解、文字读取和定位；具体接口随模型版本变化 |

CLIP 的两个模态只在损失层面相遇，所以可以把百万级图片预编码后做近邻检索。Flamingo 让每层文本状态主动读取视觉特征，适合多图交错上下文。BLIP-2 的 Q-Former先把大量视觉特征压成固定数量的查询输出。LLaVA 更直接：逐视觉 token 投影后拼入语言序列。Qwen-VL 也有视觉前端和接入模块，不能因为能统一输入输出就说所有模态从第一层开始完全共享参数。

选型先看输出：只要匹配分数或向量索引，双编码器通常更省；需要开放式回答，要选生成式 VLM。再看信息密度：文档小字、图表、定位和长视频需要更高分辨率、更多视觉 token 或保留空间结构。最后在同一数据和硬件上比较任务质量、首 token 延迟、吞吐、显存和失败类型，不能凭“结构更复杂”推断效果更好。

## 知识点

双编码器、视觉连接器、查询压缩、门控 Cross-Attention、视觉指令微调、模态融合位置和任务选型。
