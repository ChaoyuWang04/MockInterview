## 题目

统一多模态 Transformer 如何表示、对齐和融合文本、图像、音频或视频?请比较统一 token 序列、独立编码器加投影和 Cross-Attention 路线,并说明模态采样频率不一致时如何处理。

## 要点

- “统一”不要求所有模态共用同一个原始输入前端
- 对齐决定不同模态能否进入可比较或可交互的表示空间
- 融合可分为早期拼接、投影后输入与 Cross-Attention
- 采样、压缩和损失配比用于控制模态不平衡

## 答案

**统一多模态模型的关键是把各模态变成模型可消费的表示,建立跨模态对应关系,再选择合适的交互位置;它不等于音频、图像和文本必须共用同一个 Tokenizer。**

| 路线 | 表示与融合 | 适合的取舍 |
|---|---|---|
| 双/多编码器 | 各自编码后在共享空间做对比对齐 | 检索高效,细粒度生成交互有限 |
| 编码器+投影+LLM | 视觉/音频特征经投影成为 LLM 输入 token | 易复用预训练模块,接口清楚 |
| Cross-Attention | 主干表示通过交叉注意力读取另一模态 | 可控制插入位置和信息量 |
| 统一离散序列 | 多模态 token 混排,由同一主干建模 | 接口统一,但离散化和长序列成本更难 |

CLIP 是独立图文编码器加对比对齐;Flamingo 用视觉编码、Perceiver Resampler 和门控 Cross-Attention 接入语言模型;Chameleon 则把文本和图像离散 token 放入早期融合序列。这些实例说明“原生”与“拼接式”并非简单高下关系:模块化方案便于复用和替换,统一序列更利于共享生成接口,最终取决于任务与预算。

视频帧、音频采样点远多于文本 token,不能原样全部输入。可用 patch、卷积下采样、关键帧、向量量化、Resampler 或分层时间池化压缩,再用模态类型标识和时间位置表示保持顺序;训练时还要控制数据采样比例和各损失权重,避免高频模态主导梯度。

自回归适合把多模态输出统一成序列,扩散更擅长连续高维生成。实际系统也可以由自回归模型负责规划或离散 token,再由扩散解码器生成像素,无需强行二选一。
