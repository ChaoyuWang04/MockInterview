## 题目

请说明视觉语言模型的典型训练流程，包括数据准备、架构选择、跨模态对齐目标、分阶段训练和评估。为什么不能把所有模型都概括成同一个固定训练配方？

## 要点

- 数据要同时检查图文对应、覆盖、重复、泄漏、版权、隐私和安全
- 双编码器、查询连接器和输入投影面对不同目标，损失与训练阶段不能混用
- 对比、匹配、生成和指令监督分别解决全局对齐、细粒度判断与任务遵循
- 冻结范围和学习率按阶段与模块决定，不存在统一的固定数值
- 评测应拆开看感知、对齐、生成、幻觉、时延和资源成本

## 答案

**VLM 训练不是一条固定流水线，而是先明确产品接口，再组合数据、结构和训练信号。** 只做图文检索时，双编码器对比学习可能已经足够；要做开放式问答，还要让视觉表示进入语言模型并训练生成与指令遵循。

```mermaid
flowchart LR
  A[图文与交错数据] --> B[清洗 去重 权限]
  B --> C[视觉与语言模块]
  C --> D[表征或连接预训练]
  D --> E[多模态指令训练]
  E --> F[可选偏好与安全对齐]
  F --> G[分层离线和线上评测]
```

### 数据和架构先对齐任务

数据至少要保留图片身份、文字、区域或时间关系以及来源许可。清洗不能只用当前 CLIP 相似度一刀切，否则会删除难但正确的样本，并把现有模型偏差写回训练集。训练集、验证集和评测集要按原文档、视频或事件隔离，避免相邻帧和近重复图泄漏。

结构决定训练信号：CLIP 双编码器输出可检索向量；BLIP-2 用 Q-Former连接冻结视觉塔和 LLM；LLaVA 把视觉 token 投影进语言序列；Flamingo 在语言层间增加 Cross-Attention。选择时要结合输出形式、视觉token预算、是否复用已有模型和部署成本。

### 不同目标各解决什么

| 目标 | 学到什么 | 主要限制 |
|---|---|---|
| 图文对比 | 全局向量空间中的配对关系 | 对局部位置和生成能力监督较弱 |
| 图文匹配 | 联合表示下判断一对图文是否匹配 | 需要可靠负样本，计算通常高于双塔 |
| 描述或自回归生成 | 根据视觉条件生成文本 | 可能学会流畅描述却忽略视觉事实 |
| 多模态指令监督 | 按任务和对话格式回答、定位或调用工具 | 数据质量、任务覆盖和模板偏差决定能力边界 |
| 偏好或奖励训练 | 优化人工偏好、安全或可验证任务指标 | 是可选后训练，不是所有模型的必经第三阶段 |

代表模型的阶段也不同。CLIP 端到端训练双编码器；BLIP-2 第一阶段连接冻结图像编码器学习视觉语言表示，第二阶段连接冻结 LLM 学习生成；LLaVA 先训练投影连接，再做视觉指令微调。把 ITC、ITM、生成、指令微调和 RLHF 写成所有 VLM 必须依次经过的统一流程是不准确的。

### 训练和评测闭环

先冻结大模块可降低早期优化难度，发现领域视觉特征不足后再比较部分解冻、LoRA 或全量训练。高分辨率和视频增加视觉 token、激活、通信与样本长度方差，需要配合分桶、动态批处理、序列并行或视觉压缩；具体并行组合由模型、集群和框架决定。

评测应分层：编码器是否看清对象、文字与位置；图文匹配是否校准；答案是否忠于图像；视频顺序是否正确；不同人群和内容是否有偏差；最后再看吞吐、P95/P99时延和显存。多模态幻觉不能只靠语言流畅度评分，应让评审看到原图或可追溯的视觉证据。
