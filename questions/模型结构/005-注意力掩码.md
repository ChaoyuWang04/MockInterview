## 题目

在多头注意力中，mask 应加在哪一步，为什么必须在 softmax 前处理？请区分并说明 Causal Mask 与 Padding Mask 的表示、合并、广播和数值选择。

## 要点

- mask 加在缩放后的 attention logits 上、softmax 之前
- 因果 mask 屏蔽未来，padding mask 屏蔽无效键位置
- 0/1、布尔值及三角方向依 API 约定
- 两种 mask 的合并、shape 广播和 `-inf` 数值边界

## 答案

**mask 应转换成加性偏置，放在缩放后的 $QK^\top$ 与 softmax 之间。** 标准写法是：

$$
A=\operatorname{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}+M\right),\qquad O=AV
$$

允许读取的位置令 $M_{ij}=0$，屏蔽位置令 $M_{ij}=-\infty$，这样其 softmax 概率为 0。若内核不适合无穷值，可按 dtype 选足够小且不会溢出的有限负数。

Causal Mask 按查询和键的位置关系屏蔽未来；Padding Mask 对每个样本屏蔽补齐出来的键。两者同时存在时，按“任一条件要求屏蔽就屏蔽”合并，或把两个加性偏置相加。常见 logits shape 为 `[B,H,N_q,N_k]`，mask 可从 `[B,1,1,N_k]` 或 `[1,1,N_q,N_k]` 广播。

### 常见追问简答

- **为什么不在 softmax 后直接置零？** 剩余权重之和会小于 1；若再归一化才可能等价，但多做一步且更易出错。只把最终输出清零也阻止不了无效 V 污染其他位置。
- **0/1 mask 哪个代表屏蔽？** 没有统一答案；不同 API 的布尔语义相反，必须先读接口约定再转换。
- **下三角一定代表保留吗？** 取决于行列分别表示 query 还是 key，以及布尔语义，不能只看图形判断。
- **训练与推理有何区别？** 训练常构造完整三角 mask；增量推理的当前 query 天然只配已有 K/V，但 padding、分块边界仍需正确处理。

## 知识点

mask 改变 softmax 的归一化支持集。因果约束看位置关系，padding 约束看样本有效长度；表示语义由具体 API 决定。
