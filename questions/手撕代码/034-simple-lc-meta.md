## 题目

请现场实现一个力扣简单难度的算法题，例如两数之和或反转链表，要求代码正确、结构清晰。

## 要点

- 这是允许现场任选或由面试官指定的 meta 题，没有唯一输入输出。
- 写代码前确认具体题、函数签名、数据范围和边界契约。
- 先讲不变量，再编码并用最小边界样例走查。
- 时间、辅助空间和是否修改输入都要明确。

## 答案

当前记录没有指定最终抽到的是哪一道题，因此不存在唯一实现。合适的现场流程是：

1. 与面试官确认选择的题目和函数签名。
2. 复述输入、输出、是否保证有解、重复值、空输入和可变性约束。
3. 先给最直接的正确方案，再说明可利用的有序性、哈希、双指针或链表指针不变量。
4. 写完后走查最小输入、一般输入和一个易错边界。
5. 分析最坏时间、辅助空间和输出空间。

下面选择“两数之和”做一次完整示范。这里约定返回一对不同元素的下标；有多组答案时返回扫描中最先找到的一组，没有答案时返回 `None`：

```python
def two_sum(nums, target):
    seen = {}
    for right, value in enumerate(nums):
        left = seen.get(target - value)
        if left is not None:
            return left, right
        # 相同值再次出现时保留较早下标，使返回规则稳定。
        if value not in seen:
            seen[value] = right
    return None
```

扫描到 `right` 时，`seen` 只含左侧元素，因此返回的两个下标必然不同；先查补数再记录当前值，也能正确处理 `[3, 3]`、目标为 6 的情况。时间复杂度期望为 $O(n)$，辅助空间为 $O(n)$。

这个实现只是原题允许的示范选择。若现场改选“反转链表”，需重新确认是否允许原地改指针以及输入是否可能有环。平台老师展示的 LC 1 哈希解和 LC 206 三指针解不能被写成这条真题唯一指定的原题。
