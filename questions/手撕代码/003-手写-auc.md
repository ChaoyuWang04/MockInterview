## 题目

不使用 sklearn,手写计算 AUC。说明 AUC 的直观含义,并给出比暴力枚举更快的算法;分数有并列时怎么处理?

## 答案

**一句话理解**:随机抓一个正样本和一个负样本,模型给正样本打的分更高的概率,就是 AUC。所以 AUC = 0.5 等于瞎猜,AUC = 1 表示所有正样本的分都高于所有负样本。它只看**排序**,不看分数绝对值,也和阈值无关。

### 解法一:定义法(暴力)

枚举所有正负样本对,统计"正样本分更高"的比例,并列算 0.5 分。$O(P \cdot N)$,数据一多就慢。

### 解法二:排序秩和(面试要的)

把所有样本按分数**升序**排序,秩 rank 从 1 开始。正样本的秩之和,减掉"正样本内部互相比较"的那部分,再除以正负对总数:

$$
\mathrm{AUC} = \frac{\sum_{i \in \text{正样本}} \mathrm{rank}_i - \frac{P(P+1)}{2}}{P \cdot N}
$$

直觉:某个正样本的秩是 $r$,说明有 $r-1$ 个样本分数比它低,其中一部分是正样本(要减掉),剩下的都是它"赢过"的负样本。

```python
def auc(y_true, y_score):
    pairs = sorted(zip(y_score, y_true))          # 按分数升序
    n = len(pairs)
    ranks = [0.0] * n
    i = 0
    while i < n:                                   # 并列分数取平均秩
        j = i
        while j + 1 < n and pairs[j + 1][0] == pairs[i][0]:
            j += 1
        avg = (i + 1 + j + 1) / 2                  # 秩从 1 开始
        for k in range(i, j + 1):
            ranks[k] = avg
        i = j + 1

    P = sum(y for _, y in pairs)
    N = n - P
    if P == 0 or N == 0:
        return 0.5                                 # 只有一类,AUC 无定义
    pos_rank_sum = sum(r for r, (_, y) in zip(ranks, pairs) if y == 1)
    return (pos_rank_sum - P * (P + 1) / 2) / (P * N)
```

复杂度 $O(n \log n)$,瓶颈在排序。

### 两个必答的细节

- **并列分数必须取平均秩**:否则同分样本的先后顺序会人为影响结果,AUC 有偏
- **为什么不用准确率**:正负样本比例悬殊时(如 1:99),全预测负例准确率也有 99%,而 AUC 会诚实地给 0.5

## 知识点

AUC 的概率解释、ROC 曲线下面积、排序秩和公式、并列取平均秩、类别不平衡下 AUC 优于准确率;推荐/广告场景还常看 GAUC(按用户分组加权)。
