## 题目

已有等概率返回 1 到 5 的 `rand5()`，实现等概率返回 1 到 7 的 `rand7()`。证明结果无偏，计算期望调用次数，推广到 `randM()` 生成 `randN()`，并说明为何精确算法不能保证固定最坏调用次数。

## 要点

- 两次 `rand5()` 可构造 1 到 25 的等概率样本，不能直接对 25 个结果取模 7。
- 只接受 1 到 21，再模 7；每个输出恰好对应 3 个等概率原像。
- 单轮接受率 $21/25$，每轮调用两次，期望 `rand5` 调用次数是 $50/21$。
- 通用方法从 $M^k$ 个等概率状态中接受最大的 $N$ 的整数倍，再取模。
- 拒绝采样期望 $O(1)$，但循环次数无确定上界；固定有限调用不可能精确产生七等分。

## 答案

**先把两个 `rand5` 拼成 25 个等概率结果，只保留其中 21 个，再均匀映射到 7 个输出。**

```python
def rand7(rand5):
    while True:
        x = (rand5() - 1) * 5 + rand5()   # 1..25，每个概率 1/25
        if x <= 21:
            return (x - 1) % 7 + 1
```

接受区间 1..21 中，每个余数类恰好有 3 个值，所以 1..7 的返回概率都是 $3/21=1/7$。若直接对 1..25 取模，四个余数会多一个原像，产生模偏差。

一轮接受概率是 $21/25$，期望轮数 $25/21$；每轮用两次 `rand5`，期望调用次数为 $50/21$。可以回收 22..25 的剩余熵，再与后续 `rand5` 拼接以降低期望调用，但实现和证明更复杂。

通用 `randM → randN`：选择最小 $k$ 使 $M^k\ge N$，用 $k$ 次调用构造 `0..M^k-1` 均匀整数；令 `limit=floor(M^k/N)*N`，只接受 `<limit` 的值后 `%N`。若接受率太低，可增加 k 或回收拒绝区间。

算法的期望时间是常数，但最坏调用次数无界。若强制最多调用 $k$ 次，所有完整随机路径的概率分母都是 $5^k$；因为 7 不整除 $5^k$，无法把这些路径精确分成七个等概率集合。因此“严格最坏 $O(1)$ 且精确均匀”与当前随机源不兼容，只能接受近似偏差或允许拒绝重试。
