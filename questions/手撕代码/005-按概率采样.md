## 题目

给一个数组 `nums` 和等长的概率数组 `probs`(和为 1),实现一个函数,按照 `probs` 给定的概率随机返回 `nums` 中的一个元素。要求多次采样时尽量快。

## 要点

- 想到"累积概率 + 一个 0~1 随机数"这个转化
- 用二分查找把单次采样降到 $O(\log n)$
- 知道 Alias Method 能做到 $O(1)$

## 答案

**一句话理解**:把概率想象成一根长度为 1 的绳子,按 `probs` 切成 n 段——概率大的那段就长。随机往绳子上扔一个点,落在哪一段就返回哪个数。落点自然更容易落进长的段,这就实现了"按概率"。

"落在哪一段"用**累积概率(前缀和,即 CDF)**判断:第 i 段覆盖区间 $[\,\mathrm{cdf}_{i-1},\ \mathrm{cdf}_i\,)$,所以要找的是**第一个大于随机数的前缀和位置**——正是二分查找。

```python
import random, bisect

class Sampler:
    def __init__(self, nums, probs):
        self.nums = nums
        self.cdf = []                       # 累积概率:[p0, p0+p1, ...]
        s = 0.0
        for p in probs:
            s += p
            self.cdf.append(s)
        self.total = s                      # 不强制和为 1,兼容"权重"输入

    def sample(self):
        x = random.random() * self.total
        i = bisect.bisect_right(self.cdf, x)  # 第一个 > x 的位置
        return self.nums[min(i, len(self.nums) - 1)]  # 防浮点误差越界
```

- 预处理 $O(n)$,单次采样 $O(\log n)$;采一次就丢的场景直接线性扫也行
- 用 `total` 归一化,输入是**未归一化的权重**(如 [3, 1, 1])也能直接用
- `min(i, n-1)` 是必要的兜底:浮点累加误差可能让 `x` 略大于最后一个前缀和

### 进阶:Alias Method

把 n 个概率重排成 n 个"面积相等的桶",每个桶最多装两个事件。采样时先等概率选一个桶,再按桶内的分界值二选一——**单次采样 $O(1)$**,预处理 $O(n)$。采样次数极多(如推荐召回、负采样)时值得上。

## 知识点

累积分布函数(CDF)、前缀和 + 二分查找、按权重随机采样、Alias Method;LeetCode 528「按权重随机选择」就是这道题的标准版。工程上负采样、Top-p 采样的实现都基于同一套思路(见知识库 解码策略 篇)。
