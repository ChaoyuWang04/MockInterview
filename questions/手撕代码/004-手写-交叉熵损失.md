## 题目

手写交叉熵损失,分别实现二分类(BCE)和多分类(CE)两个版本。为什么工程实现都从 logits 出发而不是从概率出发?

## 要点

- 写对两个公式,并知道多分类只有正确类那一项起作用
- softmax 减最大值、logsumexp 这两个数值稳定技巧
- 说清"为什么用 logits 而不是概率"

## 答案

**一句话理解**:交叉熵衡量"模型给正确答案的概率有多低"。正确类概率越接近 1,$-\log p$ 越接近 0;概率越接近 0,惩罚越趋于无穷大——所以它对"自信地答错"惩罚极重。

### 两个公式

二分类($p$ 是预测为正类的概率):

$$
\mathcal{L}_{\mathrm{BCE}} = -\left[y\log p + (1-y)\log(1-p)\right]
$$

多分类(独热标签下,求和只剩正确类那一项):

$$
\mathcal{L}_{\mathrm{CE}} = -\sum_{c} y_c \log p_c = -\log p_{y}
$$

### 数值稳定实现

直接 `log(softmax(z))` 会溢出:`exp` 遇到大 logits 变 inf,概率变 0 后 `log(0) = -inf`。标准做法是减最大值 + logsumexp:

$$
\log \mathrm{softmax}(z)_i = z_i - \max(z) - \log \sum_j e^{z_j - \max(z)}
$$

```python
import numpy as np

def cross_entropy(logits, labels):           # logits: (N, C), labels: (N,) 类别下标
    z = logits - logits.max(axis=1, keepdims=True)          # 减最大值防溢出
    logsumexp = np.log(np.exp(z).sum(axis=1, keepdims=True))
    log_probs = z - logsumexp                                # log_softmax
    return -log_probs[np.arange(len(labels)), labels].mean()

def bce_with_logits(logits, y):              # logits: (N,), y: (N,) 取 0/1
    # 等价于 -[y*log(sigmoid(z)) + (1-y)*log(1-sigmoid(z))],但不会溢出
    return (np.maximum(logits, 0) - logits * y + np.log1p(np.exp(-np.abs(logits)))).mean()
```

`bce_with_logits` 那一行是 PyTorch 里的同名实现:把 $z>0$ 和 $z<0$ 两种情况合并成一个不会溢出的表达式。

### 为什么从 logits 出发

先 softmax 得到概率、再取 log,中间会丢精度甚至出 0;而 log_softmax 把两步合成一步,数学上等价、数值上稳定。所以框架都提供 `CrossEntropyLoss(logits, target)` 和 `BCEWithLogitsLoss`——**不要自己先 sigmoid/softmax 再送进去**,这是最常见的实现错误。

另外:交叉熵对 logits 的梯度非常干净,就是 $p - y$,这也是它训练稳定的原因之一。

### 为什么它等价于最大似然

对独立样本,最大似然要最大化正确标签概率的乘积 $\prod_i p(y_i\mid x_i)$。取对数后变成最大化 $\sum_i\log p(y_i\mid x_i)$；再加负号改成最小化,恰好就是交叉熵。对 softmax logits 求导可得

$$
\frac{\partial \mathcal L}{\partial z}=p-y.
$$

MSE 对模型输出的梯度是 $2(\hat y-y)/N$；若分类模型还在外面套 sigmoid,链式法则会再乘 $p(1-p)$,饱和区的梯度容易变小。交叉熵与 sigmoid/softmax 合并后得到 $p-y$,因此分类通常更直接。

## 知识点

交叉熵与最大似然等价、log_softmax 数值稳定、BCEWithLogits、梯度 $p-y$;延伸:label smoothing、focal loss(类别不平衡)、KL 散度与交叉熵的关系(见知识库 KL散度 篇)。
