## 题目

请系统介绍几种主流的对比学习方法（如SimCLR、MoCo、CLIP等），并深入分析它们在视觉-语言预训练模型中的应用方式、核心机制、技术特点及相互之间的区别与演进关系。

## 要点

- 正例对应需保留任务语义,其他实例不一定都是真负例
- 对比损失在候选集合中识别正例
- 区分增强、动量队列和图文双塔三种机制
- 解释对比表示与生成式重构、视觉指令微调的关系

## 答案

**对比学习通过构造正负关系,让表示保留有助于识别匹配对象的信息;SimCLR、MoCo 和 CLIP 的主要区别是正例来自哪里、负例如何组织。** 一种常用目标为

$$
L=-\log\frac{\exp(s(q,k^+)/\tau)}{\exp(s(q,k^+)/\tau)+\sum_{j=1}^{K}\exp(s(q,k_j^-)/\tau)}
$$

相似度 $s$ 经温度 $\tau>0$ 缩放,分母包含正例。它相当于在 $K+1$ 个候选里识别正类;错误配对和语义重复的“假负例”会扭曲监督。

| 方法 | 正例与负例 | 关键机制与代价 |
|---|---|---|
| SimCLR | 同一图像的两种增强为正例,批内其他视图作负例 | 编码器后接非线性投影头,较大 batch 扩充候选但增加显存 |
| MoCo | 同实例增强配对,历史 key 队列提供负例 | key 编码器按 query 参数的指数移动平均更新,保持队列表示相对一致;旧特征仍有滞后 |
| CLIP | 配对图像与文本为正例,批内非配对项作候选负例 | 图文双编码器映射到共同空间,优化双向对比目标;可用类别文本做零样本分类 |
| SimCSE | 无监督版本同一句子经两次独立 Dropout 得到正例 | 不同句子作为批内负例,仍需关注语义相近句被误排斥 |

CLIP 原论文使用 32,768 的 minibatch,目的是在每步获得大量图文候选;这是其具体训练配置,不是所有对比学习模型都必须照搬的阈值。更大的 batch 会增加候选数,也会增加显存、通信和假负例风险。

CLIP 从图文对应关系学习跨模态对齐,不是从单模态损失自动推导出对齐;它仍使用图像裁剪增强,温度可学习。大规模配对数据也可能包含偏差,不能保证只学到本质语义。

### 改进与生成模型的关系

FILIP 用图像 patch 与文本 token 的细粒度后交互相似度改善全局对齐的局限;DeCLIP 增加模态内自监督、多视图及近邻监督来提高数据利用。它们不等于通用难负样本挖掘,真正的采样与假负例处理见 [难负样本选取](071-难负样本选取.md)。

MAE、BERT MLM 通过恢复被遮盖内容学习表示,较少依赖显式负例,但重构目标可能保留检索不需要的细节;对比学习可直接优化相似度结构,代价是增强和配对设计。LLaVA 继承 CLIP 预训练视觉编码器,再通过连接层和生成式 token 损失学习视觉指令,并非原样继续优化 InfoNCE。温度与负例数量的工程取舍见 [InfoNCE 与 BCE](043-infonce与bce.md)。
