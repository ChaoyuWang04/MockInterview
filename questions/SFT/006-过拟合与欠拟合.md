## 题目

请定义机器学习中的欠拟合与过拟合,结合偏差-方差权衡说明成因及对泛化能力的影响,列举识别方法及至少三种针对每种现象的解决方案和原理。过拟合请进一步列举至少五种表现、五种缓解方法,并从数据、模型结构、正则化、训练策略等维度,结合大模型训练与微调说明适用条件与局限。

## 要点

- 用训练与独立验证表现区分拟合不足和训练样本上的过度特化
- 列出至少五种过拟合信号,说明单个信号不能独立确诊
- 欠拟合至少三种、过拟合至少五种干预,均解释原因
- 说明 SFT 的评估与早停,不把遗忘、分布偏移全部称为过拟合

## 答案

**欠拟合是训练集规律也没学好;过拟合是训练集继续变好,对新样本的泛化却变差。** 前者常与高偏差有关,后者常与高方差有关,但还需排除优化失败和数据分布偏移。

在平方损失、噪声条件均值为零的设定下,固定输入处的期望测试误差可分成偏差平方、方差与不可约噪声。偏差衡量平均预测离真实规律多远,方差衡量换一批训练数据后预测变动多大;这不是任意任务损失都原样成立的分解。

### 怎样识别

同时看训练/验证曲线随训练步数和数据量的变化;小数据可交叉验证,时间或用户相关数据应按时间/用户划分,避免泄漏。五类过拟合信号是:①训练损失下降而验证损失回升;②验证 F1 等业务指标变差;③能复述训练样本却做不好未见样本;④分类边界追随个别噪声点;⑤输入做保语义改写后表现骤降。**边界复杂或对扰动敏感只是线索,需独立验证表现佐证。**

### 怎样干预

| 现象 | 方法与作用原理 | 适用边界 |
|---|---|---|
| 欠拟合 | 增加容量/有效特征,让模型能表达规律 | 先排除错标与目标不匹配 |
| 欠拟合 | 减弱正则化,放宽参数约束 | 训练改善后继续监控验证集 |
| 欠拟合 | 优化学习率、训练更久,让优化充分进行 | 损失已不再下降时不能只堆步数 |
| 过拟合 | 增加独立数据或保语义增强,减少对个例的依赖 | 重复模板不等于增加多样性 |
| 过拟合 | 权重衰减/L2,限制参数增长 | AdamW 与 Adam 加 L2 的区别见 [L1 与 L2 正则化](026-l1与l2正则化.md) |
| 过拟合 | Dropout 随机屏蔽激活,减少共同依赖 | 强度过大也会欠拟合 |
| 过拟合 | 早停并恢复最佳验证检查点 | 需要有代表性的验证集 |
| 过拟合 | 缩小可训练容量,如冻结层或 LoRA | 减少自由度,但不保证消除过拟合 |

### 大模型与来源追问

- **SFT 的特殊表现与早停:**除验证损失外,检查新指令、改写提示、域外任务及通用能力。每隔固定步数评估,若主指标连续若干次未改善就停并恢复最佳版本;等待次数和最小改善幅度按评测噪声设定。训练只认识模板是特化,通用能力退化也可能是遗忘。
- **预训练和全量微调:**预训练常有更多样的数据、更少重复轮次,应重视去重、质量和域外验证;SFT 小数据反复训练更容易记忆,可降低学习率、早停、限制可训练参数并检查通用能力。预训练同样可能过拟合;全量微调相对小模型也不是必然风险更高。
- **参数多为何仍能泛化:**数据规模、预训练起点、优化的隐式偏好和显式正则化共同影响结果。双下降指某些设定中测试误差在刚能拟合全部训练数据的插值阈值附近升高,继续增加容量后又下降。它说明经典 U 形曲线不是全部情形,不能推出“大模型不易过拟合”。
- **SFT 与 RLHF:**SFT 可过拟合示范答案;RLHF 可出现奖励上涨、独立人评或留出任务下降,需区分过拟合与奖励投机。LoRA 的秩过小限制适配,过大增加自由度和成本,选法见 [LoRA 原理与秩选择](002-lora-原理与秩选择.md)。
- **早停与正则化同时用:**正则化改变收敛速度,应重新调等待时间;约束过强又停太早可能欠拟合。固定评估口径,不要直接比较带正则项的训练损失与不带正则项的验证损失。
- **数据还是容量问题:**先检查标签、特征和小批量拟合;再控制其他变量,分别清洗数据、增加容量并比较学习曲线。加容量仍学不好不能直接判为容量不足。
