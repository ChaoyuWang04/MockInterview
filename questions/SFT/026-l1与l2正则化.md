## 题目

请系统比较 L1 与 L2 正则化在数学表达形式、对模型权重的影响机制、产生的模型特性(如稀疏性)、优化难度以及典型应用场景中的主要区别,并结合实际训练经验说明在大模型微调中如何选择合适的正则化方法。

## 要点

- 比较绝对值惩罚与平方惩罚的梯度、几何直觉和稀疏性
- 区分 L1 的稀疏最优解与普通梯度更新能否精确归零
- 说明 Adam 加 L2 与 AdamW 的更新区别
- 微调选法取决于泛化或压缩目标,不给通用衰减系数

## 答案

**L1 倾向让部分权重归零,L2 倾向平滑缩小权重;在 Adam 中,给损失加 L2 与独立做权重衰减不等价。** 设数据损失为 $L_0$,权重为 $w$,正则强度为 $\lambda>0$:

| 比较项 | L1 | L2 |
|---|---|---|
| 目标函数 | $L_0+\lambda\sum_j\lvert w_j\rvert$ | $L_0+\frac\lambda2\sum_jw_j^2$ |
| 惩罚的梯度 | 非零处为 $\lambda\operatorname{sign}(w_j)$,零处用次梯度 | $\lambda w_j$,大权重受到更大收缩 |
| 特性与直觉 | 约束边界有坐标轴尖角,常产生稀疏解 | 约束边界平滑,通常分摊权重而非筛掉特征 |
| 优化与场景 | 不可微但可用次梯度、坐标下降或近端法;适合特征选择与稀疏建模 | 光滑,容易结合梯度优化;适合限制权重规模 |

例如 L1 的近端更新把一次梯度步后的值 $u$ 变为 $\operatorname{sign}(u)\max(\lvert u\rvert-\eta\lambda,0)$,$\eta$ 为学习率;小值因此精确归零。**普通 SGD/Adam 直接加 L1 不保证得到精确零**,非凸网络也不能沿用凸问题的全局保证。L2 不主动偏好稀疏,不代表权重绝不可能为零。

### Adam 中的区别

普通 SGD 加上述 L2 得到 $w\leftarrow(1-\eta\lambda)w-\eta\nabla L_0$,与相应权重衰减等价。Adam 加 L2 时,$\lambda w$ 进入梯度的一、二阶矩,衰减被自适应缩放;AdamW 则在数据梯度更新外独立缩小权重,不把衰减项混入矩估计。系数应连同学习率、训练轮数在验证集上选择。

### 大模型微调如何选

目标若是泛化,可先比较较弱权重衰减、早停、Dropout、数据多样化及 LoRA 等容量限制。LayerNorm 调节激活分布,不等价替代 Dropout。直接 L1 带来的非结构化零值未必被密集计算内核利用,还可能损害预训练能力;需要压缩时应同时设计稀疏结构、优化方法和部署支持,不能把“参数为零”当成提速。若要保持原模型行为,可按任务加入参考分布约束,而非一味把全部权重拉向零。


### 相关特征、先验与组合

Elastic Net 用 $L_0+\lambda_1\|w\|_1+\frac{\lambda_2}{2}\|w\|_2^2$ 结合稀疏选择与平滑收缩。高度相关的特征中,纯 L1 选择可能不稳定,L2 有助于稳定共同分担;需要同时筛选时可比较弹性网络。数值特征宜先按训练集尺度处理,否则相同惩罚对不同量纲不公平。

数据损失为负对数似然时,L1/L2 可分别解释为拉普拉斯/高斯先验下的 MAP。不可导不妨碍使用次梯度或近端法;凸问题满足相应步长等条件时有收敛保证,非凸神经网络不保证全局最优。线性平方损失的 Ridge 有闭式解,不能推广到任意带 L2 的模型。

LoRA 冻结主干而只训练低秩参数,仍可对这些参数设置权重衰减或 Dropout,与秩、轮数一起调节;限制秩不等于不需要正则化。L1 若配普通 Adam 未必产生精确零,即使产生非结构化稀疏也未必省计算。选法应由泛化、压缩需求及内核支持决定;没有调查资料时不报告“实际使用频率”。
