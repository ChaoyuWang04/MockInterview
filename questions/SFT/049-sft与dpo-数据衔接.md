## 题目

在采用 SFT(监督微调)与 DPO(直接偏好优化)联合训练的大模型对齐流程中,训练数据如何系统性组织?请说明两个阶段的数据格式、来源、样本构造及衔接逻辑,并比较自建数据与公开数据在质量、成本、领域适配和工程效率上的取舍。

## 要点

- SFT用示范回答,DPO用同一prompt的可靠偏好对
- 基于SFT起点构造偏好,不把随机差答案当作高质量负例
- 按prompt与近重复分组划分数据,区别泄漏和监督冲突
- 来源配比由覆盖与验证决定,降低标注成本不能取消质量检查

## 答案

**先用可靠示范建立任务行为,再让偏好对覆盖这个策略真实会犯的错误。** 两阶段可以衔接,但没有固定的数据量或自建/公开配比。

### 数据格式与来源

| 阶段 | 样本 | 来源与质量要求 |
|---|---|---|
| SFT | prompt/对话历史与示范回答 | 人工、业务记录或合成示范;答案正确、模板一致,只对目标回答计算损失 |
| DPO | 同一 prompt 的 chosen/rejected | 当前策略候选经人、模型或可验证规则比较;语境一致、标准明确、优劣可信 |

公开数据适合快速建立覆盖广的基线,但要审查领域、许可、隐私和模板;自建数据贴近业务且标准可控,却消耗采样、标注和复核成本。领域差异大时,先按任务和语义筛选,补缺口;改写要保持事实与约束,经规则或人工检查,不能只替换业务名词。SFT 质量差会使起始策略和生成候选都偏离目标,DPO 无法凭不可靠偏好自动补齐基础能力。

### 采样、标注与两阶段衔接

从合适的 SFT checkpoint 初始化策略和冻结参考策略,采样多个有差异的回答,明确正确性、安全性、格式等判断维度。过滤重复、明显无效或无法比较的回答,再构造可信且有区分度的偏好对。拒绝采样可先筛掉不满足硬条件的候选;始终只配“最好对最差”容易学到长度或格式捷径,也应覆盖接近且可判定的错误。

降低标注成本可用规则验证、模型初评和去重,把分歧或高价值样本交人工复核;随机交换候选顺序、盲化来源并抽检,防止位置和自我偏好。只保留胜者可继续 SFT,保留胜负关系才能形成 DPO 信号。

按 prompt、用户/文档来源和近重复分组拆分训练与评测。SFT 答案成为 DPO rejected 不自动等于泄漏:若有更好的答案,可以有一致的相对偏好;真正要排除评测污染及互相矛盾的标准。

### 数据效率与配比

标准 DPO 可反复使用离线偏好对,省在线采样与显式 RM;PPO 在训练中生成新回答,能利用当前策略覆盖和外部奖励,但消耗采样与打分预算。没有统一谁“每条数据更高效”的排序。

分别画示范规模与偏好规模的验证收益曲线。基础任务没学会先补 SFT;基础合格但质量排序不佳再补可靠偏好。业务分布改变、收益饱和或保留能力回退时调整配比,同时按有效 token 和标注成本计量,不照搬70/30等示例。

### 训练顺序与 Agent 边界

常见顺序是先 SFT、后 DPO:先让策略学会任务格式和基本行为,再用偏好对调整“两个可用答案中更喜欢哪个”。DPO 后仍可补 SFT,例如修复格式或补新知识,但普通 SFT 目标不保留偏好分差,可能冲淡刚学到的对齐效果;需要混合目标、回放偏好数据或分阶段评测,不能默认顺序可随意交换。

Agent 长程任务的成败常由多步决策共同造成,只给完整轨迹一个胜负标签很难指出哪一步该改。可以比较同一中间状态后的分支、增加步骤或子目标反馈,或改用能与环境继续交互的在线 RL。DPO 是否优于 SFT 取决于偏好信号是否可靠且可归因,没有统一结论。
