## 题目

请详细解释 LoRA 和 QLoRA 的基本原理,比较它们在大模型微调中的异同,并从参数更新机制分析二者如何缓解灾难性遗忘,以及这一作用的边界。

## 要点

- LoRA 冻结基座、训练低秩增量;QLoRA 进一步量化基座存储
- 区分可训练状态、基座权重和激活显存
- 低秩约束不限制增量范数,冻结不保证启用适配器后保留能力
- 用原任务与目标任务对照定位量化、遗忘或优化问题

## 答案

**QLoRA 在 LoRA 的低秩更新之外,进一步压缩冻结基座的存储。** 二者都只更新适配参数,但启用适配器后的模型仍会改变行为,不能据此保证没有遗忘。

| 比较点 | LoRA | QLoRA |
|---|---|---|
| 有效权重 | $W_0+sBA$ | $\operatorname{dequant}(Q(W_0))+sBA$ |
| 基座 | 通常以 BF16/FP16 等精度存储并冻结 | 通常以 NF4 4-bit 存储并冻结 |
| 更新对象 | A/B 及明确声明的额外参数 | 高精度 A/B,不直接优化 4-bit 编码 |
| 节省来源 | 大量基座梯度与优化器状态 | 进一步减少基座权重及量化元数据 |

QLoRA 的双重量化压缩分块缩放常数,分页优化器缓解瞬时内存峰值。原论文在特定配置下用单卡 48GB 微调 65B;普通 16-bit 65B 基座裸权重已约 130GB,不能把这个成绩归给常规 LoRA。量化不消除激活,反量化也有开销。

### 遗忘与秩的边界

LoRA 把更新限制在选定层的低秩形式,有时减少对原能力的破坏;但低秩矩阵可以有很大的范数,r 小也可能遗忘,r 大也不必然遗忘。关闭独立适配器可恢复其冻结基座,与“使用适配器时仍保留通用能力”是两回事。QLoRA 关闭适配器恢复的是量化基座,量化误差已经可能改变输出,并没有额外的知识隔离保护。

### 如何诊断和缓解

先分别评测原始基座、量化基座和微调后模型,在目标任务与保留任务上比较质量、困惑度及错误类型,从而区分量化损失和训练遗忘。固定模板、解码和数据拆分,再查回答掩码、训练步数、学习率、目标层与秩;相关容量诊断见 [超参数调优](031-lora-超参数调优.md)。

可降低优化强度、早停、重放可靠通用样本,或为独立任务保留独立适配器。增大 r 应由受控验证支持,不是见到掉点就加秩。NF4 基座仍参与前后向,梯度经反量化后的权重传给 A/B,无需对冻结的离散编码求更新梯度;若量化误差主导,比较更高精度 LoRA。NF4 与 INT8 的误差、块大小和计算精度见 [NF4 与计算精度](083-qlora-nf4与计算精度.md)。
