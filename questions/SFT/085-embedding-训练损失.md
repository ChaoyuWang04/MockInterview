## 题目

Embedding 微调常用哪些损失函数?请给出对比损失与三元组损失的数学形式和直觉,说明如何选择正负样本以及调节温度。

## 要点

- 损失应让相关内容更近,不相关内容更远
- 区分候选间竞争和正负相对间隔
- 相似度与距离的方向相反,公式符号不能混用
- 难负例需要核实相关性,温度不能替代数据质量

## 答案

**Embedding 训练是在塑造向量之间的关系。常见做法是让 query 在候选中认出正例,或者要求正例比负例更接近 query 一定的距离。**

### 候选间竞争:InfoNCE类损失

对一个 query 向量 $q$,正例 $d^+$ 和负例 $d_j^-$,一种常见形式是:

$$
L=-\log\frac{\exp(s(q,d^+)/\tau)}{\exp(s(q,d^+)/\tau)+\sum_j\exp(s(q,d_j^-)/\tau)}
$$

$s$ 是相似度,越大越接近;$\tau>0$ 是温度。它把候选相似度当作分类分数,提高正确文档在这组候选中的概率。负例越像正例,越容易占走概率,对训练影响也越大。语义检索通常适合这种“从一组文档里选相关文档”的目标。

这里写的是**单正例**形式。一个 query 有多个相关文档时,需要显式使用多正例目标或屏蔽相关项,不能把其他相关文档都当负例。批内负例只是复用别的样本作为候选的方式,不是它们必然不相关的证明。

### 相对间隔:三元组损失

对锚点 $a$、正例 $p$、负例 $n$,以距离 $d$ 定义:

$$
L=\max(0,d(a,p)-d(a,n)+m)
$$

$m>0$ 是要求的间隔。若正例距离 0.2、负例距离 0.8、间隔 0.3,损失已经为零;若负例离得只有 0.4,损失为 0.1,仍需拉开。

**若改用越大越近的相似度,就要反过来写成** $\max(0,s(a,n)-s(a,p)+m)$。三元组适合直接表达相对排序或间隔要求,但大量太容易的三元组梯度为零,效果依赖采样。它也属于广义对比学习方法,不能把“对比损失”和“交叉熵”看成互斥类别:上面的 InfoNCE 本来就具有候选分类的交叉熵形式。

### 正负样本与温度怎样选

正例应对应真实任务:检索用能回答 query 的文档,同义匹配用等价表达。负例先混入随机不相关项,再加入检索器找出的“文字很像但答非所问”的难例。难例必须检查是否其实也能回答问题,否则是在强行推开正确答案。重复文档、同义 query 和多答案尤其容易制造假负例。

温度越低,候选概率越尖锐,高相似度负例的影响往往更集中;过低会放大错标和假负例,过高则区分较弱。相似度尺度、向量归一化、负例数量都影响合适的温度,因此与采样策略一起调,用独立检索验证集比较 Recall@K、排序质量与稳定性,不背固定数值。
