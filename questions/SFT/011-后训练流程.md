## 题目

请系统阐述大语言模型在预训练之后的后训练(Post-training)完整流程,详细说明监督微调(SFT)、奖励建模(Reward Modeling)和基于人类反馈的强化学习对齐(如 PPO)等关键阶段的目标、数据形式、技术实现及其在模型对齐中的作用。

## 要点

- 区分示范学习、偏好建模与基于奖励的策略优化
- 讲清三个阶段的数据、训练对象与依赖关系
- PPO 用优势估计和裁剪控制更新,RLHF 常另加对参考策略的 KL 约束
- 回答为何不能只增加 SFT 轮次,以及稳定性、DPO 与 reward hacking
- 说明这是典型流程,对齐税仍需评测和缓解

## 答案

**典型流程是先用示范教模型回答,再把人类偏好训练成评分信号,最后用评分改进生成策略。** 这是 InstructGPT 式路线,并非所有后训练都必须经过三个阶段。

| 阶段 | 数据与目标 | 怎么训练 |
|---|---|---|
| SFT | 指令与示范回答,学习遵循指令 | 对回答 token 做交叉熵训练,可全参或 LoRA |
| RM | 同一 prompt 的优选/劣选回答,学习相对偏好 | 模型输出标量,用成对损失提高优选回答的相对分数 |
| PPO 对齐 | prompt 与策略新生成的回答,提高期望奖励 | 冻结 RM 打分,critic 估计价值,用优势指导策略更新 |

RM 通常从已有语言模型初始化并加评分头。RL 的策略通常从 SFT 模型起步;critic 是预测回报的基线,不等于判定人类偏好的 RM。PPO 裁剪新旧策略的概率比以限制单次更新,RLHF 再用对固定参考策略的 KL 惩罚约束累计偏移;实际 token 级优势可用 GAE 估计,不是都简化为一个终局分数减常数。

### 为什么继续 SFT 不够

多训示范仍在优化“复现这个答案”,没有引入“两个回答谁更好”的新监督。偏好优化可把安全、准确和风格等比较信号纳入目标,但 SFT 并不存在“永远无法超过标注者”的定理,RL 也不保证输出必然更好。

### 稳定性、替代路线与闭环

- **PPO 不稳:**先查偏好标注、RM 过拟合及奖励尺度,再检查优势估计、学习率、裁剪和 KL。DPO 直接用偏好对更新策略,省去显式 RM、critic 和在线采样,但仍会受坏数据及过优化影响。
- **奖励被钻空子:**查看真实任务效果与 RM 分数是否背离;用独立评测、长度/格式去偏、当前策略的新偏好数据、KL 约束及早停共同缓解,不能承诺彻底杜绝。
- **迭代与对齐税:**用新反馈更新数据和评分器,选通过人评及通用能力评测的版本。对齐可能牺牲部分原有能力;混入预训练目标或保留数据可缓解,RLHF 本身不会自动消除这种代价。
