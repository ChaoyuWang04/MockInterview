## 题目

在监督式微调(SFT)过程中,如何设计损失函数以确保仅对模型生成的回答部分进行计算?请详细说明如何通过 mask 机制正确忽略输入提示(prompt)、填充 token 对损失和梯度的影响,并解释其在训练实现中的关键作用。

## 要点

- 用标签掩码选出回答目标,将提示词与填充标签设为忽略值
- loss mask 决定哪些目标计损失,attention mask 决定能看哪些输入
- 提示词没有直接预测损失,但其计算仍参与回答损失的反向链路
- 正确对齐下一 token 目标,保留回答结束标记,检查多轮边界

## 答案

**保留完整提示词作为上下文,只对回答位置的目标计算交叉熵;忽略标签不等于切断提示词的计算图。**

设序列为 $x$,目标位置 $t$ 的掩码为 $m_t$:回答及其结束标记取 1,提示词和填充取 0。

$$
\mathcal L=-\frac{\sum_t m_t\log p_\theta(x_t\mid x_{<t})}{\sum_t m_t}
$$

也就是只平均有效回答 token 的预测错误。可把无效标签设为交叉熵的忽略值(如 `-100`),或对逐 token 损失显式加权;整批没有有效目标时应跳过,避免除零。

### 三个容易弄错的位置

1. **梯度**:提示词没有自己的目标损失,但回答会注意到它的隐藏状态,梯度仍可沿这条路径更新共享权重。把提示词删掉或 detach,都会改变训练目标或梯度。
2. **错位**:位置 $t-1$ 的输出预测 $x_t$。手算损失时配对 `logits[:-1]` 与 `labels[1:]`;若训练接口已经位移,不能再移一次。首个回答 token 的监督尤其容易丢。
3. **两种掩码**:attention mask 屏蔽 padding 并配合因果可见性;label mask 只挑监督目标。EOS 与 pad 同 ID 时按真实长度区分,不能按 ID 把回答末尾的 EOS 一起删掉。

多轮对话根据结构化角色边界标出每段 assistant,可监督所有回复或只监督末轮。若误把 prompt 加入损失,就引入“预测用户提问”的额外任务,改变目标权重,不等于必然训练崩溃。检查时应解码有效标签,确认首个回答、结束标记和有效计数都正确。

### 自回归交叉熵与大词表

训练通常用真实前缀并行计算下一词元预测,因果掩码防止偷看未来;不是每步先采样一个词再训练下一个。对目标类别 $y$ 与 logits $z$,单位置交叉熵为 $-z_y+\log\sum_j e^{z_j}$,对 logits 的梯度为 $p_j-\mathbf1[j=y]$。提高真实词元条件概率等价于最大化训练序列似然,促使共享表示学习可预测的语言规律,不保证知识真实。

离散词元不能直接按 token ID 的距离做 MSE;若对类别概率做 MSE,它虽可用,梯度和概率目标也不同,详见[分类损失比较](003-二分类-mse与交叉熵.md)。实现无需物化 one-hot 标签,传目标索引即可。padding 仍按上文有效标签忽略并归一化。

词表很大时,可分块或融合计算正确词元的 logit 与全词表 log-sum-exp,避免保存完整 token×词表 logits;参考[Cut Cross-Entropy](https://arxiv.org/abs/2411.09009)。词表并行还须全局归约保证归一化一致;采样 softmax 等近似则改变计算目标或估计方式,要另评质量。
