## 题目

参数高效微调(PEFT)技术如何在降低大模型微调成本的同时缓解灾难性遗忘问题?请结合原理,举例说明几种典型的 PEFT 方法及其作用机制,并分析它们在实际应用中的优势与差异。

与全量微调相比,这些方法分别适合什么场景?

## 要点

- 只更新少量参数,主要减少梯度、优化器状态及任务权重存储
- 限制更新范围可能减轻遗忘,但冻结基座不保证模型行为不变
- 区分 LoRA、Adapter、Prefix-tuning、BitFit 的参数位置与推理开销
- 秩选择及强知识注入要依靠目标任务与原有能力的联合评测

## 答案

**PEFT 缩小可训练参数范围,因此少存梯度和优化器状态;受约束的更新也可能减少对原有能力的干扰。** 基座权重和反向传播需要的部分激活仍占显存,所以参数省多少不等于训练时间也省多少。

| 方法 | 学什么 | 推理与能力取舍 |
|---|---|---|
| LoRA | 线性权重的低秩增量 | 可合并回原矩阵,消去旁路;容量受秩与目标层限制 |
| Adapter | 插入网络的瓶颈非线性模块 | 有额外计算,可按任务切换模块 |
| Prefix-tuning | 各层注意力可使用的连续前缀 | 增加前缀状态和注意力开销,通过上下文引导生成 |
| BitFit | 模型偏置项或其子集 | 不增模块,改动空间很小;没有足够偏置参数的模型适用性受限 |

BitFit 不等于训练整个 LayerNorm。四者的参数比例、效果与延迟都依赖配置,不能统一写成“不到 1%”或固定延迟增幅。

**冻结权重不等于不会遗忘。** 启用 LoRA 或前缀后,中间表示和输出仍会变化。禁用独立适配器可恢复冻结基座的行为,但这不代表启用它时也保留全部通用能力。训练中应同时测目标任务和原有能力。

### 选型与原题追问

- **r 怎么选?** 从少量候选秩开始,固定目标层、数据并记录缩放与学习率。r 太小可能欠拟合;太大会增加开销,也可能拟合噪声,验证不再改善就不必增大。
- **LoRA 与 Adapter 的推理差异为何产生?** LoRA 是线性增量,能提前相加;经典 Adapter 含非线性,通常必须运行新增模块。两者都可多任务切换,不是 Adapter 独有。
- **强知识注入时一定要全参吗?** 没有统一阈值。先排查数据与训练设置,再与扩大目标层、提高秩和全参基线比较;若 PEFT 持续欠拟合且全参带来可接受的收益,才考虑全参或继续预训练。全参容量更大,但成本和遗忘风险也更高。

### 全参与部署的边界

全参更新全部权重,适合有可靠数据、足够预算且受限更新难以满足任务的情况;PEFT 适合节省训练状态或保留多份任务增量。QLoRA 冻结量化基座后训练 LoRA,实际效果仍须与高精度基线比较。任务与预训练分布差异大时,先改善数据、目标层和训练配置,再比较继续预训练或全参,不能只凭分布距离判 PEFT 无效。

全参微调后遗忘,先查数据、模板与更新强度,再比较旧数据回放或 EWC 等约束,用新旧验证集选检查点,见[遗忘对策](028-灾难性遗忘与对策.md)。部署时 LoRA 可在相同基座上合并线性增量;经典非线性 Adapter 通常不能这样合并。切换还须计入装载、路由和缓存,没有统一延迟增幅。
