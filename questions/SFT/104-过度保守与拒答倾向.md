## 题目

一个实体消歧模型经过 SFT 后仍然过于保守——宁可判 NIL 也不敢选候选,可能是什么原因?怎样诊断和纠正?

## 要点

- 先确认是不是真保守:看阈值曲线,而不是单点的准确率
- 最常见原因是数据里 NIL 占比过高,保守是数据教的
- 标注规范模糊时,标注者倾向标 NIL,偏差被模型放大
- 交叉熵对多数类友好,不确定时输出高熵是理性行为
- 纠正按代价顺序:先改数据分布与规范,再调损失,最后才动方法

## 答案

**先确认"保守"是不是真的。** 把模型输出的候选得分和 NIL 得分画成阈值曲线:如果调低 NIL 阈值后准确率明显回升,说明模型其实**排序是对的,只是决策点偏了**,这是校准问题不是能力问题,改阈值即可。只有排序本身就错——正确候选压根没排在前面——才是真的学不会。

排除校准问题后,按可能性从高到低排查:

1. **NIL 在训练数据里占比过高。** 保守是数据教出来的:训练集里三成是 NIL,模型学到"猜 NIL 期望损失更低"。这是最常见的原因,先统计训练集和线上真实分布的 NIL 比例是否一致。
2. **标注规范模糊。** 边界情况(提及指代不清、候选描述不全)下标注者倾向于标 NIL——这是人的避险行为,进了数据就被模型放大。查标注者一致性,看分歧样本是不是集中在 NIL。
3. **难样本被过滤掉了。** 数据清洗时把"难以确定"的样本剔除,留下的正样本都很容易,模型没见过需要靠上下文细致推断的情况。
4. **训练目标本身鼓励保守。** 交叉熵下,不确定时输出接近先验分布是理性的;类别不均衡会进一步把决策边界推向多数类。

**纠正按代价从低到高:**

| 手段 | 适用 |
|---|---|
| 调 NIL 判定阈值 | 排序正确、只是决策点偏 |
| 重采样或类别加权 | NIL 比例与线上不符 |
| 修标注规范 + 重标边界样本 | 分歧集中在 NIL |
| 补难样本、难负样本 | 模型没见过真正难的候选 |
| 偏好优化调倾向 | 上面都做完仍有系统性偏差 |

顺序很重要:**先改数据分布和规范,再调损失,最后才考虑换方法。** 直接上 DPO 去纠正一个由数据比例造成的偏差,是用复杂手段解简单问题,而且原始偏差还在数据里。

评测要同时报 NIL 的精确率和召回,以及有正确候选时的选中率——只看总准确率,一个只会判 NIL 的模型在 NIL 占多数的测试集上也能拿高分。
