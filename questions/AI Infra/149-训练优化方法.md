## 题目

请详细说明在深度学习模型训练过程中，常见的模型优化思路有哪些，包括但不限于优化器选择、学习率调整策略、正则化方法以及梯度处理等方面。

## 要点

- 先看训练/验证曲线和梯度，再决定优化器与学习率动作
- AdamW 把权重衰减与自适应梯度更新解耦
- warmup 解决训练初期更新不稳定，后续调度控制收敛
- 正则化处理过拟合，梯度裁剪处理爆炸，两者目标不同
- 混合精度的 loss scaling 与激活重算也不能混为一类

## 答案

**训练优化不是把所有技巧都打开，而是先判断问题属于“更新走不动、更新太猛、过拟合，还是数值出错”。** 然后对症调整。

| 现象 | 先检查 | 常用手段 |
|---|---|---|
| loss 几乎不降 | 学习率、数据/标签、梯度是否为零 | 调学习率、检查冻结和数据管道 |
| loss 剧烈震荡或 NaN | 梯度范数、溢出、坏 batch | warmup、降学习率、梯度裁剪、数值排查 |
| 训练好、验证差 | 数据划分、泄漏、容量 | weight decay、dropout、早停、数据增强 |
| 收敛慢但稳定 | 吞吐、学习率调度、优化器 | 提高有效吞吐，比较优化器与调度 |

### 优化器怎么选

SGD/动量方法状态少、更新规则直接，但常需更细的学习率调节。Adam 按参数的一阶和二阶矩自适应缩放，前期通常更容易训练 Transformer。AdamW 将 weight decay 与梯度更新解耦，避免把 L2 项先混入自适应缩放，因此大模型训练更常用。

AdamW 也不是无条件更好。它多保存两份优化器状态，显存和更新成本更高；`beta`、`eps`、weight decay 都要结合任务和批量实测。

### 学习率与调度

- **warmup**：训练初期统计量和激活尚不稳定，逐步升高学习率，避免第一批更新过大。
- **cosine/linear decay**：训练预算固定时逐步减小步长，让后期收敛更稳。
- **constant 或 plateau 类调度**：适合持续训练或由验证指标触发调整的场景。

改 batch size 时，不要机械套“学习率线性放大”。优化器、有效 token 数、梯度累计和训练预算都会影响合适的缩放关系。

### 正则化

weight decay 抑制权重无节制增大；dropout 随机屏蔽激活；label smoothing 减少过度自信；早停依据独立验证集阻止继续拟合噪声。SFT 是否开 dropout 取决于数据规模、模型和过拟合表现，不能默认一律关闭。

### 梯度处理与排查

梯度爆炸可通过全局梯度范数、每层梯度分布和 NaN/Inf 检测发现。全局 norm clipping 在更新前把过大的整体梯度缩回阈值内，但阈值要依据正常训练分布设定。梯度消失则要检查初始化、激活饱和、归一化、残差、学习率和错误冻结。

混合精度下，FP16 可能因小梯度下溢而使用动态 loss scaling；BF16 通常不需要同样的缩放，但仍可能因模型计算本身出现 NaN。激活重算解决的是显存，不是梯度数值稳定性。

项目复盘应按“首次异常在哪一步 → 哪项指标先变 → 改了什么 → 同预算下是否恢复”来讲。一次只改一个主要变量，保留可重复的基线。
