## 题目

权重量化、激活量化、KV cache 量化可以兼容吗?为什么?

## 要点

- 四种组合都能叠加,但收益来源与误差路径要分开看
- 权重 + 激活是同一条 GEMM,必须同时低位宽才吃得到低精度 tensor core
- 权重 + KV 作用在不同算子上,误差路径基本独立,是最常见的组合
- 顺序有讲究:先做等价变换,再做权重量化
- 误差在层间是**乘性**传播,不要指望互相抵消或线性相加

## 答案

| 组合 | 能否叠加 | 说明 |
|---|---|---|
| 权重 + 激活 | 能,本来就是同一套方法在做 | 共用一条 GEMM,必须同时低位宽才吃得到低精度 tensor core |
| 权重 + KV cache | 能,而且最常见 | 作用在不同算子上(线性层 vs attention),误差路径基本独立 |
| 激活 + KV cache | 能 | 旋转类方法就是把两者一起处理的 |
| 三者全上 | 能,但这是最激进的档位 | W4A4KV4 目前只有旋转路线做到可用 |

### 两条必须点破的纪律

**顺序有讲究**:先做等价变换(SmoothQuant 的逐通道缩放、QuaRot / SpinQuant 的旋转),**再**做权重量化(GPTQ / RTN)。变换会改变权重的分布,量化必须落在最终分布上,反过来做等于白做。

**误差怎么累积**:每加一处量化,就是往前向里多注入一个扰动,而层与层之间是**乘性传播**——后一层会放大前一层的偏差。所以既不要指望各处损失互相抵消,也不要指望它们线性相加。可靠的做法只有一个:**每加一处量化就跑一遍你真正关心的下游任务**,看掉几个点。

困惑度在这里尤其会骗人:它是逐 token 平均指标,而量化误差集中伤害低概率、关键的那些 token;在数学、代码、长链推理这类"错一步全错"的任务上,掉点常常远大于困惑度暗示的水平。

### 按收益来源搭配的三档配方

- **W4A16 + KV fp8**:单卡跑大模型 + 长上下文。权重压 4 倍解决 decode 的带宽瓶颈,KV 压一半解决上下文长度,收益来源不同,基本可以叠加
- **W8A8(或 FP8)+ KV fp8**:高并发服务。prefill 吃算力、decode 吃带宽,两头都照顾
- **W4A4KV4**:端侧与极限压缩,需要旋转类方法配专门 kernel

## 知识点

四种叠加组合、等价变换在前权重量化在后、误差的乘性传播、困惑度作为评估指标的陷阱、三档典型配方。
