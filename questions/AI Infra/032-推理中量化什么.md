## 题目

大模型推理时有哪些地方可以做量化?权重量化怎么做?激活值量化怎么做?KV cache 量化又怎么做?

## 要点

- 三个对象:权重(最好量化)、激活(最难)、KV cache(收益随序列长度放大)
- 权重训完就固定,可离线慢慢优化;主流是 W4A16 的 GPTQ / AWQ
- 激活的难点是离群通道,而 scale 落在求和维上提不出点积,所以只能 per-token / per-tensor
- 对付离群值的四条出路:绕开、搬走、摊平、躲开
- KV 是在线产生但长期存活,量化与反量化必须融进 attention 的写侧与读侧 kernel

## 答案

| 对象 | 特点 | 难度 |
|---|---|---|
| 权重 | 训完就固定,可以离线慢慢优化 | 最好量化 |
| 激活 | 随输入而变,只能在线定 scale 或拿校准集预估;且有少数幅度极大的离群通道 | 最难 |
| KV cache | 在线产生但长期存活,随 token 数线性增长 | 收益随序列长度放大 |

### 权重怎么量化

离线做,粒度可以很细:per-channel(`[out]`)或 per-group($G$=128)。两条主流路线都属 W4A16——**GPTQ** 逐层最小化**输出**重构误差 $\lVert WX - \hat{W}X\rVert_2^2$,用 Hessian $H = 2XX^\top$ 衡量敏感度、把已量化列的误差分摊给右边还没量化的列;**AWQ** 按**激活幅度**挑出约 1% 的显著通道,用等价缩放($W$ 乘 $s$、激活除以 $s$)保护它们,不改权重的相对分布。

### 激活怎么量化

难点是**离群通道**:少数固定通道的幅度比大多数激活大约 100 倍(SmoothQuant 口径;LLM.int8() 在自己口径下报最高 20 倍),而且**离群是通道的属性、不是 token 的属性**。

但粒度上被数学卡死:$Y_{t,o} = \sum_c X_{t,c}W_{c,o}$,scale 若依赖求和下标 $c$ 就提不出求和号,整数 GEMM 直接作废。所以**激活只能 per-token 或 per-tensor**——离群值偏偏长在唯一不能细分 scale 的那一维上。四条出路:

| 出路 | 做法 | 代表 | 代价 |
|---|---|---|---|
| 绕开 | 离群通道抽出走 fp16 | LLM.int8() | 混合精度 kernel 复杂,小模型上反而更慢 |
| 搬走 | 逐通道把动态范围转嫁给权重 | SmoothQuant | 权重变难量化,$\alpha$ 有 sweet spot |
| 摊平 | 正交/Hadamard 旋转打散离群 | QuaRot / SpinQuant | 部分变换必须在线做,改推理图 |
| 躲开 | 干脆不量化激活 | GPTQ / AWQ | 拿不到低位宽 tensor core 的算力翻倍 |

### KV cache 怎么量化

写时在片上量化再落块,读时 gather 进片上后在寄存器里反量化——**反量化绝不能是独立 kernel**,否则每元素 HBM 流量从 2 字节变成 2+1+2=5 字节,比不量化还差。主流引擎走**静态 per-tensor / per-head 的 fp8**;学术线的 K 按 channel、V 按 token 是另一套。

## 知识点

三个量化对象的难度分级、GPTQ / AWQ 的核心一招、激活离群通道、求和维不可切、四条出路、KV 侧量化必须融进 kernel。
