## 题目

请说明强化学习的核心要素，并比较 DQN、A2C、PPO、DDPG、TD3、SAC 等方法。面对离散或连续动作、部分可观测、稀疏奖励、昂贵采样和大模型对齐，应依据哪些条件选型？

## 要点

- 定义状态、动作、奖励、策略、回报和环境交互闭环
- 从动作空间、数据复用、稳定性、探索和计算成本比较算法
- 说明部分可观测、稀疏奖励与 Model-based 方法的额外条件
- 解释 LLM 中 state/action/trajectory 的映射及 PPO 相对 DQN 的适配性
- 说明奖励模型偏差、DPO 等替代路线与工程评测边界

## 答案

**强化学习让智能体通过环境反馈学习策略，目标是最大化长期回报。** 状态描述当前可用信息，动作改变环境，奖励给出局部反馈，策略决定如何选动作；状态若不足以预测后续，就要用历史、记忆网络或 belief state 处理部分可观测性。监督学习拟合给定标签，自监督学习从数据自身构造监督；RL 的训练标签来自策略行动后得到的回报，数据分布还会随策略变化。

### 先看环境，再选算法

| 条件 | 常见候选 | 主要判断 |
|---|---|---|
| 小型离散动作、可长期复用数据 | DQN | replay 提高复用，target network 稳定 bootstrap 目标 |
| 通用随机策略、允许新采样 | A2C、PPO | PPO 用裁剪限制单批次更新，通常比裸 A2C 更保守 |
| 连续控制 | DDPG、TD3、SAC | DDPG/TD3 为确定性策略；SAC 用随机策略和熵探索 |
| 真实交互昂贵且动力学可学 | Model-based RL | 可减少真机样本，但要承担模型偏差和规划成本 |

稳定性和样本效率不能只按算法标签排序。稀疏奖励可结合示范、课程、目标重标记、内在动机或可验证的中间任务；高维状态通常需要表示学习。若环境模型在关键区域不准，Model-based 规划会系统性利用模型漏洞，此时宁可使用保守的 Model-free 或离线方法。

### 为什么 LLM 对齐常用策略梯度

语言模型中，state 是 prompt 加已生成前缀，action 是下一个 token，完整回答是 trajectory。DQN 不需要枚举所有 token 序列，但要在大量文本前缀上估计每个动作的 Q 值；长时序、终局奖励和 bootstrap 误差让它很难稳定。PPO 直接复用预训练语言模型的策略分布，用序列奖励和优势更新所采样 token，因此更容易落地。DDPG 面向连续动作；A2C 没有 PPO 的裁剪；SAC 虽有高样本复用率，但把连续控制方法稳定扩展到巨大离散语言动作仍有明显难点。

经典 RLHF 是 SFT、奖励模型、PPO 的一种实现，不是 RLHF 的唯一形式。奖励模型可能偏好长度、格式或训练集捷径，导致奖励升高而真实质量下降；要用盲化标注、去偏数据、当前策略难例、独立人评与任务评测、KL 约束和早停共同控制。DPO 从 KL 正则化奖励目标推导出成对偏好损失，训练时没有环境交互和价值网络；是否把它称为“强化学习”是分类口径问题，更准确的工程描述是离线直接偏好优化。它省掉显式奖励模型与在线 RL，但仍依赖数据覆盖和偏好假设。

算法选型最后看四件事：奖励能否可靠计算、能否继续采样、动作空间与时序结构、失败成本。先建立统一评测，再比较每单位真实交互、算力和时间带来的收益，不用“某算法永远最稳或最省样本”的固定排名。
