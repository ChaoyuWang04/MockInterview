## 题目

多智能体强化学习中的信用分配指什么?环境只给一个全局奖励时,为什么不能让每个智能体直接拿全局奖励做策略梯度,而要先把它分配到个体?

## 要点

- 信用分配 = 判断全局回报里哪一部分该记在哪个智能体的哪个动作上
- 直接用全局奖励会把队友行为的波动全部混进本体梯度,方差随智能体数增长
- 由此产生懒惰智能体:躺平也能分享队友挣来的回报,梯度分不出好坏
- 两条主流路线:值分解(VDN/QMIX)和反事实基线(COMA)
- LLM 多 Agent 多为串行调用,更常用组内相对优势而非值分解

## 答案

**信用分配要回答的是:这一份全局回报,该记在谁的哪一步上。** 不解决它,每个智能体收到的训练信号里都混着队友的噪声。

直接用全局奖励做策略梯度,单个智能体 $i$ 的梯度是

$$
\nabla_{\theta_i}J=\mathbb E\left[R_{\rm global}\,\nabla_{\theta_i}\log\pi_i(a_i\mid o_i)\right]
$$

$R_{\rm global}$ 里同时包含了其他 $n-1$ 个智能体这一局的表现。它对 $\theta_i$ 而言是与自身动作无关的随机扰动:期望上不引入偏差,却把方差抬得很高,而且信噪比随 $n$ 增大持续下降。后果很具体——智能体 $i$ 做对了,只要队友搞砸,它照样被压;反过来它躺平也能分到队友挣来的回报,于是收敛出**懒惰智能体**。

两条主流路线:

- **值分解**:学一个联合价值,再拆成个体价值。VDN 用求和,QMIX 用单调混合网络。它们要求"个体最优与联合最优一致"(IGM 条件)成立,否则拆出来的个体价值会误导策略。
- **反事实基线**:COMA 固定其他智能体的动作,比较"该智能体换成别的动作"时的期望回报差,把这个差当优势。它直接消掉与自身动作无关的部分,但需要中心化 critic 支持反事实查询,属于 CTDE(集中训练、分散执行)。

放到 LLM 多 Agent 上要注意场景差异:主管派发子 Agent 的调用通常是**串行或树形**,不是同时决策的博弈,而且状态是文本。因此实践中更常用轨迹级的组内相对优势替代价值函数,或按步分组做更细的信用分配,见 [分层优势与 GiGPO](030-分层优势与gigpo.md);VDN/QMIX 这类为同步多体设计的方法反而少用。单智能体多轮轨迹内部的信用分配是另一个问题,见 [Agentic RL 轨迹与信用分配](022-agentic-rl.md)。

## 知识点

全局奖励与个体梯度方差、懒惰智能体、IGM 条件、VDN、QMIX、COMA 反事实基线、CTDE、差分奖励。
