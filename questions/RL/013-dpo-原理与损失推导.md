## 题目

请从 KL 正则化的奖励目标和 Bradley–Terry 偏好模型推导 Direct Preference Optimization(DPO)的损失,说明 Reference Model、$\beta$ 与优劣样本各自的作用。DPO 与显式 Reward Model、PPO 的训练流程有何区别,优势和边界是什么?

## 要点

- 从 KL 正则奖励目标写出最优策略,反解隐式奖励并消去 $Z(x)$
- 写出 chosen/rejected 相对 Reference Model 的 logistic 损失
- 比较 RM 排序学习、DPO 策略学习和 PPO 在线 Actor-Critic
- 说明 Reference Model、$\beta$、BT 假设、离线覆盖与标注噪声
- 能处理 IPO/KTO、长文本、负 loss、训练发散等追问

## 答案

**DPO 把“先训练 Reward Model,再用 PPO 优化”的两步流程,改写成在离线偏好对上直接训练策略。** 它的起点仍是 KL 正则化的奖励最大化,并非凭经验发明一个分类损失。

### 三步推导

对 prompt $x$、回答 $y$,考虑

$$
\max_\pi\ \mathbb E_{y\sim\pi}[r(x,y)]
-\beta D_{\rm KL}(\pi(\cdot\mid x)\|\pi_{\rm ref}(\cdot\mid x)).
$$

其最优策略及反解奖励为

$$
\pi^*(y\mid x)=\frac{1}{Z(x)}\pi_{\rm ref}(y\mid x)e^{r(x,y)/\beta},\qquad
r(x,y)=\beta\log\frac{\pi^*(y\mid x)}{\pi_{\rm ref}(y\mid x)}+\beta\log Z(x).
$$

Bradley–Terry 模型假设 $P(y_w\succ y_l\mid x)=\sigma(r(x,y_w)-r(x,y_l))$。同一 prompt 下两项的 $\beta\log Z(x)$ 相消,把 $\pi^*$ 换成待训练策略便得到

$$
\mathcal L_{\rm DPO}=-\mathbb E\log\sigma\!\left[
\beta\log\frac{\pi_\theta(y_w\mid x)}{\pi_{\rm ref}(y_w\mid x)}
-\beta\log\frac{\pi_\theta(y_l\mid x)}{\pi_{\rm ref}(y_l\mid x)}
\right].
$$

括号内是优选回答相对 reference 的提升,减去劣选回答相对 reference 的提升。训练增大这个分差。Reference 是固定行为锚点,也定义了隐式奖励的零点；固定数据时可缓存它的 log-prob,但标准 DPO 的概念仍依赖 reference。无 reference 的 SimPO 等是不同目标。

### 与 RM、PPO 的区别

| 方法 | 偏好数据训练出什么 | 后续怎样优化策略 |
|---|---|---|
| 显式 RM | 标量评分器 $r_\phi(x,y)$,用 $-\log\sigma(r_w-r_l)$ | PPO 再在线 rollout,RM 打分,Critic 估优势 |
| DPO | 策略 $\pi_\theta$,用相对 reference 的成对分差 | 没有单独 RM、Critic 和在线 RL 循环 |

PPO 常最大化 $\mathbb E[\min(\rho_t\hat A_t,\operatorname{clip}(\rho_t,1-\epsilon,1+\epsilon)\hat A_t)]$,可利用当前策略的新回答及任意可靠奖励；DPO 复用固定偏好对,工程更简单,减少 RM 外推和 Actor-Critic 耦合,但不能探索数据没覆盖的行为。两者效果没有无条件高低。

### 参数、假设和故障

原始奖励目标里 $\beta$ 越大越保守；DPO 损失里它还缩放分差与梯度,要和学习率、训练步数一起调,用偏好准确率、实际生成、长度分桶和能力回归评测选择。BT 的标量效用差难表达循环偏好、群体分歧；错标与矛盾应先复核、仲裁或降权,再用较小更新和早停。旧策略生成的离线数据还会有覆盖偏移,可采集当前策略候选后重新标注。

长文本并非必然输给 PPO,但序列 log-prob 累加、截断和长度偏置会更明显；先平衡长度、核对 mask 并分桶评测,再比较长度归一化变体。IPO 用有限目标的平方损失抑制分差无限增大的倾向,可能在有噪声时更稳,但不是普遍保证；KTO 适合单条好/坏反馈。

标准 DPO 的负对数似然 $-\log\sigma(\cdot)\ge0$。日志若显示负值,先确认记录的是待最大化的 $\log\sigma$ 还是 loss；真 loss 发散则检查 chosen/rejected 是否反了、response mask 与截断、序列求和口径、冻结或缓存的 reference、学习率、$\beta$ 和数值精度。
