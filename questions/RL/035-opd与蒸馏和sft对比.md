## 题目

On-Policy Distillation 的具体训练流程是什么?它与传统(离线)知识蒸馏、以及用教师生成数据做 SFT,区别在哪里?

## 要点

- 流程的关键是每轮重新采样,采样一次训到底就退化成离线蒸馏
- 三者差在两个正交维度:轨迹由谁生成、监督是软分布还是硬 token
- 教师数据 SFT 只保留 one-hot 目标,丢掉了分布里的相对信息
- 离线蒸馏有软分布但轨迹来自教师,学生走偏后的状态没被训到
- 教师前向是主要开销,它决定了 OPD 比 SFT 贵多少

## 答案

### 训练流程

1. 学生按**当前**策略对一批 prompt 采样,得到自己的输出
2. 冻结的教师在**这些学生轨迹**上做一次前向,给出每个位置的词表分布
3. 逐 token 计算学生与教师分布的 KL(方向按需选)
4. 反传只更新学生
5. 学生更新后,**回到第 1 步重新采样**

第 5 步是"on-policy"的全部含义:数据分布必须跟着策略一起变。若只采一次样本然后反复训练多个 epoch,轨迹很快就不再是当前学生会走的路,整个方法退化成离线蒸馏。

### 三者的区别

差别落在两个正交维度上——**轨迹由谁生成**,和**监督是软分布还是硬 token**:

| 方案 | 轨迹来自 | 监督粒度 | 对教师的要求 |
|---|---|---|---|
| 离线知识蒸馏 | 教师或固定数据集 | 逐 token 全词表分布 | 能拿到完整分布 |
| 教师数据做 SFT | 教师 | 硬 token(one-hot) | 只要文本 |
| OPD | 学生自己 | 逐 token 全词表分布 | 完整分布,且能在任意前缀上前向 |

**教师数据 SFT** 最省事,但每个位置只留一个正确答案,教师"第二、第三选择分别有多可能"的信息全部丢掉;而且学生学的是教师会走的路,自己走偏之后怎么办没人教。

**离线蒸馏**补回了软分布,却仍在教师的轨迹上训练,exposure bias 依旧。

**OPD** 两个维度都占:在学生自己会到达的状态上,拿到密集的分布反馈。代价是每一轮都要让教师在学生的新轨迹上前向一遍,这是它比 SFT 贵的主要来源,也是工程上最先要优化的地方。
