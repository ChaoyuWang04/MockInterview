## 题目

GRPO（Group Relative Policy Optimization）为什么对同一个 prompt 采样一组回答，并用组内相对奖励估计优势？请写出核心目标，从奖励来源、方差、稳定性、训练成本和适用场景比较 GRPO、PPO 与 DPO；如果题目中的“SFTQ”没有给出论文或完整定义，应如何处理？

## 要点

- GRPO 的标准全称与组内相对优势公式
- 免 critic 不等于免奖励、免 reference 或离线训练
- PPO、GRPO、DPO 的数据与目标不同
- 效率、长序列、多模态和稀疏噪声奖励都要说明边界
- SFTQ 不是可唯一识别的标准算法名，不能强行比较

## 答案

**GRPO 的核心变化是不用价值网络，而用同题多个回答的相对得分作基线。** 对 prompt $q$ 采样 $G$ 个回答，奖励为 $r_1,\ldots,r_G$，常见优势写成：

$$
\hat A_i=\frac{r_i-\operatorname{mean}(r_1,\ldots,r_G)}{\operatorname{std}(r_1,\ldots,r_G)}
$$

再用旧策略概率比 $\rho_{i,t}$ 做 PPO 式裁剪，并可加入相对参考策略的 KL 正则：

$$
J=\mathbb E\!\left[\min(\rho_{i,t}\hat A_i,\operatorname{clip}(\rho_{i,t},1-\epsilon,1+\epsilon)\hat A_i)\right]-\beta D_{KL}(\pi_\theta\|\pi_{ref})
$$

同一回答的生成 token 通常共享这个 response 级优势。组内减均值回答“这个回答比同题其他回答好多少”，因此不再训练 critic，也省去 GAE 和 value loss。代价是每题必须生成多个有差异的候选；全对、全错或奖励几乎相同时，组内没有有效梯度。标准化能稳定奖励尺度，但小组、离群奖励和相关样本仍会带来噪声，不能保证方差总比 PPO 小。

| 方法 | 训练数据与信号 | 更新方式 | 主要取舍 |
|---|---|---|---|
| PPO | 在线 rollout、标量奖励、critic 价值估计 | token 级优势与新旧策略比裁剪 | 通用、信用分配细；四模型工程重，critic 可能不稳 |
| GRPO | 在线组采样、规则或模型给出的标量奖励 | 组内相对优势与裁剪更新 | 免 critic；生成成本随组大小增加，依赖组内可区分性 |
| DPO | 固定的优选/劣选回答对 | 对策略与 reference 的对数概率比做分类式优化 | 流程近似监督学习；受离线偏好覆盖限制，不能在线探索新回答 |

GRPO **不是在线 DPO**。它仍需奖励：数学答案匹配、代码单测、过程/结果验证器或神经奖励模型都可以。原始 GRPO 目标也可保留 reference KL；“免 critic”不能推导出“免奖励模型”或“完全没有正则”。在数学、代码等可验证推理任务中，便宜且较难钻空子的结果奖励、同题多解和免 critic 的组合很合适；长序列则会放大 rollout 成本、终局奖励的信用分配困难和长度偏置。

多模态反馈本质上仍要归约为可比较的标量或多目标约束：可组合图文一致性、OCR/检测指标、安全规则与人类偏好分，并先校准各分量尺度。组相对机制本身没有“分段向量奖励”的固定设计。实际效率取决于生成长度、组大小、奖励模型和并行实现，不能声称固定节省比例。调优时先看零方差组占比、奖励分布、长度、熵、KL 和独立任务指标，再调组大小、采样温度、学习率、裁剪和 KL。

奖励稀疏但可靠、且同题能产生好坏混合候选时可优先试 GRPO；若需要细粒度状态价值或组采样太贵，PPO 的 critic 可能更合适。奖励噪声大时，两者都会受影响，应先改善奖励、做独立评测并控制更新强度，不能只靠换算法。题目若只写“SFTQ”，由于它不是可唯一识别的通用算法缩写，应先索要论文、全称与训练目标；未澄清前最多与普通 SFT 比较，不能编造一套“SFTQ”机制。
