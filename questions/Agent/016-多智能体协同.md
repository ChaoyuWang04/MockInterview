## 题目

解释多智能体系统的基本概念，并分析多个 LLM Agent 相比单 Agent 在分工、容错和并行效率上的潜在优势与新增挑战。请结合场景设计角色、任务分配、通信、共享状态和协调机制。

## 要点

- 多 Agent 的收益有条件，必须与同预算单 Agent 比较
- 任务图、角色边界、消息契约和状态所有权明确
- 覆盖超时、重复消息、冲突和幻觉传播
- 比较集中、去中心化和混合调度
- 给出延迟、成本、正确率和协作效率指标

## 答案

**多智能体系统是多个有独立状态或职责的 Agent 通过消息和环境协作；它只有在任务可并行或确有专业分工时才可能胜过单 Agent。** 例如地图服务可让交通、路径和 POI Agent 并行产出带来源的候选，由协调器依据用户约束合成结果。

先把目标拆成带依赖、输入输出、deadline 和验收条件的任务图。消息携带 task ID、版本、来源、置信度和幂等键；共享状态指定唯一写入者，其他 Agent 通过事件读取。管理者适合统一路由与预算，但可能成为瓶颈；去中心化合同网适合动态分配，却增加通信和一致性成本；常用做法是分层混合调度。

超时后可由备用 Agent 接管，但租约和幂等键要防止原任务恢复后重复写入。多个答案冲突时按证据新鲜度、权威性和约束验证仲裁，高风险结果交给独立验证器或人工；不要只让 Agent 相互投票，因为错误可能高度相关。消息只传必要摘要和证据引用，减少 token 开销及幻觉扩散。

单 Agent 任务不可并行、共享上下文很大或协商轮数多时，多 Agent 反而更慢。评测应在相同模型、token、工具和时限预算下比较任务成功率、墙钟延迟、总成本、通信占比、冲突率、重复工作率、故障恢复率和责任可追踪性。

## 知识点

多智能体系统、任务图、消息契约、状态所有权、合同网、租约、仲裁、协作评测。
