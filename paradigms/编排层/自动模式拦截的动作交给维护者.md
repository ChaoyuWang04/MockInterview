# 一步动作会被自动模式拦下

**现行做法**:自动模式的权限检查会拦几类动作——把别的仓库的历史合并进来、改生产部署的项目设置、把本机或服务器上没公开过的个人资料搬进公开仓库。遇到这几类,不先试再被拦,而是在意图卡或方案里直接写「这一步交维护者执行」,附上可以原样粘贴的命令;维护者跑完回一句,agent 接着做后面的验证。被拦之后不换个写法绕过去。

**原则**:权限边界是维护者的,不是要绕开的障碍;提前把那一步交出去,比撞墙后再转交少一轮往返。

**Claude 与 Codex**:这里说的拦截是 Claude Code 自动模式的分类器;Codex 的审批模式不同,遇到同类动作照样交给维护者。
