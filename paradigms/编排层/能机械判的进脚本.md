# 一条规则反复被违反

**现行做法**:凡是能机械判定的(格式、命名、引用存在性、图的碰撞、跨篇长句重复),写成测试或 lint,不写进守则正文。守则只留需要判断力的条目。脚本报的是「可疑处」,抽样看原文再下结论;检查逼得人换措辞躲避时,改检查而不是改文章。

**原则**:能让机器守的规则不占 agent 的注意力;守则越短,需要判断的那几条越被认真对待。

**Claude 与 Codex**:相同。
