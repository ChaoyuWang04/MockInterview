# 给 agent 写常驻指令

**现行做法**:只维护一份入口文件 `AGENTS.md`,控制在 200 行以内,只放路由、协作契约和不可破坏的约束;`CLAUDE.md` 只写一行 `@AGENTS.md` 导入它。流程细节放在各手册,操作细节放在 skill,agent 按任务只加载需要的那一份。

**原则**:常驻上下文越短、越具体,遵循度越高;两份手工同步的副本迟早漂移,只留一份真源。

**Claude 与 Codex**:Codex 原生读 `AGENTS.md`。Claude Code 在目录里有 `CLAUDE.md` 时默认不再读 `AGENTS.md`,且部分会话读不到 `AGENTS.md`,所以用 `CLAUDE.md` 导入最稳;导入的文件在启动时就全部进上下文,拆文件不等于省 token。

**本仓库落实在**:`AGENTS.md`、`CLAUDE.md`、`docs/00-START.md` 的地图
