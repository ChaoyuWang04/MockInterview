# 维护者丢来一份材料或一句模糊的话

**现行做法**:agent 自己识别输入该走哪份手册,先出一张意图卡(理解、路径与去重、产出与终点、至多 3 个带推荐项的待定问题),维护者确认一次后一路做到终点——验证、更新索引与队列、提交推送。同一任务里的「继续」「下一批」「收尾」不再确认。维护者不需要先让 agent 读文档、讲流程。

**原则**:对齐意图的成本放在最前面,而且只付一次;之后的每次请示都是在把判断推回给人。

**Claude 与 Codex**:相同。两边都从 `AGENTS.md` 读到这套契约(Claude 经 `CLAUDE.md` 导入)。

**本仓库落实在**:`AGENTS.md` 的「收到输入怎么做」与「口令」
